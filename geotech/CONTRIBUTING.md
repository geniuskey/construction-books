# GeotechBook 챕터 작성 가이드

GeotechBook은 ConstructionBooks 서가(`construction.euiyun.com`)의 세 번째 권인 지반공학 교과서다. 배포 주소는 `https://construction.euiyun.com/geotech/`. 엔진·CSS·장 구성 규칙은 MechanicsBook(`../mechanics/`)·MaterialsBook(`../materials/`)을 그대로 물려받았다. 전역 객체 `CB`, 구조 해석기(`CB.frame`/`CB.beam`/`CB.truss`/`CB.section`)가 그대로 있고, 이 책에서 **지반 모델** `CB.soil`(상 관계, 응력 단면, 지중 응력, 압밀, 연직 배수, 전단강도, 토압, 지지력, 사면, 액상화, 투수)과 기준 지반 `CB.soil.SITE`를 더했다. 문체·구성·그림·시뮬레이터 수준의 본보기는 `../materials/chapters/mix-design.html`, `../materials/chapters/durability.html`, `../mechanics/chapters/beam-forces.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 역사·수치·기준 조항은 확인된 것만 쓴다(확실하지 않으면 쓰지 않거나 "약", "교육용 가정"으로 표시한다).

## 구조

빌드 없이 열리는 정적 페이지다. `index.html` + `chapters/<slug>.html` + `css/style.css`(앞 권과 같고 강조색만 흙 갈색 `#7a4f26`, 보조색 안전 주황 `#e8590c`) + `js/common.js`(전역 `CB`, 장 목록 `CHAPTERS`). classic script만 쓴다(ES module 금지). 외부 라이브러리는 쓰지 않는다(KaTeX는 빌드가 처리). 3D는 `CB.orbit`(캔버스 2D 투시)으로 그린다.

- 장 목록은 `js/common.js`의 `CHAPTERS`에 있다.
- 용어는 `js/glossary-data.js`(시리즈 공통 v1)에 있다. 본문에서 처음 나오는 용어는 `<span class="term">…</span>`. 장을 쓸 때는 그 장의 용어를 `js/glossary/<slug>.json`(용어 객체 `{"ko","en","abbr","def","chapters":["<slug>"]}`의 배열)에 따로 적고, 합치는 일은 `tools/merge-glossary.py geotech`가 한다(같은 `ko`는 하나로). `en`은 대문자로 시작하고(예: "Effective stress"), `abbr`에 밑줄을 쓰지 않는다(`cu`, `OCR`). 앞 권에 있는 용어(응력, 모어 원 등)는 지반 관점으로 새로 정의하되 모순되지 않게 한다.

## 원칙: 조사 → 시험 → 해석 → 판단

지반공학은 "보이지 않는 재료를 조사하고, 시료로 시험하고, 모델로 계산하고, 불확실성을 안고 판단하는" 학문이다. 이 책은 모든 개념을 **땅속을 그림으로 열어 보고(지층 단면) → 손으로 계산하고(식) → 시뮬레이터로 확인하고 → 기준 지반 G-10 위의 실제 구조물(B-10의 굴착·기초, 진입 도로 성토 E-4, T-36 교대, 깎기 비탈 S-10)에서 숫자로 만나는** 순서로 쓴다. 지반 정수의 불확실성(같은 층에서도 흩어지는 N값, 시험 방법에 따라 다른 강도)과 공학적 판단을 장마다 한 번 이상 다룬다.

- 한국어, 대상은 건축·토목 2–3학년과 지반·기초를 다시 공부하는 신입 엔지니어(구조역학의 응력·모어 원, 미적분을 안다고 가정). 영어 원어는 `<span class="en">(Effective stress)</span>`처럼 병기.
- 장 첫머리는 `.origin`("이 계산이 없었다면")으로 연다. 각 절은 가능하면 `.problem`(현장의 질문)으로 시작한다.
- 흐름: 문제 → 그림(SVG) → **조작하는 시뮬레이터** → 정의·원리(KaTeX) → **손으로 푸는 예제**(`.callout` 안에 단계별, 단위까지) → 기준 구조물 노트(`.callout.site`) → 쓰이는 곳(`.uses`) → 핵심 정리 → 확인 퀴즈(6–8문항).
- 정의·원리·정리는 `<div class="callout def"><strong>원리 4.1 (유효응력의 원리)</strong> …</div>`처럼 **장 번호.순번**. `.callout.deep`은 심화(유도·예외·고급 주제). 예제는 `예제 4.1`, 그림은 `그림 4-1.`.
- 장마다 **시뮬레이터 6–8개, 그림 6개 이상, 퀴즈 6–8문항.** 시뮬레이터는 계산하는 모델이다. 숫자를 바꾸거나 점을 끌면 그림과 값이 바로 반응해야 하고, 입력을 끝까지 움직여도 NaN·음수 응력·0으로 나누기가 나오면 안 된다. 쓰는 식은 본문이나 `sim-note`에 적는다.
- 지반 계산은 `CB.soil`로 한다(장 고유의 모델 — 유선망 유한 차분, 다짐 곡선, 응력 경로, 흙막이 벽 해석, 말뚝 하중 전이, 1차원 지반 응답, 암반 분류 — 은 페이지 스크립트에 둔다). 같은 공식을 장마다 다시 구현하지 않는다. 구조 계산(옹벽 벽체, 흙막이 벽의 휨, 버팀보)은 `CB.beam`/`CB.frame`을 쓴다.
- 색은 CSS 변수와 `CB.palette()`만. 라이트/다크 모두 확인. 폭 360px에서 가로 스크롤 금지. SVG는 `viewBox`만 주고 width/height 생략, viewBox 폭은 900 이하.
- 시뮬레이터 `id`는 `sim-<장 접두사>-<이름>`, 캔버스·입력 등 요소 id도 같은 접두사(`cn-cv-iso`, `cn-H`). 이 장 전용 CSS 클래스도 접두사(`.cn-bar`). 절 `id`는 의미 있는 영어 슬러그로 짓고 바꾸지 않는다.

## 단위·부호·색 규약 (책 전체 공통)

**단위.** 응력·압력·강도 kPa(= kN/m²), 지지력도 kPa, 단위중량 kN/m³(물 γw = 9.81 kN/m³), 길이 m(입자 크기 mm), 투수 계수 m/s, 압밀 계수 m²/년, 시간 연·일, 각도 °, 힘 kN, 선 하중 kN/m. 함수비·간극률·포화도는 % 또는 소수(본문에 밝힌다). 값 표시는 `CB.num(v, d)` 또는 `CB.sig(v)`.

**부호와 좌표.** 지반공학 관습대로 **압축 응력이 +**(MechanicsBook의 인장 + 와 반대임을 4장과 9장에서 한 번 밝힌다). 깊이 z는 지표에서 아래로 +. 단면 그림은 지표를 위에, 깊이를 아래로 그리고 깊이 축에 "깊이 z (m)"를 적는다. 모어 원은 σ를 오른쪽 +(압축), τ를 위 +로 그린다.

**색.**

| 대상 | 색 | 사용 |
|---|---|---|
| 흙 입자·지층 | `accent`(갈색) 계열, 층마다 명도 차 | 단면, 상 관계 막대 |
| 물·간극수압 | `blue` | 지하수위(▽), 수압 분포, 유선 |
| 공기 | `text-faint` | 상 관계 막대 |
| 유효응력 | `accent` | 응력 단면 |
| 전응력 | `text-dim` | 응력 단면 |
| 하중·추력·활동력 | `accent2`(주황) | 화살표, 활동 토체 |
| 저항력·안전 | `ok`(초록) | 저항 화살표, FS ≥ 기준 |
| 위험·파괴 | `bad` | FS < 기준, 활동면 |
| 등수두선 / 유선 | `accent2` 점선 / `blue` 실선 | 유선망 |

지하수위는 책 전체에서 파란 ▽ 기호와 수평 점선으로 그린다.

**01 흙과 지반 조사** — 지반공학이 다루는 것(기초·굴착·성토·비탈·터널, 피사의 사탑 같은 실패 사례는 확인된 사실만) / 흙의 생성: 풍화(물리·화학), 잔적토·운적토(충적·해성·풍적), 한국의 지반(화강암 풍화토, 서·남해안 해성 점토) / 입자의 크기와 모양(자갈·모래·실트·점토 경계) / 지반 조사의 단계와 범위 / 시추와 시료 채취(교란·불교란, 얇은 관 시료) / 표준관입시험: N값, 에너지 보정 N₆₀, 상재압 보정, N값과 상대 밀도·φ′·연경도 / 콘 관입 시험(qc, fs, 마찰비, 간극수압 측정 CPTu)과 흙의 판별 / 베인 시험, 공내 재하 시험, 물리 탐사(탄성파) 맛보기 / 주상도 읽기, 지층 단면 만들기 / 기준 지반 G-10 소개와 이 책의 지도. 시뮬: G-10 시추 주상도 만들기(깊이별 층·N값 막대, 클릭하면 층 정보), 표준관입시험 애니메이션(해머 낙하 → 관입량 → N, 에너지 효율 보정), N값 → 상대 밀도·φ′ 상관(흩어짐 띠 포함), CPT 로그와 흙 판별 도표(qc–마찰비 점 끌기), 시추공 여러 개 → 지층 단면 보간(시추 위치 옮기기, 놓친 렌즈), 조사 비용 vs 불확실성(시추 수 → 추정 오차), 입자 크기 감각(자갈~점토 확대).
**02 흙의 상 관계와 다짐** — 3상 모형(흙 입자·물·공기)과 부피·질량 / 간극비 e, 간극률 n, 함수비 w, 포화도 S, 비중 Gs, 단위중량 γ·γd·γsat·γ′ / 관계식 Se = wGs와 유도 / 상대 밀도 Dr / 다짐의 원리: 함수비와 건조 단위중량, 최적 함수비와 최대 건조 단위중량, 다짐 에너지(표준·수정 다짐), 영공기 간극 곡선 / 다짐한 흙의 구조(건조 측·습윤 측)와 투수성·강도 / 현장 다짐 관리: 들밀도 시험(모래 치환), 상대 다짐도, 함수비 관리, 다짐 장비 / CBR과 노상 / E-4 성토와 P-13 노상의 다짐. 시뮬: 3상 막대 계산기(아는 값 3개 → 나머지 모두, `CB.soil.phase`), 흙 블록 확대(입자 배치·물 채우기 → e·w·S), 다짐 시험 시뮬(몰드에 다지기 → 점 찍기 → 다짐 곡선 맞춤, 에너지 바꾸기, 영공기 간극 곡선 `CB.soil.zav`), 들밀도 시험 계산기(모래 치환 질량 → γd → 상대 다짐도 판정), 다짐 곡선과 투수 계수·강도의 관계, 성토 물량 계산(자연 상태 → 다짐 후 부피, 토량 환산 계수), 상대 밀도 → 액상화 민감도 맛보기.
**03 흙의 분류** — 분류의 목적 / 입도 분석: 체 분석과 비중계 분석(스토크스 법칙), 입도 곡선, D₁₀·D₃₀·D₆₀, 균등 계수 Cu와 곡률 계수 Cc, 입도 양호·불량 / 연경도: 액성 한계(캐사그란데·낙하 콘), 소성 한계, 수축 한계, 소성 지수 PI, 액성 지수 LI, 연경도 지수 / 소성도(A선·U선) / 통일 분류법(USCS): 자갈·모래·세립토, 2문자 기호(GW, SP, CL, CH, ML, MH, OH, Pt), 판정 흐름 / AASHTO 분류와 군지수 맛보기 / 점토 광물(카올리나이트·일라이트·몬모릴로나이트), 비표면적과 이중층, 활성도 A = PI / 점토분 % / 예민비와 해성 점토 / G-10 각 층의 분류. 시뮬: 입도 곡선 만들기(체 잔류량 → 곡선, D₁₀·D₆₀·Cu·Cc 자동), 비중계 침강(스토크스: 입자 크기 → 침강 시간 애니메이션), 액성 한계 시험(타격 횟수–함수비 점 → 25회 함수비), 소성도 위에 점 끌기 → 기호·이름, USCS 판정 흐름도 마법사(입도·한계 입력 → 단계별 판정), 점토 광물 비교(층 구조 그림·비표면적·활성도), 흙 표본 맞히기 게임(성질 → 분류 기호 고르기).
**04 유효응력** — 테르자기의 유효응력 원리 σ′ = σ − u와 그 뜻(입자 접촉력) / 지층 속 전응력·간극수압·유효응력 단면(`CB.soil.profile`) / 지하수위 변화(양수에 따른 침하, 지하수위 상승) / 수중 단위중량 / 모관 현상: 모관 상승 높이, 부(−)의 간극수압, 불포화 흙 맛보기 / 침투가 있을 때: 하향·상향 침투와 유효응력, 침투력 iγw / 한계 동수경사 ic = γ′/γw와 분사 현상(quick condition), 보일링 / 하중 직후 간극수압의 증가(B 계수 맛보기, 7장 연결) / 굴착 바닥의 양압력과 B-10 매트에 작용하는 양압력 88 kPa / 부호 규약(압축 +) 안내. 시뮬: G-10 응력 단면(지하수위 끌기 → σ, u, σ′ 선, `CB.soil.site`), 입자 접촉력 모형(물 넣기 → 부력 → 접촉력 감소), 양수에 따른 지하수위 저하 → 유효응력 증가 → 침하 추정, 모관 상승관(입자 크기 → 높이, 부압), 상향 침투 탱크(수두 차 올리기 → σ′ → 0 분사 현상 애니메이션, `CB.soil.ic`), 굴착 바닥 양압력과 들림 안전율(굴착 깊이·피압 수두), 수압·유효응력 퀴즈형 단면(층 쌓기).
**05 투수와 침투** — 흙 속의 물 흐름과 수두(위치·압력·속도 수두), 동수경사 / 다르시 법칙 v = ki, 유출 속도와 침투 속도 / 투수 계수의 크기(자갈~점토, 하젠 식 맛보기)와 영향 인자 / 실내 시험(정수두·변수두)과 현장 시험(양수 시험, 티엠 식) / 성층 지반의 등가 투수 계수(`CB.soil.keq`) / 2차원 침투: 라플라스 방정식, 유선과 등수두선, 유선망 그리기 규칙, 침투량 q = kH Nf/Nd / 널말뚝·흙댐 아래 침투, 양압력 / 파이핑과 출구 동수경사, 필터 기준(테르자기) / 굴착 시 지하수 처리(차수·배수) / B-10 지하연속벽 아래 침투. 시뮬: 정수두·변수두 시험기(수두·시간 → k), 다르시 탱크(시료 길이·수두 → 유량, 유출 vs 침투 속도), 성층 지반 등가 k(층 쌓기 → kh·kv, 흐름 방향), 2D 유선망 유한 차분(널말뚝 깊이·상하류 수위 끌기 → 등수두선·유선·침투량·출구 경사, 페이지 내 라플라스 해석기), 흙댐 침윤선(카사그란데 포물선 근사), 양수 시험(티엠 식: 관측정 두 개 → k), 필터 설계(필터·보호 흙 입도 곡선 → 기준 만족 여부).
**06 지중 응력** — 하중은 깊어질수록 퍼진다 / 부시네스크 해: 집중 하중(`CB.soil.point`), 선 하중, 띠 하중(`strip`), 원형(`circle`), 직사각형 모서리 공식과 중첩(`cornerI`, `rect`) / 영향계수 표와 압력 구근(0.1q 등압선의 깊이 ≈ 2B) / 2:1 분포법(`twoToOne`)과 오차 / 뉴마크 영향원 맛보기 / 성층 지반과 웨스터가드 해 맛보기 / 기초의 접지압 분포(강성 기초: 점토에서 가장자리 집중, 모래에서 가운데 집중) / 인접 기초의 영향(중첩) / E-4 성토 아래 응력(사다리꼴 하중), B-10 매트·T-36 교대 아래 응력. 시뮬: 집중 하중 아래 응력 등고선(하중 끌기, 등압선 색), 띠·원·직사각형 압력 구근 비교(폭·형상 → 0.1q 깊이), 직사각형 중첩 계산기(점 위치 끌기 → 모서리 네 개의 합·차, `CB.soil.rect`), 2:1법 vs 부시네스크(깊이별 오차 곡선), 이웃한 기초 두 개의 중첩(거리 → 겹친 응력), 성토 하중(사다리꼴) 아래 응력, 접지압 분포(강성·지반 종류).
**07 압밀** — 점토가 천천히 내려앉는 이유(물이 빠져야 유효응력이 는다) / 스프링–피스톤 모형 / 압밀 시험(오이도미터): 하중 단계, 시간–침하 곡선, e–log σ′ 곡선 / 압축 지수 Cc, 팽창(재압축) 지수 Cr, 체적 압축 계수 mv / 선행압밀응력 σ′p(캐사그란데 작도), 과압밀비 OCR, 정규압밀·과압밀 / 1차 압밀 침하량(`CB.soil.settlement`) / 테르자기 1차원 압밀 이론: 가정, 지배 방정식 ∂u/∂t = cv ∂²u/∂z², 등시곡선(`uRatio`), 평균 압밀도와 시간 계수(`U`, `Tv`), 배수 거리 / cv 구하기(√t법·log t법) / 2차 압밀(`secondary`) / E-4 성토의 0.43 m와 9년. 시뮬: 스프링–피스톤 모형(하중 → 물 빠짐 → 스프링 압축 애니메이션), 압밀 시험기(하중 단계 → e–log σ′ 점, Cc·Cr 직선 맞춤), 캐사그란데 작도(곡선 위 최대 곡률점 끌기 → σ′p), 침하량 계산기(H·e₀·Cc·Cr·σ′₀·Δσ·σ′p → S, 정규/과압밀 분기), 등시곡선 애니메이션(Tv 슬라이더 → u(z) 곡선, 한면/양면 배수), U–Tv 곡선과 시간 계산(층 두께·cv → t₅₀, t₉₀), √t법으로 cv 구하기(시간–침하 데이터에 접선 끌기), E-4 시간–침하 곡선.
**08 침하와 연약지반 개량** — 침하의 성분: 즉시(탄성) 침하 Si = qB(1 − ν²)If/E, 1차 압밀, 2차 압밀 / 허용 침하와 부등 침하, 각변위(1/500 등, 기준 확인)와 건물 손상 / 연약지반의 문제(침하·안정·측방 유동) / 선행 재하(프리로딩)와 과재하 / 연직 배수재: 원리, 배치(정삼각·정사각, `de`), 방사 방향 압밀(Barron·Hansbo, `Uh`), 스미어와 웰 저항 맛보기, 연직·방사 조합 U = 1 − (1 − Uv)(1 − Uh) / 진공 압밀 맛보기 / 다짐 공법(동다짐, 진동 다짐, 모래 다짐 말뚝 SCP)과 치환율 / 고결 공법(심층 혼합, 고압 분사 그라우팅)과 시멘트 혼합토 / 경량 성토(EPS) / 계측과 관찰적 방법(침하판·간극수압계, 아사오카법 맛보기) / E-4 개량 설계. 시뮬: 즉시 침하 계산기(B·q·E·ν·형상 → Si), 부등 침하와 각변위(기둥 침하 점 끌기 → 각변위·손상 등급), 선행 재하 계획(과재하 높이 → 목표 침하 도달 시간), PVD 간격 설계(간격·배치·ch → Uh 시간 곡선, `CB.soil.Uh`·`U` 조합), 연직 배수 평면 배치 그림(간격 바꾸면 영향 원 de), SCP 치환율(지름·간격 → 치환율 → 복합 지반 강도), 아사오카법(계측 침하 점 → 최종 침하 예측), E-4 무처리 vs PVD 시간–침하 비교.
**09 흙의 전단강도** — 흙은 전단으로 파괴된다 / 마찰과 맞물림, 다일러턴시(조밀한 모래 팽창, 느슨한 모래 수축) / 모어–쿨롱 파괴 기준 τf = c′ + σ′ tanφ′(`tauF`), 모어 원과 파괴 포락선, 파괴면 각도 45° + φ′/2 / 직접 전단 시험 / 삼축 압축 시험: 장치, UU·CU·CD, 간극수압 측정, 유효응력 경로 / 응력 경로(p′–q 또는 s′–t) / 배수 강도와 비배수 강도 cu, φ = 0 해석 / 정규압밀 점토의 cu/σ′v(약 0.22), 과압밀 점토 / 간극수압 계수 A·B(스켐턴) / 일축 압축 시험, 베인 시험과 보정 / 예민비와 틱소트로피 / 모래의 한계 상태 맛보기 / 단기·장기 안정과 어떤 강도를 쓰나 / G-10 연약 점토의 cu 단면. 시뮬: 직접 전단 시험기(수직 응력 → 전단 응력–변위 곡선, 조밀/느슨 다일러턴시), 모어 원과 포락선(σ₃·σ₁ 끌기 → 파괴 판정, 파괴면 각도, `sigma1f`), 삼축 CD vs CU vs UU(같은 시료로 세 시험 → 경로·강도 비교), 응력 경로 그리기(p′–q 평면, 배수·비배수), 간극수압 계수 A(과압밀비 → 경로가 휘는 방향), cu 단면(G-10 깊이별 cu = 0.22σ′v0, 베인 시험 점과 비교), 예민비(교란 전후 강도).

**15 지반 동역학과 액상화** — 지진과 지반(지진파, 가속도·주기) / 흙의 동적 성질: 전단파 속도 Vs, 동적 전단 탄성계수 G = ρVs², 변형률에 따른 G/Gmax·감쇠 / 1차원 지반 응답: 고유 주기 T = 4H/Vs(`period`), 공진과 증폭 / 지반 분류(Vs30, 기반암 깊이 — KDS 17 10 00의 S1–S6 형태, 기준 확인) / 액상화의 메커니즘(반복 하중 → 간극수압 상승 → 유효응력 0) / 간편 판정법: CSR(`CSR`, `rd`), (N₁)₆₀(`CN`), CRR(`CRR`), 안전율, 규모 보정 맛보기 / 액상화의 결과: 모래 분출, 침하, 측방 유동, 말뚝 피해 / 대책: 다짐, 배수, 고결, 지하수위 저하 / 기계 기초 진동 맛보기 / G-10 느슨한 모래층의 판정(FS 약 0.6). 시뮬: 전단파 전파 애니메이션(층마다 Vs → 파가 느려지고 커짐), 지반 응답 1자유도·층 모형(입력 주기 → 증폭 곡선, 공진, 페이지 내 전달 함수), G/Gmax·감쇠 곡선(변형률 → 강성 저하), Vs30 계산기(G-10 층 → Vs30·지반 분류), 액상화 판정 단면(깊이별 CSR·CRR·FS 곡선, 지진 가속도·지하수위·N값 슬라이더), 반복 삼축 시험(사이클 → 간극수압비 상승 → 액상화), 대책 효과(다짐 후 N값 → FS).

**17 용어집 & 종합 퀴즈** — 공식·수치 한눈표(상 관계, G-10 응력 단면, 지중 응력 영향계수, 압밀 식과 U–Tv 표, 전단강도·토압 계수, 지지력 계수 표, 사면 안전율, 말뚝 지지력, 액상화 판정), 부호 규약 정리, 용어 검색, 전 범위 종합 퀴즈(장마다 1–2문항). `../materials/chapters/glossary.html`의 구조를 따른다.

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `geotech/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
- 유효응력 기호는 프라임(σ′, φ′, c′)으로 쓴다. HTML에서는 `′`(U+2032), KaTeX에서는 `\sigma'`.
