# ConcreteBook 챕터 작성 가이드

ConcreteBook은 ConstructionBooks 서가(`construction.euiyun.com`)의 다섯 번째 권인 철근콘크리트 구조 교과서다. 배포 주소는 `https://construction.euiyun.com/concrete/`. 엔진·CSS·장 구성 규칙은 앞 권을 물려받았다. `js/common.js`는 MaterialsBook 엔진(구조 해석기 + 재료 모델 `CB.conc`, `CB.steel`)을 복사하고 **철근콘크리트 설계 함수** `CB.rc`(응력 블록, φ, 변형률 적합 휨강도, 소요 철근량, 전단, 정착, 균열 단면과 유효 단면 2차 모멘트, 균열 간격, P–M 상관도, 모멘트 확대)를 더했다. 본보기는 `../mechanics/chapters/beam-forces.html`, `../materials/chapters/mix-design.html`, `../structure/chapters/seismic.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 기준 조항·계수는 확인된 것만 쓴다(확실하지 않으면 "KDS 14 20 형태", "교육용", "현행 기준 확인"으로 표시한다).

## 구조

빌드 없이 열리는 정적 페이지다. `index.html` + `chapters/<slug>.html` + `css/style.css`(앞 권과 같고 강조색만 철근 청회색 `#4f5d75`, 보조색 안전 주황 `#e8590c`) + `js/common.js`(전역 `CB`, 장 목록 `CHAPTERS`). classic script만, 외부 라이브러리 없음(KaTeX는 빌드). 3D는 `CB.orbit`(배근 3D 장면에 적극 사용).

- 용어: 장의 용어를 `js/glossary/<slug>.json`(`{"ko","en","abbr","def","chapters":["<slug>"]}` 배열)에 적고 `tools/merge-glossary.py concrete`가 합친다. `en` 대문자 시작, `abbr` 밑줄 금지, 띄어쓰기 변형으로 같은 용어를 두 번 넣지 않는다(예: "인장 지배 단면", "유효 깊이", "스터럽"으로 통일). 앞 권 용어(탄성계수, 크리프 등)는 RC 설계 관점으로 정의하되 모순되지 않게.

## 원칙: 단면 → 변형률 → 힘 → 설계

철근콘크리트는 "균열이 생기는 재료(콘크리트)와 인장을 맡는 재료(철근)를 한 단면에 묶어, 변형률 적합과 평형으로 강도를 계산하고, 연성 있게 파괴되도록 설계하는" 학문이다. 이 책은 모든 설계식을 **단면을 그리고(단면·배근 그림) → 변형률 분포를 정하고 → 힘의 평형으로 강도를 계산하고(시뮬레이터, `CB.rc`) → 기준의 요구와 비교해 철근을 고르는** 순서로 쓴다. 공식을 외우게 하지 말고 변형률 적합에서 유도한다.

- 한국어, 대상은 건축·토목 3학년과 RC 설계를 다시 공부하는 신입 엔지니어(구조역학·건설재료·건축구조 앞 권을 안다고 가정, 링크).
- 장 첫머리는 `.origin`("이 계산이 없었다면"), 각 절은 가능하면 `.problem`.
- 흐름: 문제 → 그림(SVG) → **조작하는 시뮬레이터** → 정의·원리(KaTeX) → **손으로 푸는 설계 예제**(`.callout`, 단계별, 단위, 판정까지) → 기준 구조물 노트(`.callout.site`) → `.uses` → 핵심 정리 → 확인 퀴즈(8문항).
- 정의·원리는 `<div class="callout def"><strong>원리 3.2 (변형률 적합)</strong> …</div>`, 예제 `예제 3.1`, 그림 `그림 3-1.`. `.callout.deep`은 심화.
- 장마다 **시뮬레이터 7–8개, 그림 6개 이상, 퀴즈 8문항.** 시뮬레이터는 계산하는 모델. 단면 그림 위에서 철근을 끌어 놓거나 개수·호칭을 바꾸면 변형률도·응력 블록·강도·판정이 바로 바뀌는 것이 이 책의 기본 화면이다. 극단 입력에도 NaN·음수 철근량 없이 "단면 부족" 같은 판정 문구를 낸다.
- 설계 계산은 `CB.rc`로 한다(같은 식을 장마다 다시 구현하지 않는다). 부재력이 필요하면 `CB.beam`/`CB.frame`, 재료 성질은 `CB.conc`(Ec, fr, 크리프 등), 철근 규격은 `CB.steel.BARS`. 장 고유 모델(비틀림 박벽관, STM 절점, 프리스트레스 손실, 2축 휨 등)은 페이지 스크립트에 둔다.
- 색은 CSS 변수와 `CB.palette()`만. 라이트/다크 모두. 폭 360px 가로 스크롤 금지. SVG는 `viewBox`만, 폭 900 이하.
- 시뮬레이터 `id`는 `sim-<접두사>-<이름>`, 요소 id·전용 CSS 클래스도 접두사. 절 `id`는 의미 있는 영어 슬러그.

## 단위·부호·색 규약 (책 전체 공통)

**단위.** 단면 치수·철근·피복 mm, 단면적 mm², 응력·강도 MPa, 힘 kN, 모멘트 kN·m, 분포 하중 kN/m, 변형률 무차원(‰ 표기 가능). `CB.rc` 함수는 mm·MPa로 받고 kN·kN·m로 돌려준다(소스 주석 확인).

**부호.** 단면 해석에서는 **압축을 +**로 그리고(콘크리트 응력 블록·압축 철근), 인장 철근 변형률을 εt(양의 크기)로 말한다. 부재력은 MechanicsBook 규약(새깅 휨모멘트 +, 휨모멘트도는 인장측)을 따른다. P–M 상관도는 압축 P를 위 +, M을 오른쪽 +로 그린다.

**색.** 콘크리트 압축 블록 `compression`(빨강) 반투명, 인장 철근·인장 변형률 `tension`(파랑), 압축 철근 `compression`, 스터럽·띠철근 `accent`, 균열 `text-dim` 선, 하중 `accent2`, 판정 합격 `ok`·불합격 `bad`, 균형점·한계선 `warn` 점선. 단면 그림은 콘크리트 회색(`surface-2`) 바탕에 철근 원.

**01 철근콘크리트의 원리** — 콘크리트는 압축에 강하고 인장에 약하다(fr ≈ 압축의 1/10) / 철근을 넣는 자리와 이유 / 두 재료가 함께 일하는 조건: 부착, 비슷한 열팽창계수, 알칼리 환경 / RC의 역사(모니에·에네비크 등 확인된 사실만) / 보의 하중–처짐 거동 단계: 균열 전(탄성) → 균열 후 탄성 → 항복 → 극한, 각 단계의 변형률·응력 분포 / 연성 파괴와 취성 파괴(과소·과다 철근) / 균열은 결함이 아니라 설계의 일부 / RC 구조 형식과 부재 종류 / 기준 부재 G1·C1 소개와 이 책의 지도. 시뮬: 보 재하 실험(하중 올리기 → 균열 전파 그림·하중–처짐 곡선·단계 표시, `CB.rc.crack`·`flexure`), 단면 응력 분포 단계별(모멘트 슬라이더 → 균열 전/후/항복/극한 변형률·응력도), 철근 위치 실험(철근을 위·가운데·아래로 끌기 → 강도 비교), 과소·균형·과다 철근 파괴 모드(철근량 → 파괴 애니메이션과 연성 지수), 무근 vs 철근 콘크리트 보(같은 하중에서 파괴 하중 비), B-10 3D 배근 장면(`CB.orbit`: G1·C1 철근 켜기), 재료 곡선 겹치기(`CB.conc.sigma`, `CB.steel.sigma`).
**02 강도 설계의 기초** — 설계 철학: 허용 응력 설계 → 강도 설계(한계상태) / 소요 강도 U(하중 조합, StructureBook 2장 연결)와 설계 강도 φSn / 강도 감소 계수 φ와 εt(`CB.rc.phi`) / 기본 가정: 평면 유지, 철근과 콘크리트 변형률 같음, 콘크리트 인장 무시, εcu, 철근 탄성–완전 소성 / 콘크리트 압축 응력 분포 → 등가 직사각형 응력 블록(η·0.85fck, β₁, `CB.rc.block`)과 그 근거(합력·작용점 같게) / 변형률 적합과 힘의 평형으로 중립축 구하기 / 인장 지배·변화 구간·압축 지배 단면, 최소 허용 인장 변형률(`etMin`) / 균형 철근비(`rhoB`) / 고강도 콘크리트에서 블록 계수 변화. 시뮬: 응력 블록 근거(포물선–직선 분포 vs 등가 직사각형: 합력·작용점 비교, `CB.conc.sigma`), 블록 계수 탐색(fck 슬라이더 → εcu·η·β₁), 변형률 적합 끌기(중립축 깊이 c 끌기 → C·T 막대, 평형될 때까지), φ 곡선(εt → φ, 구간 색칠), 하중 조합과 설계 강도 비교(소요 vs 설계 막대), 신뢰도 맛보기(φ와 하중 계수가 파괴 확률에 미치는 영향), 블록 깊이 a와 c의 관계.
**03 단철근 직사각형 보의 휨** — 공칭 휨강도 유도 Mn = As fy (d − a/2) / 철근이 항복하는지 확인(εs ≥ εy) / 철근비와 파괴 형태, 균형·최대·최소 철근(`asMin`, εt,min) / 설계 순서: 단면 가정(h ≈ L/12 등) → 소요 As(`asReq`) → 철근 선택(`CB.steel.BARS`) → 배치·순간격·피복(MaterialsBook 11장 연결) → 강도·εt 확인 / 유효 깊이와 2단 배근 / 단면 크기 vs 철근량의 경제성 / G1 정모멘트 설계(Mu⁺ 460 → 4-D25), 단순보 근사 7-D25와 비교. 시뮬: 단면 휨강도 계산기(b·h·d·철근 개수·호칭 → a, c, εt, φMn, 판정, 단면에 변형률도·응력 블록, `CB.rc.flexure`), 철근비 슬라이더(ρ → Mn, φ, 파괴 모드 구간 색), 소요 철근 설계기(Mu·b·d → As 소요 → 철근 조합 후보 표·순간격 검토, `asReq`), 단면 크기 최적화(h 바꾸기 → 철근량·콘크리트량·비용), 2단 배근 효과(d 감소 → 강도), 최소 철근 이유(균열 모멘트 vs 공칭 강도, `crack`), G1 정모멘트 단면 설계 마법사.
**04 복철근 보와 T형 보** — 압축 철근이 필요한 경우(단면 제한, 장기 처짐, 연성, 지점 부모멘트) / 압축 철근의 변형률과 항복 여부 확인, 변형률 적합 일반해(`flexure`의 층별 철근) / 연속보 지점의 부모멘트와 상하 배근 / T형 보: 슬래브와 일체, 유효 폭(기준 형태: 경간/4, 복부 + 16t 등 — 확실한 규칙만), a가 플랜지 안 vs 복부까지(`bf`, `hf`) / 부모멘트 구간에서는 직사각형 / L형 보 / G1 지점 부모멘트(Mu⁻ 640 → 6-D25)와 중앙 T형 보 효과. 시뮬: 복철근 단면(압축 철근 개수·위치 → 압축 철근 응력·항복 여부·φMn·εt), 압축 철근의 연성 효과(As′ 늘리기 → εt 증가 곡선), T형 보 계산기(bf·hf·As → a 위치 판정, 응력 블록 그림, `flexure` bf·hf), 유효 폭 규칙 비교(경간·보 간격·슬래브 두께 → 후보값과 최솟값), 연속보 모멘트 포락선과 배근(`CB.beam` 연속 3경간 → 정·부모멘트에 필요한 As 분포), 절단점 맛보기(7장 연결), G1 전체 배근도(상하 철근 길이 방향 그림).
**05 전단과 사인장 균열** — 보의 전단 응력과 주응력 궤적(MechanicsBook 10장 연결) / 휨 균열·휨–전단 균열·복부 전단 균열 / 스터럽이 없는 보의 전단 파괴(a/d의 영향, 전단 계곡) / 콘크리트 전단강도 Vc = (1/6)λ√fck bw d(`Vc`), 정밀식 맛보기 / 트러스 모형: 45° 압축 스트럿 + 스터럽 인장 / 스터럽 설계 Vs = Av fyt d/s(`Vs`), 상한(`VsMax`), 최소 전단 철근(`avMinPerS`), 최대 간격(d/2, 600 mm 형태) / 위험 단면(지점에서 d) / 경사 스터럽·굽힘 철근 / 깊은 보 맛보기(14장) / G1 전단 설계(Vu 400 kN). 시뮬: 주응력 궤적과 균열 방향(하중 위치 → 궤적 그림), 전단 경간비 실험(a/d → 파괴 모드·강도, 전단 계곡 곡선, 교육용), 트러스 모형 애니메이션(스터럽 간격 → 스트럿과 타이 힘), 전단 설계기(Vu 분포 위에 φVc·φ(Vc+Vs) 계단, 스터럽 간격 구간 결정, `CB.beam` 전단력도), 스터럽 간격 계산기(Vu·bw·d → s 소요, 최소·최대 규정 판정), 단면 크기 한계(Vs,max 초과 판정), G1 전단 배근도(구간별 간격).
**06 비틀림** — 비틀림이 생기는 곳(가장자리 보, 캔틸레버 슬래브, 곡선 보) / 평형 비틀림과 적합 비틀림 / 균열 전: 박벽관 유추 τ = T/(2A₀t)(MechanicsBook 10장 연결) / 균열 비틀림 모멘트 Tcr, 무시해도 되는 한계(Tcr/4 형태) / 균열 후 입체 트러스 모형: 폐쇄 스터럽 At/s = Tn/(2A₀ fyt cotθ), 종방향 철근 Al / 전단과 비틀림 조합, 단면 크기 제한 / 상세: 폐쇄 스터럽 135° 갈고리, 모서리 종철근 / B-10 가장자리 보(슬래브 끝 부모멘트가 만드는 비틀림). 시뮬: 박벽관 전단 흐름(단면 형상 → A₀·전단 흐름·τ 그림), 균열 비틀림(단면 → Tcr, 무시 한계 판정), 입체 트러스(θ 각도 → 스터럽·종철근 양 비교), 비틀림 철근 설계기(Tu·Vu → At/s + Av/s, Al, 단면 한계), 평형 vs 적합 비틀림(가장자리 보 강성 → 슬래브 모멘트 재분배, `CB.frame` 맛보기), 폐쇄 스터럽 상세 3D(`CB.orbit`), 개방형 vs 폐쇄형 스터럽 효과.
**07 정착과 이음** — 부착 메커니즘(MaterialsBook 11장 연결)과 부착 응력 / 정착 길이 ld: 기본식 ldb = 0.6 db fy/(λ√fck)(`ldb`), 보정 계수(위치·도막·크기, 확실한 것만) / 표준 갈고리 ldh(`ldh`)와 갈고리 상세 / 압축 철근 정착 / 철근 절단점: 이론 절단점 + 연장 길이(d 또는 12db 형태), 정모멘트 철근의 지점 연장 / 겹침 이음 A급·B급(1.0·1.3 ld 형태), 이음 위치, 기계식·용접 이음 / 다발 철근 / G1 상하 철근의 절단과 이음 계획. 시뮬: 부착 응력 분포(정착 길이 → 철근 응력 증가 곡선, 뽑힘·쪼갬), 정착 길이 계산기(db·fy·fck·보정 → ld, 막대 비교), 갈고리 vs 직선 정착(공간 제약 → 선택), 절단점 결정기(모멘트도 위 철근 개수 계단 + 연장 길이, `CB.beam`), 겹침 이음 위치 고르기(모멘트도 위 이음 위치 → A/B급 판정), 철근 응력 전달 애니메이션(이음 구간 힘 흐름), 다발 철근 효과.
**08 처짐과 균열** — 사용성 한계(StructureBook 15장 연결) / 균열 단면 해석: 환산 단면, n = Es/Ec, 중립축 kd, Icr(`crack`) / 균열 모멘트 Mcr / 유효 단면 2차 모멘트(브랜슨, `Ie`) / 즉시 처짐(`CB.beam`에 EIe) / 장기 처짐 λΔ = ξ/(1 + 50ρ′)(`lambdaD`), 크리프·수축(MaterialsBook 8장) / 처짐 제한과 최소 두께(L/16 등 표 형태, 확인) / 균열 폭: 영향 인자(철근 응력·피복·간격), 균열 제어 간격(`sMax`), 피막·노출 조건 / 수축·온도 철근 / G1 처짐(Ma 350 kN·m)과 균열 간격 검토. 시뮬: 균열 단면 계산기(As·n → kd·Icr, 환산 단면 그림), Ie 곡선(Ma/Mcr → Ie/Ig, 브랜슨 지수), 하중–처짐 곡선(하중 증가 → 균열 전 강성 → 감소, 즉시 처짐, `CB.beam`), 장기 처짐 시간 곡선(ξ·ρ′ → 처짐 증가), 최소 두께 검토(경간·지지 조건 → h_min 판정), 균열 간격 검토기(fs·cc → s_max, 철근 배치 그림 판정), 균열 폭 영향 인자(교육용 Gergely–Lutz 형태 식, 출처 형태 명시).
**09 슬래브** — 슬래브의 종류(1방향·2방향·플랫 플레이트·플랫 슬래브·와플) / 1방향 슬래브: 단위 폭 보로 설계, 근사 모멘트 계수(연속, 형태), 최소 두께, 수축·온도 철근, 최대 간격 / 2방향 슬래브: 직접 설계법(StructureBook 3장 연결), 정적 모멘트 M₀ 분배, 주열대·중간대, 테두리 보 / 뚫림 전단: 임계 둘레 b₀(d/2), vc 식(형태), 전단 머리·스터드 레일 / 슬래브 개구부 / B-10 210 mm 슬래브 배근(D13 @ 간격). 시뮬: 1방향 슬래브 설계기(경간·하중·두께 → 모멘트 계수 → 철근 간격, 단위 폭 단면), 2방향 모멘트 분배(장단변비·테두리 보 강성 → 주열대/중간대 모멘트 막대 → 철근 간격), 뚫림 전단 검토(기둥 크기·d·위치 → b₀·vu·φvc, 전단 보강 선택), 수축·온도 철근(두께 → 최소 철근비·간격), 슬래브 배근 평면도(상·하단 철근 영역 그림), 개구부 영향(개구부 위치 → 임계 둘레 감소), 처짐 최소 두께 표 탐색.
**10 기둥과 P–M 상관도** — 기둥의 종류(띠·나선·합성), 축하중만 받는 기둥 P₀ = η0.85fck(Ag − Ast) + fy Ast, 최대 설계 축력 0.80·0.85 제한(`pm` PnMax) / 띠철근·나선 철근의 역할과 간격, 나선의 구속 효과 / 편심 하중과 변형률 적합 / P–M 상관도 만들기: 중립축 깊이를 바꿔 가며 점 찍기(`pm`), 균형점(`bal`), 압축 지배·인장 지배 구간, φ 전이 / 철근비 한계(1–8 % 형태) / 2축 휨(브레슬러 상반 하중법 형태) 맛보기 / C1(800 × 800, 16-D25) 검토: Pu 9,000 kN·Mu 300 kN·m. 시뮬: P–M 상관도 만들기 애니메이션(c를 줄여 가며 점이 찍히고 단면 변형률도가 같이 바뀜, `CB.rc.pm`), 하중점 끌기(Pu·Mu 점 끌기 → 안/밖 판정, 안전율), 철근 배치·비 바꾸기(면당 개수·호칭 → 상관도 변화), 띠 vs 나선(φ·PnMax 차이 비교), 중심 축하중 계산(P₀ 성분 막대), 2축 휨 상호작용 면(교육용 브레슬러, `CB.orbit` 3D 면), C1 층별 검토(1층~10층 Pu·Mu → 철근 줄이기 가능 층).
**11 장주와 모멘트 확대** — 단주와 장주, 세장비 kLu/r(`slender`)와 단주 한계(34 − 12M₁/M₂ 형태) / 유효 길이 계수 k와 골조 강성(정렬 도표 개념) / 비횡이동 골조의 모멘트 확대 δns = Cm/(1 − Pu/0.75Pc)(`magnifier`), Cm, EI 산정(0.4EcIg/(1+βdns)) / 횡이동 골조의 δs, 안정 지수 Q / P–Δ 2차 해석(StructureBook 4장 연결) / 최소 모멘트(편심 최소값 형태) / 상관도 위에서 확대 모멘트가 점을 옮기는 모습 / C1(Lu 4.3 m, kLu/r ≈ 18 → 단주)과 가늘게 바꾼 가상 기둥. 시뮬: 세장비 판정기(k·Lu·h·M₁/M₂ → 단주/장주), 모멘트 확대 계산기(Pu/Pc → δns 곡선, `magnifier`), 상관도 위 하중점 이동(확대 전·후 점, `pm`), 정렬 도표 근사(기둥·보 강성 비 → k, 교육용 근사식), 좌굴 모드 그림(비횡이동 vs 횡이동, MechanicsBook 13장 연결), 2차 해석 비교(`CB.frame`으로 반복 P–Δ vs 확대 계수), 가늘어지는 기둥(h 줄이기 → 장주 전환·강도 감소).
**12 벽체와 내진 상세** — 내진 설계에서 RC의 역할(StructureBook 8장 연결): 연성과 상세 / 전단벽: 휨·축력(P–M 개념), 전단강도 Vn = Acv(αc λ√fck + ρt fy) 형태, 최소 수평·수직 철근 / 경계 요소: 변위 기반 판정 형태, 횡구속 / 특수 모멘트 골조 상세: 보(최소 철근, 정·부 강도 비, 스터럽 간격 d/4·6db 형태), 기둥(강기둥–약보, 띠철근 간격 소성 힌지 구간), 접합부 전단 / 135° 갈고리와 크로스타이 / 연결보 대각 철근 / 필로티 기둥 / B-10 코어 전단벽(400 mm) 검토. 시뮬: 전단벽 전단강도(벽 길이·두께·수평 철근비 → Vn, 판정), 경계 요소 필요 여부(변위·중립축 깊이 → 판정, 교육용 형태), 띠철근 구속 효과(간격 → 구속 콘크리트 응력–변형률, 만더 모형 교육용), 특수 모멘트 골조 보 상세 검토기(철근·스터럽 → 규정 체크리스트), 강기둥–약보 검토(ΣMnc/ΣMnb, `flexure`·`pm`), 연결보 대각 철근(경사각 → 전단 저항), 상세 3D(`CB.orbit`: 접합부 철근 배치).
**13 기초** — 기초의 종류와 선택(GeotechBook 13–14장 연결) / 독립 기초: 크기(사용 하중/허용 지지력), 계수 접지압, 1방향 전단(d 위치), 2방향(뚫림) 전단(d/2), 휨(기둥면), 철근 정착, 기둥–기초 하중 전달(지압) / 줄기초·복합 기초(강성 기초 가정의 접지압) / 말뚝 기초: 말뚝 머리 반력, 기초판 펀칭(말뚝·기둥), 말뚝 캡 / 전면 기초(매트) 개념 / B-10 C1 아래 말뚝 5본 캡 검토(GeotechBook 14장: 1,340 kN/본). 시뮬: 독립 기초 설계기(하중·허용 지지력 → 크기 → 두께(전단) → 철근(휨) 단계 진행, 판정 색), 1방향·2방향 전단 위험 단면 그림(두께 바꾸기 → 둘레·전단력), 편심 하중 접지압(e → 사다리꼴/삼각형, StructureBook·GeotechBook 연결), 복합 기초 접지압과 휨모멘트도(`CB.beam` 탄성 지반 근사 또는 등분포), 말뚝 캡 반력 분배(편심 → 말뚝별 반력), 말뚝 캡 펀칭(말뚝 간격·캡 두께), 기둥–기초 지압 검토.
**14 스트럿–타이 모델** — B 영역과 D 영역(생브낭 원리), D 영역에서는 평면 유지가 성립하지 않는다 / 스트럿–타이 모델의 구성: 스트럿(콘크리트 압축), 타이(철근), 절점(CCC·CCT·CTT) / 강도: 스트럿 유효 강도 0.85βs fck, 절점 βn(형태, 확실한 값만) / 모델 고르기: 하중 경로법, 탄성 응력 궤적 따르기 / 깊은 보(L/h < 4 형태), 코벨(내민 받침), 보의 개구부, 기둥 머리, 말뚝 캡 / 최소 철근과 균열 제어 / B-10 지하 깊은 보 또는 13장의 말뚝 캡을 STM으로. 시뮬: B·D 영역 응력 궤적(하중 위치 → 응력 흐름 그림), STM 트러스 해석(절점 끌기 → 부재력, `CB.truss`), 깊은 보 STM(경간/깊이 → 스트럿 각도·타이 힘, 판정), 코벨 설계(하중·편심 → 타이 철근), 절점 강도 검토(절점 종류 → 허용 응력), 개구부 주변 하중 경로, 말뚝 캡 STM 3D 맛보기(`CB.orbit`).
**15 프리스트레스트 콘크리트** — 원리: 미리 압축을 주어 인장을 없앤다(프레시네 등 확인된 사실만) / 프리텐션과 포스트텐션, 부착·비부착 / 긴장재(강연선 강도, 확인) / 응력 계산: f = −P/A ± Pe/S ∓ M/S, 전달 시·사용 시, 허용 응력(형태) / 하중 평형법(포물선 텐던 상향력 8Pe/L²) / 핵 거리와 편심 한계, 텐던 배치 영역 / 손실: 탄성 수축, 정착 활동, 마찰, 크리프·수축·릴랙세이션(MaterialsBook 8장) / 공칭 휨강도(fps 근사 형태) / 장경간 바닥·교량 거더 / 교육용 PSC 보 예제. 시뮬: 응력 분포 계산기(P·e·M → 상하연 응력, 단계별 그림, `CB.section`), 하중 평형(텐던 처짐 → 상향 등분포, 순 하중), 텐던 배치 영역(경간 따라 편심 상하한 → 허용 영역 그림, 텐던 끌기), 손실 막대(초기 → 유효 긴장력 단계별), 프리텐션 vs 포스트텐션 애니메이션, PSC vs RC 같은 경간 단면 크기 비교, 처짐 캠버(긴장 → 솟음 + 하중 처짐, `CB.beam`).
**16 B-10 설계 실습** — 앞 장을 하나의 설계 흐름으로: 하중 집계(StructureBook 2장) → 해석(`CB.beam` 연속보, 횡하중 조합) → G1 휨(정·부) → 전단 → 처짐·균열 → 정착·절단 → C1 P–M → 슬래브 → 기초(말뚝 캡) → 배근도와 철근 물량(MaterialsBook 11장의 물량 산출과 비교) → 검토 체크리스트 / 설계 결과 요약표 / 흔한 실수와 검증 / 단순보 근사(7-D25)와 연속보 설계(4-D25/6-D25)의 차이, 철근 물량 차이. 시뮬: G1 전 과정 설계 계산서(입력 하나 바꾸면 모든 단계가 연쇄 재계산되는 단계 카드), 연속보 모멘트 포락선 + 배근 계단(`CB.beam`, 패턴 재하), C1 층별 P–M 검토 표(`pm`), 철근 물량 산출(배근 → 길이·질량, 층당 합계), 설계 대안 비교(fck·fy·단면 → 콘크리트·철근·비용·탄소), 체크리스트 게임(일부러 틀린 설계 찾기), 3D 배근도(`CB.orbit`: G1–C1 접합부).
**17 용어집 & 종합 퀴즈** — 설계식 한눈표(응력 블록, φ, 휨·전단·비틀림·정착·처짐·균열·기둥·장주·STM·PSC 식, G1·C1 설계 결과), 부호 규약, 용어 검색, 종합 퀴즈. `../structure/chapters/glossary.html` 구조를 따른다.

## JS 헬퍼 (`js/common.js`, 전역 `CB`)

화면·컨트롤·차트·좌표 평면·구조 해석은 `../mechanics/CONTRIBUTING.md`의 "JS 헬퍼"와 같고, 재료 모델 `CB.conc`·`CB.steel`은 `../materials/CONTRIBUTING.md`와 같다. 시그니처는 반드시 `js/common.js` 소스에서 확인한다.

철근콘크리트 설계(이 책에서 더함; 입력 mm·MPa, 출력 kN·kN·m):

```js
CB.rc.Es;                                     // 200,000 MPa
CB.rc.block(fck);                             // { ecu, eta, beta1 }  (30 MPa → 0.0033, 1.00, 0.80)
CB.rc.phi(et, fy, spiral);                    // 강도 감소 계수
CB.rc.etMin(fy);                              // 휨부재 최소 허용 인장 변형률 max(0.004, 2εy)
CB.rc.flexure({ b, h, fck, fy, layers: [{ d, As }], bf, hf });   // { c, a, Mn, phi, phiMn, et, es[], ok, rho, block }
CB.rc.asReq(Mu, b, d, fck, fy);               // 소요 As (mm²), NaN이면 단면 부족
CB.rc.asMin(bw, d, fck, fy); CB.rc.rhoB(fck, fy);
CB.rc.Vc(fck, bw, d, lambda); CB.rc.Vs(Av, fyt, d, s); CB.rc.VsMax(fck, bw, d); CB.rc.avMinPerS(fck, bw, fyt);   // kN, mm²/mm
CB.rc.ldb(db, fy, fck, lambda); CB.rc.ldh(db, fy, fck, lambda, beta);                                        // mm
CB.rc.crack({ b, h, d, As, d2, As2, fck });   // { n, Ec, Ig, kd, Icr, fr, Mcr (kN·m), yt }
CB.rc.Ie(Mcr, Ma, Ig, Icr); CB.rc.lambdaD(xi, rhoP); CB.rc.sMax(fs, cc, dry);
const pm = CB.rc.pm({ b, h, fck, fy, layers: [{ d, As }], spiral });   // { pts: [{ c, Pn, Mn, phi, phiPn, phiMn, et }], P0, PnMax, phiPnMax, bal, at(c) }
CB.rc.magnifier({ fck, Ig, k, Lu, Pu, Cm, betaD });   // { EI, Pc, Cm, delta }
CB.rc.slender(k, Lu, h);
CB.rc.bars(n, "D25");                          // n × 공칭 단면적
CB.rc.REF;                                     // { G1: {...}, C1: {...} } 기준 부재
```

`CB.rc`를 고쳤으면 `node tools/concrete.test.cjs`(`npm test`에 포함)를 다시 돌린다. 공통 함수를 더하면 이 표와 검사에도 더한다.

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `concrete/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
