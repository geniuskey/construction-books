Chapter 14

부정정 구조와 응력법

단순보에 지점을 하나 더 받치면 보는 덜 휘고 덜 처집니다. 그런데 계산은 갑자기 막힙니다. 반력은 네 개인데 평형 방정식은 세 개뿐이라, 힘의 평형만으로는 반력을 하나로 정할 수 없기 때문입니다. 이런 구조를 부정정 구조라 합니다. 부족한 방정식은 "구조물은 끊어지거나 지점에서 떨어지지 않는다"는 변형의 조건, 곧 적합 조건에서 얻습니다. 실제 건물의 보와 기둥, 연속 다리, 라멘은 거의 모두 부정정입니다. 이 장에서는 여분의 힘(여유력)을 하나 골라 떼어 냈다가 변형이 맞도록 되돌려 놓는 응력법으로 부정정 구조를 풀고, 부정정 구조가 정정 구조와 무엇이 다른지 — 지점 침하에 응력이 생기고, 강한 쪽이 힘을 더 받고, 부재 하나가 끊어져도 버틸 수 있다는 것 — 를 숫자로 확인합니다.

  • 보·라멘·트러스의 부정정 차수를 세고, 차수가 0 이상이어도 불안정할 수 있는 경우를 구별한다.
  • 여유력을 골라 기본 구조물(정정)을 만들고, 적합 조건 \(\delta_{10} + f_{11}X_1 = 0\)으로 여유력을 구한다.
  • 1단 고정보와 2경간 연속보를 응력법으로 풀고, 3연모멘트식으로 기준 건물 B-10의 4경간 큰보를 푼다.
  • 지점 침하와 온도 변화가 정정 구조에서는 응력을 만들지 않지만 부정정 구조에서는 만든다는 것을 계산으로 보인다.
  • 부정정 구조에서 힘이 강성에 비례해 나뉜다는 것을 교차보와 스프링으로 설명한다.
  • 여유도와 대체 하중 경로의 뜻을 알고, 정정 구조와 부정정 구조의 장단점을 비교한다.
이 계산이 없었다면지점이 많은 다리를 평형만으로 풀려던 시대

19세기 철도가 퍼지면서 강을 여러 경간으로 건너는 다리가 늘었습니다. 경간마다 보를 따로 놓는 대신 여러 지점 위로 한 줄의 보를 이어 놓으면 재료가 훨씬 덜 듭니다. 문제는 계산이었습니다. 지점이 셋 이상인 연속보는 평형 방정식만으로는 반력이 정해지지 않습니다. 프랑스의 클라페이롱이 1857년에 연속보의 지점 모멘트를 잇는 3연모멘트식을 발표했고, 영국의 맥스웰(1864)과 독일의 모어(1874) 등이 "변형이 서로 맞아야 한다"는 조건으로 부정정 트러스를 푸는 방법을 정리했습니다. 오늘날 응력법(유연도법)이라 부르는 방법의 뿌리입니다.

오늘의 구조 해석 프로그램은 16장의 강성법으로 수천 개의 미지수를 한꺼번에 풀지만, 그 결과가 맞는지 판단하는 감각은 이 장에서 나옵니다. 연속보 중간 지점의 반력이 왜 단순보 두 개일 때보다 큰지, 기초가 1 cm 가라앉으면 보에 무슨 일이 생기는지, 왜 다리 한쪽 끝에는 굴러가는 받침을 두는지가 모두 적합 조건의 이야기입니다.

평형 방정식이 모자람→여유력을 떼어 내고 변형 계산→적합 조건으로 여유력 결정→연속보·라멘·침하·온도

부정정 차수: 미지수와 방정식의 수

반력 넷, 방정식 셋

B-10 입구 캐노피의 캔틸레버(4장 예제 4.4) 끝에 기둥을 하나 세워 받치면 고정단의 반력 셋(수평력·연직력·모멘트)에 기둥 반력 하나가 더해져 미지수가 넷이 됩니다. 평면 구조물의 평형 방정식은 \(\Sigma F_x = \Sigma F_y = \Sigma M = 0\) 셋뿐입니다. 미지수 하나는 어디서 구할까요?

평면 구조물 전체에 대해 쓸 수 있는 독립 평형 방정식은 세 개입니다. 반력 성분이 세 개보다 많으면 그 여분은 평형만으로는 정해지지 않습니다. 내부 힌지가 있으면 "힌지에서 \(M = 0\)"이라는 조건이 하나씩 더해지므로 여분이 줄어듭니다(4장의 게르버보). 이 여분의 개수가 부정정 차수입니다.

정의 14.1 (부정정 차수) 평면 구조물에서 평형 조건만으로 정해지지 않는 미지 힘의 개수를 부정정 차수(degree of static indeterminacy) \(n\)이라 한다.
  • 곧은 보: \(n = r - 3 - c\) (\(r\): 반력 성분 수, \(c\): 내부 힌지 수).
  • 라멘(골조): \(n = (3m + r) - (3j + c)\) (\(m\): 부재 수, \(j\): 절점 수, \(c\): 힌지가 풀어 주는 조건 수).
  • 트러스: \(n = m + r - 2j\) (3장의 판별식).
\(n = 0\)이면 정정, \(n \gt 0\)이면 \(n\)차 부정정, \(n \lt 0\)이면 반드시 불안정이다. 단, \(n \ge 0\)은 안정의 필요조건일 뿐이다. 반력이 모두 한 점을 지나거나 모두 나란하면 \(n \ge 0\)이어도 기하학적 불안정이다.

아래에서 지점과 힌지를 바꿔 보세요. 계산된 차수와 함께, 강성법 해석기(16장)가 실제로 풀리는지(안정인지)도 표시합니다. 롤러만 셋 둔 보는 \(n = 0\)인데도 수평으로 미끄러지는 기구라서 풀리지 않습니다.

여유력과 적합 조건

1단 고정보(왼쪽 고정, 오른쪽 롤러)를 생각해 봅시다. 미지 반력은 넷, 차수는 1입니다. 응력법의 생각은 단순합니다. 반력 하나를 골라 떼어 내면 남은 구조물은 정정이 되어 풀 수 있습니다. 떼어 낸 반력은 모르는 하중 \(X\)로 다시 걸어 둡니다. 원래 구조물에서 그 반력이 있던 점은 움직이지 않았으므로, \(X\)는 "그 점의 변위를 0으로 되돌리는 크기"여야 합니다.

정의 14.2 (여유력·기본 구조물·적합 조건) 부정정 구조물에서 떼어 내도 구조물이 안정하게 남는 반력이나 단면력을 여유력(redundant)이라 하고, 여유력을 모두 떼어 낸 정정 구조물을 기본 구조물(primary structure)이라 한다. 원래 구조물에서 여유력 방향의 변위(또는 회전)가 가져야 할 값, 보통 0을 나타내는 조건을 적합 조건(compatibility condition)이라 한다.
원리 14.3 (응력법, 유연도법) \(n\)차 부정정 구조물에서 여유력 \(X_1, \dots, X_n\)을 골라 기본 구조물을 만든다. 기본 구조물에 실제 하중만 걸었을 때 여유력 \(i\) 방향의 변위를 \(\delta_{i0}\), 여유력 \(j\)에 단위 힘을 걸었을 때 \(i\) 방향 변위를 \(f_{ij}\)(유연도 계수)라 하면, 중첩과 적합 조건에서
$$\sum_{j=1}^{n} f_{ij} X_j = \Delta_i - \delta_{i0} \quad (i = 1, \dots, n), \qquad \text{행렬로 } [F]\{X\} = \{\Delta\} - \{\delta_0\}$$
\(\Delta_i\)는 원래 구조물에서 그 점의 실제 변위(지점이면 0, 침하가 있으면 그 값). 맥스웰-베티 상반 정리(12장)에 따라 \(f_{ij} = f_{ji}\)이므로 유연도 행렬 \([F]\)는 대칭이다.
여유력을 구한 뒤의 단면력·반력은 중첩으로 얻는다: \(M = M_0 + \sum_j m_j X_j\) (\(M_0\): 기본 구조물의 하중 모멘트, \(m_j\): 단위 여유력의 모멘트).
예제 14.1 (1단 고정보, 등분포 하중) 경간 \(L = 6\) m, 왼쪽 A 고정, 오른쪽 B 롤러, 등분포 하중 \(w = 12\) kN/m, \(EI\) 일정.
  1. 여유력. B의 롤러 반력 \(X_1 = R_B\)(위 +)를 고른다. 기본 구조물은 A에 고정된 캔틸레버다.
  2. 기본 구조물의 처짐. 등분포 하중에 의한 끝 처짐 \(\delta_{10} = -wL^4/(8EI) = -12 \times 1296/(8EI) = -1944/EI\). 끝에 위 방향 단위 힘을 걸면 \(f_{11} = L^3/(3EI) = 72/EI\).
  3. 적합 조건. \(-1944/EI + (72/EI)X_1 = 0\) → \(X_1 = R_B = 27\) kN \(= 3wL/8\).
  4. 나머지는 평형. \(R_A = wL - R_B = 72 - 27 = 45\) kN, \(M_A = R_B L - wL^2/2 = 162 - 216 = -54\) kN·m \(= -wL^2/8\).
  5. 양의 최대 모멘트. B에서 \(u\)만큼 떨어진 곳의 \(M = R_B u - wu^2/2\)은 \(u = R_B/w = 2.25\) m(A에서 3.75 m)에서 최대 \(9wL^2/128 = 30.4\) kN·m.
검산: A의 고정단 모멘트 대신 A의 회전을 여유력으로 골라도(아래 시뮬레이터) 같은 답이 나온다.

연속보와 3연모멘트식

2경간 연속보는 차수 1이므로 가운데 지점 반력 \(R_B\)를 여유력으로 고르면 기본 구조물은 경간 \(2L\)인 단순보가 됩니다. 단순보 한가운데의 처짐과 한가운데 단위 힘에 의한 처짐은 11장의 공식으로 바로 씁니다.

예제 14.2 (같은 두 경간, 등분포 하중) 경간 \(L = 8\) m 두 개, 전체에 \(w = 10\) kN/m.
  1. 기본 구조물. 경간 \(2L = 16\) m 단순보. 가운데 처짐 \(\delta_{10} = -5w(2L)^4/(384EI)\), 가운데 위 방향 단위 힘에 의한 처짐 \(f_{11} = (2L)^3/(48EI)\).
  2. 적합 조건. \(R_B = -\delta_{10}/f_{11} = \dfrac{5w(2L)^4/384}{(2L)^3/48} = \dfrac{5}{8}w(2L) = 1.25wL = 100\) kN.
  3. 평형. \(R_A = R_C = (2wL - R_B)/2 = 0.375wL = 30\) kN.
  4. 지점 모멘트. \(M_B = R_A L - wL^2/2 = 240 - 320 = -80\) kN·m \(= -wL^2/8\). 경간 최대는 A에서 \(0.375L = 3\) m 떨어진 곳의 \(+9wL^2/128 = 45\) kN·m.
경간마다 단순보로 따로 놓았다면 가운데 지점 반력은 \(wL = 80\) kN, 경간 최대 모멘트는 \(wL^2/8 = 80\) kN·m였다. 연속성 덕분에 경간 모멘트가 45로 줄고, 대신 지점 위에 −80이 생긴다.

경간이 셋 이상이면 여유력도 여럿이라 연립 방정식이 됩니다. 이때 중간 지점의 반력 대신 중간 지점 위 휨모멘트를 여유력으로 고르면 식이 특히 깔끔해집니다. 지점마다 보를 잘라 힌지를 넣으면 기본 구조물은 단순보의 줄이 되고, 적합 조건은 "지점 양쪽 보의 처짐각이 같다(보가 꺾이지 않는다)"가 됩니다.

원리 14.4 (3연모멘트식) 연속보의 이웃한 세 지점 \(A, B, C\)(높이 같음)의 지점 모멘트 \(M_A, M_B, M_C\)(새깅 +)와 경간 \(L_1 = AB\), \(L_2 = BC\) 사이에는, \(EI\)가 일정할 때
$$M_A L_1 + 2M_B (L_1 + L_2) + M_C L_2 = -\frac{6 A_1 \bar{a}_1}{L_1} - \frac{6 A_2 \bar{b}_2}{L_2}$$
\(A_1, A_2\): 각 경간을 단순보로 보았을 때의 휨모멘트도 넓이, \(\bar a_1\): \(A_1\)의 도심에서 A까지 거리, \(\bar b_2\): \(A_2\)의 도심에서 C까지 거리. 등분포 하중 \(w\)이면 \(6A\bar a/L = wL^3/4\), 경간 가운데 집중 하중 \(P\)이면 \(3PL^2/8\).
이 식을 중간 지점마다 하나씩 쓰면 미지 지점 모멘트와 같은 개수의 방정식이 된다.
4경간 연속 큰보 G1 기준 건물 B-10의 큰보 G1은 X 방향으로 8 m × 4경간이 이어집니다. 기둥의 휨 강성을 무시하고 모든 경간에 \(w_u = 100\) kN/m가 걸린 연속보로 보면, 끝 지점 모멘트가 0이므로 3연모멘트식 세 개는 \(q = wL^2/2 = 3200\) kN·m로
$$4M_1 + M_2 = -q, \quad M_1 + 4M_2 + M_3 = -q, \quad M_2 + 4M_3 = -q$$
대칭(\(M_1 = M_3\))을 쓰면 \(M_1 = -3q/14 = -686\) kN·m, \(M_2 = -q/7 = -457\) kN·m입니다(\(-0.107wL^2\), \(-0.071wL^2\)). 반력은 끝 지점 314 kN, 첫째 중간 지점 914 kN, 가운데 지점 743 kN로, 단순보로 보았을 때(끝 400, 중간 800)와 크게 다릅니다. 기둥이 보의 회전을 일부 막는 실제 골조는 15장의 방법으로 풉니다. 모든 값은 교육용입니다.

연속보의 진짜 재미는 하중이 한 경간에만 있을 때 나타납니다. 왼쪽 경간을 누르면 보가 가운데 지점을 지렛대 삼아 오른쪽 경간을 들어 올리려 하므로, 오른쪽 끝 지점에는 아래로 잡아당기는 반력(들림)이 생길 수 있습니다. 집중 하중을 끌어 보세요.

지점 침하와 온도: 부정정 구조에서만 생기는 힘

기초가 1 cm 가라앉으면

B-10의 기둥 하나가 이웃 기둥보다 기초가 1 cm 더 가라앉았다고 합시다. 하중은 그대로입니다. 그 위의 큰보는 아무 일 없을까요? 다리의 강재가 한여름에 30 °C 더워져 늘어나면요?

정정 구조물은 지점이 움직이거나 부재가 늘어나도 강체처럼 따라 움직일 뿐이라 힘이 생기지 않습니다. 평형 방정식이 반력을 하나로 정해 주는데, 그 식에는 변위가 들어 있지 않기 때문입니다. 부정정 구조물은 다릅니다. 여분의 지점이 움직이려는 변형을 붙잡으므로, 적합 조건의 우변 \(\Delta_i\)가 0이 아니게 되고 그만큼의 여유력이 생깁니다.

원리 14.5 (강제 변위에 의한 단면력) 지점 침하, 온도 변화, 제작 오차처럼 하중 없이 주어지는 변형을 강제 변위라 한다. 정정 구조물에서 강제 변위는 단면력을 만들지 않는다. 부정정 구조물에서는 원리 14.3의 \(\{\Delta\}\)에 강제 변위를 넣어 여유력을 구하며, 그 크기는 구조물의 강성(EI)에 비례한다. 대표적인 결과:
$$\text{양단 고정보, 한쪽 끝 침하 } \Delta: \; M = \frac{6EI\Delta}{L^2}; \qquad \text{2경간 연속보, 가운데 침하 } \Delta: \; M_B = \frac{3EI\Delta}{L^2}; \qquad \text{양단 고정 봉, 온도 } \Delta T: \; N = -EA\alpha\Delta T.$$
예제 14.3 (G1과 같은 2경간 연속보의 침하) 경간 \(L = 8\) m 두 개, \(EI = 3.14 \times 10^5\) kN·m²(G1 단면, 균열 전), 가운데 지점이 \(\Delta = 10\) mm 침하.
  1. 기본 구조물. 가운데 반력 \(X\)(위 +)를 떼어 낸 16 m 단순보. 하중이 없으므로 \(\delta_{10} = 0\), \(f_{11} = (2L)^3/(48EI)\).
  2. 적합 조건. 가운데 처짐이 \(-\Delta\)여야 하므로 \(f_{11}X = -\Delta\) → \(X = -48EI\Delta/(2L)^3 = -6EI\Delta/L^3 = -6 \times 3.14 \times 10^5 \times 0.01/512 = -36.8\) kN. 하중이 없으니 가운데 지점이 보를 아래로 끌어당기는 힘이다.
  3. 휨모멘트. \(M_B = R_A L = 18.4 \times 8 = +147\) kN·m \(= 3EI\Delta/L^2\). 보 아래 섬유가 인장이다.
하중 \(w_u = 100\) kN/m로 생긴 \(M_B = -800\) kN·m(\(-wL^2/8\))에 이것을 더하면 \(-653\) kN·m. 지점 모멘트는 줄고 경간 모멘트는 늘어난다. 강성이 두 배인 보라면 같은 침하에 두 배의 모멘트가 생긴다. 튼튼하게 만든다고 침하에 안전해지지 않는다는 뜻이다.

강한 쪽이 더 받는다: 강성에 따른 힘의 분배

정정 구조에서 힘의 흐름은 기하학(지점의 위치)만으로 정해집니다. 부정정 구조에서는 여러 길이 한 점에서 같은 변위를 가져야 하므로, 하중은 강성이 큰 길로 더 많이 흐릅니다. 나란히 놓인 두 스프링을 함께 누르면 각 스프링이 받는 힘은 \(F_i = k_i \delta\), 곧 강성에 비례합니다. 구조물의 부재도 마찬가지입니다.

원리 14.6 (강성 비례 분배) 한 점에서 같은 변위 \(\delta\)를 공유하는 \(n\)개의 하중 경로가 있고, 경로 \(i\)의 강성(그 점에 단위 변위를 주는 데 드는 힘)이 \(k_i\)이면, 그 점의 하중 \(P\)는
$$P_i = \frac{k_i}{\sum_j k_j} P, \qquad \delta = \frac{P}{\sum_j k_j}$$
로 나뉜다. 단순보 가운데의 강성은 \(k = 48EI/L^3\)이므로 짧은 보일수록 \(L^3\)에 반비례해 훨씬 많이 받는다.

여유도: 부재 하나가 끊어질 때

부정정 차수의 영어 이름 redundancy는 "여분"이라는 뜻입니다. 정정 구조물은 부재나 지점 하나만 잃어도 기구가 되어 무너지지만, \(n\)차 부정정 구조물은 이론적으로 최대 \(n\)개의 구속을 잃어도 서 있을 수 있습니다. 끊어진 부재가 나르던 힘이 다른 길로 돌아가기 때문입니다. 이것을 대체 하중 경로(alternate load path)라 합니다.

정의 14.7 (여유도와 연쇄 붕괴) 구조물의 일부가 손상되어도 하중을 다른 경로로 전달해 전체 붕괴를 막는 능력을 여유도(redundancy) 또는 강건성이라 한다. 국부 손상이 이웃 부재의 과부하로 이어져 손상 범위보다 훨씬 큰 붕괴로 번지는 현상을 연쇄 붕괴(progressive collapse)라 한다.

1968년 영국 런던의 22층 아파트 로넌 포인트에서는 한 층의 가스 폭발로 바깥벽 패널 하나가 떨어져 나가자 그 위층들이 받칠 곳을 잃고 건물 한 모서리가 맨 위층부터 아래까지 무너졌습니다. 패널끼리 이어 주는 연결이 약해 하중이 돌아갈 길이 없었던 것입니다. 이 사고 이후 여러 나라의 기준이 "부재 하나를 잃어도 버티는" 연결과 대체 경로를 요구하게 되었습니다. 다만 여유도는 공짜가 아닙니다. 대체 경로의 부재가 늘어난 힘을 견딜 만큼 강해야 하고, 연결부가 그 힘을 전달할 수 있어야 합니다.

핵심 정리

  1. 평형 방정식만으로 정해지지 않는 힘의 개수가 부정정 차수다. 보는 n = r − 3 − c, 라멘은 n = 3m + r − 3j − c, 트러스는 n = m + r − 2j. n ≥ 0은 안정의 필요조건일 뿐이다.
  2. 응력법은 여유력을 떼어 낸 정정 기본 구조물에서 변위를 계산하고, 적합 조건 δ₁₀ + f₁₁X₁ = Δ₁로 여유력을 정한다. 여유력이 여럿이면 대칭 유연도 행렬의 연립 방정식이 된다.
  3. 1단 고정보(등분포): RB = 3wL/8, MA = −wL²/8. 같은 2경간 연속보: 가운데 반력 1.25wL, MB = −wL²/8. 3연모멘트식으로 여러 경간의 지점 모멘트를 구한다.
  4. 지점 침하·온도 같은 강제 변위는 정정 구조에는 힘을 만들지 않고, 부정정 구조에는 강성에 비례하는 힘을 만든다. 2경간 연속보의 가운데 침하 Δ는 MB = 3EIΔ/L².
  5. 부정정 구조에서 하중은 강성에 비례해 나뉜다. 단순보 가운데 강성은 48EI/L³이라 짧은 부재가 훨씬 많이 받는다.
  6. 여유도는 부재 하나를 잃어도 하중이 다른 경로로 돌아가는 능력이다. 대신 남은 경로는 늘어난 힘을 견뎌야 한다.

1. 한쪽 끝이 고정되고 다른 끝이 롤러로 받쳐진 보(1단 고정보)의 부정정 차수는?

반력 성분은 고정단 3개 + 롤러 1개 = 4개, 평형 방정식은 3개이므로 \(n = 4 - 3 = 1\)이다.

2. 같은 경간 L 두 개의 연속보 전체에 등분포 하중 w가 걸릴 때 가운데 지점 반력은?

가운데 반력을 여유력으로 두면 \(R_B = \dfrac{5w(2L)^4/384}{(2L)^3/48} = 1.25wL\). 전체 하중 \(2wL\)의 5/8이다. 단순보 둘이었다면 \(wL\)이었다.

3. 응력법에서 평형 방정식으로 모자란 식은 무엇으로 채우는가?

원래 구조물에서 떼어 낸 지점은 움직이지 않으므로, 기본 구조물의 그 점 변위(하중에 의한 것 + 여유력에 의한 것)의 합이 0이어야 한다. 이것이 적합 조건이다.

4. 지점이 1 cm 침하해도 휨모멘트가 생기지 않는 구조는?

정정 구조는 강제 변위를 강체 운동으로 받아들인다. 반력이 평형만으로 정해지고 그 식에 변위가 들어 있지 않기 때문이다. 나머지는 모두 부정정이다.

5. 양단 고정보의 한쪽 끝이 Δ만큼 침하할 때 생기는 끝 모멘트 6EIΔ/L²는 보를 두 배 깊게(I가 8배) 만들면?

강제 변위에 의한 힘은 강성 \(EI\)에 비례한다. 단면을 키운다고 침하에 안전해지지 않는다. 대신 응력은 \(M/S\)이고 \(S\)는 4배이므로 응력은 2배로 는다.

6. 경간 6 m와 8 m인 두 단순보(EI 같음)가 가운데에서 교차해 집중 하중 P를 받는다. 짧은 보가 받는 몫은 약?

교점 처짐이 같으므로 분담은 강성 \(48EI/L^3\)에 비례한다: \(8^3/(6^3 + 8^3) = 512/728 \approx 0.70\).

7. 3연모멘트식을 같은 두 경간(양 끝 단순 지지, 등분포 w)에 쓰면 가운데 지점 모멘트는?

\(0 + 2M_B(2L) + 0 = -2 \times wL^3/4\) → \(4M_B L = -wL^3/2\) → \(M_B = -wL^2/8\). 예제 14.2의 응력법 결과와 같다.

8. 절점 10개, 반력 성분 3개인 트러스에 부재가 21개 있다. 부정정 차수는?

\(n = m + r - 2j = 21 + 3 - 20 = 4\). 이 장의 '부재를 끊어 보는 트러스'가 이 경우다. 네 개를 알맞게 끊으면 정정, 하나 더 끊으면 기구가 된다.
