도면 수백 장 사이의 어긋남은 현장에서야 드러나곤 합니다. 덕트가 보에 부딪히고, 물량이 맞지 않고, 준공 뒤에는 어떤 장비가 어디에 있는지 아무도 모릅니다. BIM은 건물을 컴퓨터 속에서 먼저 지어 보고, 그 모델에 담긴 정보를 설계·시공·운영 내내 함께 쓰는 방법입니다. BIMBook은 모든 장에서 요소를 옮기면 간섭이 다시 검출되고, 속성을 바꾸면 물량과 원가가 다시 계산되는 시뮬레이터로 익힙니다. 숫자는 기준 모델 B-10 BIM(요소 360개)에서 가져옵니다.

이 책의 지도

BIM의 줄기는 모델 → 정보 → 협업 → 활용입니다. 제1부에서 형상과 데이터 모델을, 제2부에서 정보 관리와 간섭·물량·분석을, 제3부에서 4D·5D와 현장의 디지털 기술을, 제4부에서 운영 단계와 도시, 계산 설계를 다룹니다.

제1부 · CH.01–04

BIM의 기초

도면에서 모델로, 변환 행렬과 파라메트릭 형상, IFC 데이터 모델, LOD와 정보 요구 사항.

제2부 · CH.05–08

협업과 검토

공통 데이터 환경과 승인 흐름, 간섭 검토, 겹침을 공제하는 물량 산출, 모델 기반 설계 분석.

제3부 · CH.09–12

시공과 현장

4D 공정 시뮬레이션, 5D 원가와 기성, 측량·드론·레이저 스캔, 디지털 제작과 프리패브.

제4부 · CH.13–16

운영과 미래

시설 관리와 COBie, 디지털 트윈과 센서 데이터, GIS와 도시 모델, 계산 설계와 AI.

대표 실험

수식을 읽기 전에 먼저 만져 보세요. 각 실험은 해당 장의 그 장면으로 이어집니다.

CH.01 · BIM의 이해B-10 BIM 둘러보기요소 유형을 켜고 끄고, 요소를 눌러 GlobalId와 속성을 읽습니다. CH.02 · 형상 모델링과 파라메트릭변환 행렬 놀이터이동·회전·축척을 바꾸면 4 × 4 행렬과 결과가 함께 바뀌고, 순서가 결과를 바꿉니다. CH.03 · IFC와 데이터 모델IFC 파일 읽기STEP 텍스트를 고치면 엔터티 표와 참조 그래프가 바로 다시 그려집니다. CH.04 · LOD와 정보 요구 사항기둥 하나의 LODLOD 100에서 400까지 형상과 속성, 정보량이 어떻게 늘어나는지 봅니다. CH.05 · 공통 데이터 환경과 정보 관리정보 컨테이너의 상태작업 중 → 공유 → 게시 → 보관, 허용되는 전이와 승인을 직접 밟아 봅니다. CH.06 · 간섭 검토간섭 검토기그룹과 허용 오차를 고르면 B-10의 간섭 80건이 목록과 3D에 나타납니다. CH.07 · 모델 기반 물량 산출겹침 공제 실험우선순위를 바꿔도 총량은 같고 공종 배분만 바뀌는 이유를 확인합니다. CH.09 · 4D 공정 시뮬레이션4D 재생공정표를 따라 요소가 나타나며 설비가 바닥보다 먼저 시작되는 오류를 찾습니다. CH.10 · 5D 원가와 디지털 견적요소로 그린 현금 흐름요소 완료 시점과 금액으로 S 곡선을 만들고 활동 기준 곡선과 비교합니다. CH.11 · 현실 캡처RANSAC 평면 찾기잡음과 이상점을 늘리며 최소 제곱과 RANSAC의 평면을 비교합니다. CH.14 · 디지털 트윈과 IoT칼만 필터센서 잡음과 과정 잡음을 조절하며 추정값이 따라가는 모습을 봅니다. CH.16 · 계산 설계와 AI유전 알고리즘개체 수와 변이율을 바꾸며 기둥 격자 배치의 세대별 최적 점수를 봅니다.

기준 모델 B-10 BIM

모든 장이 같은 가상 모델의 숫자를 씁니다. 실제 건물이 아니며 수치는 교육용 가정입니다.

요소지상 10층, 격자 8 m, 32 × 24 m, 높이 41 m.
  • 요소 360개: 기둥 200, 보 90, 슬래브 10, 코어 벽 40, 덕트 10, 배관 10
  • 요소마다 GlobalId, 층, 재료, 단면 속성
  • IFC 공간 구조 프로젝트 → 대지 → 건물 → 층
간섭기본 배치에서 하드 간섭 60건.
  • 덕트–보 30건, 배관–보 30건(층당 3건씩)
  • 덕트–코어 벽 관통 20건(슬리브로 해결)
  • 덕트를 천장 아래 0.95 m로 내리면 덕트–보 0건
물량·공정·좌표모델에서 꺼내는 숫자.
  • 상자 합 층당 약 339 m³ — 겹침을 공제해야 실제 물량
  • 4D·5D는 SiteBook 기준 공사 P-B10(93주)과 연결
  • 지리 참조 E 203,450 · N 551,820 · 회전 12°(가상)
