Chapter 14

디지털 트윈과 IoT

13장의 자산 정보 모델은 "무엇이 어디에 있는가"를 압니다. 하지만 지금 7층이 몇 도인지, 공조기 베어링이 떨리기 시작했는지는 모릅니다. 건물에 센서를 달고 그 측정을 모델에 이어 붙이면 모델은 현재 상태를 따라가는 살아 있는 모델이 됩니다. 이것을 흔히 디지털 트윈이라 부르지만, 그 말에는 과장도 많습니다. 이 장은 디지털 트윈을 데이터가 흐르는 방향으로 정의하고, 센서와 데이터 흐름, 샘플링과 앨리어싱, 잡음 속에서 상태를 추정하는 칼만 필터, 이상 탐지와 관리도, 잔여 수명 추정, 공조 제어 루프, 3D 센서 대시보드, 데이터 품질과 보안을 B-10 공조 시스템의 교육용 트윈으로 하나씩 계산합니다.

  • 디지털 모델·디지털 그림자·디지털 트윈을 물리 대상과 모델 사이의 자동 데이터 흐름으로 구별하고, 트윈이 돕는 결정을 먼저 정한다.
  • 센서 → 수집 → 전송 → 저장 → 분석의 흐름을 설계하고 센서 수·주기·바이트로 데이터 양을 계산한다.
  • 나이퀴스트 조건 \(f_s \gt 2f_{max}\)과 앨리어싱 진동수 \(f_a = |f - kf_s|\)를 계산한다.
  • 1차원 칼만 필터의 예측–갱신과 이득 \(K = P^-/(P^- + r)\)을 설명하고 \(q\), \(r\)가 평활과 지연을 어떻게 바꾸는지 판단한다.
  • 임계값·이동 평균·관리도로 이상을 탐지하고 탐지와 거짓 경보의 맞바꿈을 계산한다.
  • 열화 추세의 선형 회귀와 예측 구간으로 잔여 수명을 추정하고, 실내 온도의 1차 모델로 제어 루프의 응답을 해석한다.
이 정보가 없었다면건물은 고장이 난 뒤에야 말을 했다

1960년 루돌프 칼만(R. E. Kalman)은 잡음 섞인 측정에서 시스템의 상태를 순차적으로 추정하는 방법을 발표했고, 이 필터는 곧 아폴로 계획의 항법 계산에 쓰였습니다. 측정과 모델을 함께 써서 "보이지 않는 현재 상태"를 추정한다는 생각이 디지털 트윈의 뿌리입니다. 물리 제품과 그 가상 짝을 데이터로 잇는다는 개념은 2002년 무렵 미시간 대학의 마이클 그리브스(M. Grieves)가 제품 수명 주기 관리 강의에서 제시한 것으로 알려져 있고, "디지털 트윈"이라는 말은 2010년대 초 미국 항공우주국(NASA)의 기술 로드맵과 관련 논문에서 널리 쓰이기 시작했습니다.

건물에서는 오래전부터 건물 자동화 시스템이 온도와 설비 상태를 읽어 왔지만, 그 자료는 대개 화면에 잠시 보였다가 사라지거나, 어느 공간·어느 자산의 값인지 모델과 연결되지 않은 채 쌓였습니다. 센서와 통신이 싸지고 13장의 자산 정보 모델이 생기면서, 측정을 공간·자산에 붙여 상태를 추정하고, 고장을 미리 보고, 설비를 조정하는 것이 가능해졌습니다. 그러나 센서는 틀리고, 자료는 빠지고, 모델은 단순화된 것입니다. 이 장의 계산은 그 한계를 숫자로 보이는 데 목적이 있습니다.

디지털 트윈이란: 모델·그림자·트윈

대시보드는 트윈인가

B-10 운영팀에 "디지털 트윈 플랫폼" 제안서가 세 건 들어왔습니다. 하나는 3D 모델 위에 센서 값을 띄우는 화면, 하나는 매일 밤 에너지 시뮬레이션을 돌리는 모델, 하나는 측정으로 모델을 보정하고 공조 설정값을 자동으로 바꾸는 시스템입니다. 모두 디지털 트윈이라 부를 수 있을까요?

디지털 트윈이라는 말은 분야마다, 회사마다 다르게 쓰입니다. 쓸모 있는 구분 하나는 물리 대상과 디지털 모델 사이에 데이터가 자동으로 흐르는가입니다. 제조 분야의 문헌(Kritzinger 등, 2018)이 정리한 세 단계 구분이 널리 인용됩니다.

정의 14.1 (디지털 모델·그림자·트윈, 데이터 흐름 형태) 디지털 모델(digital model): 물리 대상과 모델 사이의 데이터 교환이 모두 사람 손으로 이루어진다(설계 BIM, 에너지 시뮬레이션). 디지털 그림자(digital shadow): 물리 → 디지털 방향은 자동(센서 자료가 모델에 들어감), 디지털 → 물리 방향은 사람이 판단해 조치한다(센서 대시보드, 경보). 디지털 트윈(digital twin): 양방향이 모두 자동이다. 측정이 모델의 상태를 갱신하고, 모델의 판단이 물리 대상의 제어나 작업 지시로 돌아간다. 실무에서는 "트윈"이라 불리는 것의 상당수가 그림자 단계이며, 그것만으로도 쓸모가 크다. 단계보다 중요한 것은 어떤 결정을 돕는가, 얼마나 자주 갱신하는가, 모델이 얼마나 정확한가, 누가 조치하는가이다.
"트윈"이라는 말에 속지 않기 제안서를 볼 때는 다음을 묻습니다. ① 이 시스템이 바꾸려는 결정은 무엇인가(에너지 절감, 고장 예방, 공간 재배치)? ② 모델은 무엇이고 측정으로 어떻게 보정되는가(아니면 3D 화면에 값만 띄우는가)? ③ 갱신 주기와 지연은 결정에 충분한가? ④ 모델·센서가 틀렸을 때 어떻게 아는가? ⑤ 누가 경보를 받고 조치하는가? ⑥ 운영 수십 년 동안 자료와 형식을 누가 유지하는가? 건물 디지털 트윈의 효과는 사례마다 크게 다르며, 이 장은 확인되지 않은 절감률을 제시하지 않습니다.

센서와 데이터 흐름

B-10에 센서 700개를 달면 하루에 얼마가 쌓이나

B-10 운영팀은 층마다 온도·습도·CO₂·재실 센서와 공조기 상태 점, 전력 계량기를 달고, 펌프와 공조기에는 진동 센서를 붙이려 합니다. 1분마다 저장하면 하루 몇 MB일까요? 진동 파형까지 그대로 올리면?

건물의 측정 자료는 센서(온도, 습도, CO₂, 재실, 압력·차압, 유량, 전력, 진동 가속도) → 수집(제어기·게이트웨이 같은 엣지 컴퓨팅(edge computing) 장치, 아날로그 신호를 숫자로 바꾸는 표본화와 양자화) → 전송(건물 자동화 프로토콜 BACnet(ISO 16484-5)·Modbus, 메시지 전달 방식 MQTT 같은 형태) → 저장(시각–값 쌍을 쌓는 시계열 데이터베이스(time-series database)) → 분석·모델(필터, 이상 탐지, 예측) → 표시·조치(대시보드, 경보, 작업 지시, 제어)로 흐릅니다. 각 단계에서 지연이 생기고 자료가 빠지거나 틀릴 수 있습니다.

정의 14.2 (표본화 주기와 데이터 양)
$$V_{day} = N\cdot\frac{86{,}400}{\Delta t}\cdot B, \qquad V_{vib} = M\cdot n_b\cdot (f_s\,T_b)\cdot b$$
\(N\): 일반 측정점 수, \(\Delta t\): 샘플링 주기(sampling interval)(s), \(B\): 1개 기록의 바이트(시각 8 + 값 4–8 + 측정점 ID + 품질 표시, 압축 전). 진동은 \(M\)개 센서가 하루 \(n_b\)번 길이 \(T_b\)(s)의 파형을 표본화 진동수 \(f_s\)(Hz), 표본당 \(b\) 바이트로 기록한다. 엣지에서 파형 대신 특징값 몇 개만 보내면 \(f_s T_b\)가 특징 수로 바뀐다. 저장소는 원자료를 정해진 기간만 두고 그 뒤로는 15분 평균 같은 집계만 남기는 보존 정책을 쓴다.

샘플링과 앨리어싱

1초마다 잰 펌프 진동이 느리게 출렁인다

B-10 냉수 펌프는 1,780 rpm(약 29.7 Hz)으로 돕니다. 건물 자동화 시스템이 진동을 25 Hz로 표본화했더니 4.7 Hz의 느린 진동이 보입니다. 이 4.7 Hz는 실제 진동일까요?

원리 14.3 (나이퀴스트 조건과 앨리어싱)
$$f_s \gt 2 f_{max}, \qquad f_a = \left|f - k f_s\right|,\ \ k = \operatorname{round}(f/f_s), \qquad 0 \le f_a \le \frac{f_s}{2}$$
표본화 진동수 \(f_s\)로 잰 신호에서 \(f_s/2\)(나이퀴스트 진동수(Nyquist frequency))보다 높은 성분은 사라지지 않고 \(f_a\)라는 낮은 진동수로 둔갑한다. 이것이 앨리어싱(aliasing)이다. 표본만으로는 진짜 낮은 진동과 둔갑한 진동을 구별할 수 없으므로, 표본화 전에 \(f_s/2\) 이상의 성분을 아날로그 저역 통과 필터(앤티앨리어싱 필터(anti-aliasing filter))로 걸러야 한다. 표본화 정리(나이퀴스트–섀넌)는 대역이 제한된 신호를 \(f_s \gt 2f_{max}\)로 재면 원래 신호를 복원할 수 있다고 말하며, 실무에서는 대개 그보다 훨씬 높게(수 배–10배 이상) 잰다.

예제 14.2 (펌프와 건물의 표본화)

① 펌프 \(f = 1{,}780/60 = 29.67\) Hz, \(f_s = 25\) Hz → \(k = \operatorname{round}(1.19) = 1\), \(f_a = |29.67 - 25| = 4.67\) Hz. 실제로 없는 4.67 Hz 진동이 기록된다. 회전 진동수의 2배·3배 성분(정렬 불량, 날개 통과 등)까지 보려면 \(f_s \gt 2\times3\times29.67 = 178\) Hz가 필요하고, 베어링 손상의 kHz 대역을 보려면 더 높아야 한다.

② B-10 흔들림 StructureBook 7장의 해석 모델에서 B-10의 1차 고유 주기는 1.00 s(1.00 Hz)이다. 지붕 가속도를 1초마다 재면 \(f_a = 0\)이 되어 진동이 보이지 않는다. 고차 모드(0.34 s → 2.9 Hz, 0.21 s → 4.8 Hz)까지 보려면 적어도 \(f_s \gt 9.6\) Hz, 실무에서는 수십–100 Hz로 잰다.

③ 판단 실내 온도처럼 느린 신호는 분 단위로 충분하지만, 같은 시스템의 같은 저장 주기로 진동을 재면 숫자는 나오는데 의미가 없다. 측정점마다 신호의 최고 진동수에서 표본화 진동수를 정하고, 엣지에서 앤티앨리어싱 필터와 특징 추출을 한다.

상태 추정: 잡음과 칼만 필터

온도 센서가 ±0.3 °C씩 흔들린다

B-10 5층 사무실 A의 온도 센서는 1분마다 값을 보내지만 잡음이 ±0.3 °C쯤 섞여 있습니다. 공조 제어기가 이 값을 그대로 쓰면 냉방 밸브가 쉴 새 없이 열렸다 닫힙니다. 평균을 내면 잡음은 줄지만 설정값을 바꿨을 때 늦게 따라갑니다. 얼마나 믿고 얼마나 평균할지 어떻게 정할까요?

측정은 참값에 잡음이 더해진 것이고, 참값 자체도 시간에 따라 변합니다. 둘을 함께 모델로 쓰면, 새 측정이 들어올 때마다 "지금까지의 추정"과 "새 측정"을 각자의 불확실성에 비례해 섞을 수 있습니다. 그 섞는 비율을 매 순간 최적으로 정하는 것이 칼만 필터(Kalman filter)입니다.

정의 14.4 (상태 공간 모델, 1차원 랜덤 워크)
$$x_k = x_{k-1} + w_k,\ \ w_k \sim N(0, q), \qquad z_k = x_k + v_k,\ \ v_k \sim N(0, r)$$
\(x_k\): 시각 \(k\)의 참 상태(실내 온도), \(z_k\): 측정, \(q\): 과정 잡음(process noise) 분산(한 단계 동안 참값이 얼마나 움직일 수 있나, °C²), \(r\): 측정 잡음(measurement noise) 분산(센서 잡음, 표준편차 0.3 °C면 \(r = 0.09\) °C²). 상태 추정(state estimation)은 측정 \(z_1, \dots, z_k\)에서 \(x_k\)와 그 불확실성 \(P_k\)를 구하는 일이다.
원리 14.5 (1차원 칼만 필터: 예측과 갱신)
$$P^- = P_{k-1} + q, \qquad K_k = \frac{P^-}{P^- + r}, \qquad \hat x_k = \hat x_{k-1} + K_k\,(z_k - \hat x_{k-1}), \qquad P_k = (1 - K_k)\,P^-$$
예측: 상태는 그대로 두고 불확실성만 \(q\)만큼 키운다. 갱신: 측정과 예측의 차이(혁신)에 칼만 이득(Kalman gain) \(K\)를 곱해 더한다. \(K\)는 0–1 사이로, 추정을 덜 믿을수록(\(P^-\)가 클수록) 1에 가깝고 측정을 덜 믿을수록(\(r\)가 클수록) 0에 가깝다. 시간이 지나면 \(P\)와 \(K\)는 일정한 값으로 수렴한다. $$P^-_\infty = \frac{q + \sqrt{q^2 + 4qr}}{2}, \qquad K_\infty = \frac{P^-_\infty}{P^-_\infty + r}$$ 정상 상태의 필터는 이득 \(K_\infty\)의 지수 이동 평균과 같다. 측정이 빠진 시각에는 갱신을 건너뛰고 예측만 한다(\(P\)가 커져 다음 측정을 더 믿는다). CB.bim.kalman1D(z, q, r, x0, P0)가 이 계산을 한다.

이상 탐지(anomaly detection)는 정상 상태의 자료로 기준선(평균과 흩어짐)을 정하고, 새 측정이 기준선에서 우연으로 보기 어려울 만큼 벗어나면 경보를 내는 일입니다. 품질 관리의 관리도(SiteBook 14장)와 같은 생각입니다. 규칙이 민감할수록 이상을 빨리 잡지만 거짓 경보(false alarm)도 늘어납니다.

정의 14.6 (세 가지 탐지 규칙, 교육용 형태) 기준 기간(이상이 없다고 확인한 기간)의 평균 \(\mu_0\), 표준편차 \(\sigma_0\)에 대해
$$\text{① 고정 임계값: } z_t \gt A, \qquad \text{② 이동 평균: } \left|\bar z_t^{(m)} - \mu_0\right| \gt k\,\frac{\sigma_0}{\sqrt m}, \qquad \text{③ 관리도: } |z_t - \mu_0| \gt k\sigma_0 \ \text{또는 연속 8점이 한쪽}$$
① 설비 사양·진동 심각도 기준(기계 종류별 구역 기준, ISO 20816 계열 형태 — 값은 현행 기준과 제조사 자료 확인) 같은 절대값 \(A\)를 넘으면 경보. 단순하지만 그 설비의 평소 수준을 모른다. ② 최근 \(m\)개 평균은 잡음 표준편차가 \(\sigma_0/\sqrt m\)로 줄어 작은 이동을 잡지만 \(m\)만큼 늦다. ③ 개별 값 관리도에 SiteBook 정의 14.4의 규칙 1(3σ 밖)과 규칙 4(연속 8점이 중심선 한쪽)를 쓴다. 정규 잡음에서 3σ 규칙 하나의 거짓 경보 확률은 표본마다 약 0.27 %다.

원리 14.7 (선형 회귀 외삽과 예측 구간, 교육용) 최근 \(n\)개 측정 \((t_j, y_j)\)에 최소 제곱 직선 \(\hat y = b_0 + b_1 t\)를 맞추면
$$\hat t_f = \frac{y_{lim} - b_0}{b_1}, \qquad \hat y(t) \pm t_{\alpha/2,\,n-2}\; s\sqrt{1 + \frac1n + \frac{(t - \bar t)^2}{S_{tt}}}$$
\(y_{lim}\): 한계값, 오른쪽 식이 예측 구간(prediction interval), \(s\): 잔차 표준편차, \(S_{tt} = \sum(t_j - \bar t)^2\). 예측 구간의 위·아래 경계가 한계에 닿는 시각이 고장 시각 구간의 끝이 된다(위 경계가 먼저 닿는 시각 = 이른 쪽). 멀리 외삽할수록 \((t - \bar t)^2\) 항이 커져 구간이 넓어진다. 추세가 가속하면(필터 차압은 보통 그렇다) 직선은 고장 시각을 늦게(낙관적으로) 본다.

정의 14.8 (실내 온도의 1차 모델, 교육용)
$$C\frac{dT}{dt} = UA\,(T_o - T) + Q_g - Q_c, \qquad \tau = \frac{C}{UA}$$
\(C\): 실의 유효 열용량(공기 + 가구 + 노출된 구조체, kJ/K), \(UA\): 외피·침기의 열 손실 계수(kW/K), \(T_o\): 외기 온도, \(Q_g\): 내부 발열과 일사(kW), \(Q_c\): 냉방 열량(0–\(Q_{max}\)), \(\tau\): 시상수(time constant). 제어 방식: 온–오프(\(T \gt T_s + \delta/2\)이면 \(Q_{max}\), \(T \lt T_s - \delta/2\)이면 0), 비례(P) \(Q_c = K_p (T - T_s)\), 비례–적분(PI)(PI 제어(proportional-integral control)) \(Q_c = K_p e + K_i\int e\,dt\)(\(e = T - T_s\)). P 제어는 정상 상태에서 $$T_\infty - T_s = \frac{UA\,(T_o - T_s) + Q_g}{UA + K_p}$$ 만큼의 정상 편차를 남기고, 적분 항이 이를 없앤다. 용량 한계에서 적분이 계속 쌓이지 않도록 막는 처리(적분 와인드업 방지)가 필요하다.

구조 건전성 모니터링 맛보기

건물의 진동수는 건강 지표가 될까

B-10 지붕에 가속도계를 달아 바람과 미진동에 흔들리는 응답에서 1차 고유 진동수를 매일 뽑습니다. 지진 뒤 진동수가 1 % 떨어졌다면 손상일까요, 날씨 탓일까요?

구조 건전성 모니터링(structural health monitoring, SHM)은 구조물의 응답을 계속 재서 손상을 찾는 일입니다. 구조물의 강성이 줄면 고유 진동수가 낮아집니다. 1자유도 근사 \(f = \frac{1}{2\pi}\sqrt{k/m}\)에서 \(\Delta f/f \approx \frac12\,\Delta k/k\)이므로, 강성이 2 % 줄면 진동수는 약 1 % 줄어듭니다. 문제는 온도·습도·비구조 요소(마감·칸막이)의 강성 변화도 진동수를 그만큼 움직인다는 점입니다. 그래서 진동수를 그대로 감시하지 않고, 기준 기간에 온도와의 관계를 회귀해 그 몫을 뺀 잔차를 관리도로 봅니다. 교량에 대한 계산은 CivilBook 16장 스마트 계측에서 자세히 다루며(원리 16.7, 온도 보정 회귀와 7일 이동 평균), 그 방법이 이 장의 관리도와 같습니다.

예제 14.7 (B-10 진동수 추적의 해상도) StructureBook 7장의 해석 모델: \(T_1 = 1.00\) s → \(f_1 = 1.00\) Hz.

① 손상의 크기 강성 2 % 감소 → \(\Delta f \approx 0.5\times2 = 1\) % → 0.990 Hz. 0.01 Hz의 차이다.

② 측정 길이 푸리에 변환의 진동수 해상도는 \(\Delta f = 1/T_{rec}\)이다. 0.01 Hz를 가르려면 기록이 적어도 100 s, 실무에서는 잡음을 줄이려고 10분(600 s, 해상도 0.0017 Hz) 이상을 평균한다. 표본화는 고차 모드(약 4.8 Hz)까지 보려면 \(f_s \gt 9.6\) Hz(예제 14.2).

③ 판단 측정 진동수는 비구조 요소의 강성 때문에 해석값과 다르게(대개 높게) 나오는 경향이 있으므로(StructureBook 7장), 기준선은 해석값이 아니라 측정한 기준 기간으로 잡는다. 진동수 변화는 "어딘가 달라졌다"는 신호일 뿐 위치와 원인을 알려 주지 않는다. 경보는 점검(13장 작업 지시, StructureBook 16장 안전 진단)으로 이어져야 한다.

데이터 품질과 보안

정상처럼 보이는 고장 센서

B-10 3층 사무실 D의 온도는 새벽 6시부터 하루 종일 26.3 °C입니다. 쾌적 범위 안이라 경보는 없습니다. 그러나 이 값은 측정이 아니라 멈춘 센서의 마지막 값입니다. 자료의 품질은 어떻게 검사할까요?

트윈의 판단은 자료보다 나을 수 없습니다. 센서 고장은 흔하며 모양이 정해져 있습니다: 튐(한 표본만 크게 벗어남), 고착(값이 멈춤), 결측(통신 끊김), 범위 밖(물리적으로 불가능한 값, 오류 코드), 표류(교정이 서서히 틀어짐), 시각 오류(시계 어긋남, 중복). 자료에는 값과 함께 품질 표시(정상·의심·불량·보간)를 붙여 두고, 분석과 경보가 그 표시를 따르게 합니다.

정의 14.9 (데이터 품질 규칙, 교육용) 각 표본에 대해 ① 범위: \(z \notin [z_{min}, z_{max}]\), ② 변화율: \(|z_t - z_{t-1}|/\Delta t \gt r_{max}\), ③ 고착: 최근 \(w\)분의 표준편차 \(\lt \epsilon\), ④ 결측: 기대 시각에 값이 없음, ⑤ 이웃 비교: 같은 공간 센서와의 차이 \(\gt \delta\)가 30분 이상 지속. ①–④는 센서 하나로 검사할 수 있지만 표류는 ⑤처럼 중복 측정이나 모델 예측과의 비교로만 드러난다. 데이터 품질(data quality)은 완결성·정확성·적시성·일관성으로 나누어 보며, 이 장은 완결성(결측 제외 비율)과 규칙 위반 비율로 잰다.

핵심 정리

  1. 디지털 모델·그림자·트윈은 물리 ↔ 모델의 자동 데이터 흐름으로 구별한다. 이름보다 "어떤 결정을, 얼마나 자주, 얼마나 정확히, 누가 조치하나"가 중요하다.
  2. 자료는 센서 → 엣지 → 네트워크 → 시계열 저장 → 분석 → 조치로 흐르고, 측정점은 공간·자산 ID로 모델에 연결한다. 양 = N × (86,400/Δt) × B, 진동은 엣지 특징값으로 수백 배 줄인다(B-10: 24 MB + 0.28 MB/일).
  3. fs > 2fmax를 지키지 않으면 fa = |f − kfs|로 둔갑한다(펌프 29.67 Hz를 25 Hz로 → 4.67 Hz). 앤티앨리어싱 필터와 용도별 표본화가 필요하다.
  4. 칼만 필터: P⁻ = P + q, K = P⁻/(P⁻ + r), x̂ += K(z − x̂), P = (1 − K)P⁻. q가 작으면 매끄럽지만 늦고, 크면 잡음을 통과시킨다(q 10⁻³, r 0.09 → K∞ 0.10, σ 0.3 → 0.095 °C).
  5. 이상 탐지는 기준선 대비 임계값·이동 평균(σ/√m)·관리도(3σ, 연속 8점)로 한다. 3σ 하나도 센서 500개면 하루 약 32번 거짓 경보 — 경보 피로를 계산해 규칙을 정한다.
  6. 잔여 수명은 회귀선과 예측 구간이 한계에 닿는 시각으로 추정한다. 가속하는 추세를 직선으로 보면 낙관적이다(116일 vs 실제 100일). 이른 쪽 경계로 계획하고 매번 다시 계산한다.
  7. 실온 1차 모델 C dT/dt = UA(To − T) + Qg − Qc, τ = C/UA. P 제어는 정상 편차 (UA(To − Ts) + Qg)/(UA + Kp)를 남기고 PI가 없앤다. 모델과 측정의 어긋남이 고장 진단의 단서다.
  8. 데이터 품질(튐·고착·결측·범위 밖·표류)은 규칙으로 표시하고, 표류는 이웃·모델 비교로만 잡힌다. OT망 분리·최소 권한·명령 범위 제한과 개인정보 보호가 트윈의 전제다. SHM은 Δf/f ≈ ½Δk/k와 온도 보정 잔차로 본다.

확인 퀴즈

1. 센서 값이 자동으로 3D 모델에 표시되고, 운영자가 그것을 보고 직접 설정을 바꾼다. 정의 14.1의 어느 단계인가?

물리 → 디지털은 자동, 디지털 → 물리는 사람의 조치다. 조치까지 자동으로 돌아가야 트윈이다.

2. 센서 1,000개를 10초마다 기록하고 기록 하나가 20 B이다. 하루 데이터 양은?

\(1{,}000\times8{,}640\times20 = 1.73\times10^8\) B ≈ 173 MB.

3. 50 Hz 성분이 있는 신호를 60 Hz로 표본화하면 보이는 진동수는?

나이퀴스트 진동수는 30 Hz. \(k = \operatorname{round}(50/60) = 1\), \(f_a = |50 - 60| = 10\) Hz.

4. 칼만 필터에서 측정 잡음 분산 r을 크게 가정하면?

\(K = P^-/(P^- + r)\). r이 크면 K가 작아져 새 측정을 덜 반영한다. 잡음은 줄지만 지연이 는다.

5. q = 0.001, r = 0.09일 때 정상 칼만 이득은?

\(P^-_\infty = (0.001 + \sqrt{10^{-6} + 3.6\times10^{-4}})/2 = 0.010\), \(K = 0.010/0.100 = 0.10\)(예제 14.3).

6. 기준선 σ = 0.15에서 평균이 0.3 이동했다. 9시간 이동 평균에 3σ/√m 한계를 쓸 때 한계와 이동의 관계는?

\(3\times0.15/\sqrt9 = 0.15\). 이동 0.3은 한계의 두 배라 창(9시간)이 채워지면 거의 확실히 잡힌다. 대신 9시간 늦다.

7. 가속하며 증가하는 열화 추세에 직선 회귀를 맞춰 한계 도달일을 예측하면 대체로?

과거의 완만한 기울기가 평균에 섞여 미래의 가파른 기울기를 과소평가한다(예제 14.5: 116일 vs 100일). 최근 자료에 무게를 두고 구간의 이른 쪽을 쓴다.

8. UA = 0.5 kW/K, To − Ts = 6 K, Qg = 4 kW, Kp = 6.5 kW/K인 P 제어의 정상 편차는?

\((0.5\times6 + 4)/(0.5 + 6.5) = 7/7 = 1.0\) °C. 적분 항을 넣으면 0이 된다.
