# CivilBook 챕터 작성 가이드

CivilBook은 ConstructionBooks 서가(`construction.euiyun.com`)의 여섯 번째 권인 교량·터널·도로 교과서다. 배포 주소는 `https://construction.euiyun.com/civil/`. `js/common.js`는 GeotechBook 엔진(구조 해석기 + 지반 모델 `CB.soil`, 기준 지반 `CB.soil.SITE`)을 복사하고 **토목 기반 시설 모델** `CB.civ`(교량 이동 하중과 영향선 주사, 충격, 주케이블·사장 케이블, 커쉬 해, 지반 반응 곡선, 숏크리트 지보, 시거·곡선·종단 곡선, 교통류, ESAL·AASHTO 93·웨스터가드, 매닝·합리식)를 더했다. 본보기는 `../structure/chapters/seismic.html`, `../geotech/chapters/consolidation.html`, `../concrete/chapters/flexure.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 기준 조항·계수·역사적 사실은 확인된 것만 쓴다(확실하지 않으면 "형태", "약", "교육용", "현행 기준 확인").

## 구조

빌드 없이 열리는 정적 페이지. `index.html` + `chapters/<slug>.html` + `css/style.css`(앞 권과 같고 강조색만 녹색 `#2b7a3e`, 보조색 안전 주황 `#e8590c`) + `js/common.js`(전역 `CB`, `CHAPTERS`). classic script만, 외부 라이브러리 없음. 3D는 `CB.orbit` — 교량·터널·도로 선형은 3D 장면에 잘 어울리므로 장마다 하나 이상 쓴다.

- 용어: `js/glossary/<slug>.json`(`{"ko","en","abbr","def","chapters":["<slug>"]}` 배열)에 적고 `tools/merge-glossary.py civil`이 합친다. `en` 대문자 시작, `abbr` 밑줄 금지, 띄어쓰기 변형으로 같은 용어를 두 번 넣지 않는다. 정의에 `<`·`>`를 쓰지 말고 "미만", "초과" 같은 말로 쓴다.

## 원칙: 기능 → 하중·환경 → 형식 → 계산 → 운영

토목 기반 시설은 "사람과 물자가 건너고 지나가게 하는 기능을, 자연(강·산·흙·물)과 교통 하중 속에서 수십–백 년 동안 유지하는" 구조물이다. 이 책은 **기능을 정하고(무엇을 얼마나 지나가게 하나) → 하중·환경을 정하고(트럭, 지반 응력, 홍수, 교통량) → 형식을 고르고(거더·아치·케이블, NATM·TBM, 연성·강성 포장) → 계산하고(시뮬레이터, `CB.civ`·`CB.frame`·`CB.soil`) → 운영·유지관리로 잇는** 순서로 쓴다. 앞 권(구조역학, 재료, 지반, 건축구조, RC)의 계산을 토목 구조물 규모에서 다시 만나게 하고 링크한다.

- 한국어, 대상은 토목 3학년과 교량·터널·도로 실무 입문자(앞 권을 안다고 가정).
- 장 첫머리 `.origin`("이 구조물이 없었다면" 또는 "이 계산이 없었다면"), 각 절은 가능하면 `.problem`.
- 흐름: 문제 → 그림(SVG) → **조작하는 시뮬레이터** → 정의·원리(KaTeX) → **손으로 푸는 예제**(`.callout`, 단계별, 단위, 판정) → 기준 구조물 노트(`.callout.site`) → `.uses` → 핵심 정리 → 확인 퀴즈(8문항).
- 정의·원리 `<div class="callout def"><strong>원리 2.1 (영향선)</strong> …</div>`, 예제 `예제 2.1`, 그림 `그림 2-1.`, `.callout.deep` 심화.
- 장마다 **시뮬레이터 7–8개, 그림 6개 이상, 퀴즈 8문항.** 계산하는 모델이어야 하고, 극단 입력에도 NaN·음수 길이가 없다. 무거운 계산(영향선 주사, 유한 차분, 반복 해법)은 입력이 바뀔 때만 다시 한다.
- 계산은 `CB.civ`(이 책), `CB.frame`/`CB.beam`/`CB.truss`/`CB.section`(구조), `CB.soil`(지반)로 한다. 장 고유 모델(가설 단계 해석, 지표 침하 곡선, 교차로 신호, 궤도 응력, 세굴 깊이 경험식, 열화 마르코프 모형 등)은 페이지 스크립트에 두고 "교육용"이라 밝힌다.
- 색은 CSS 변수와 `CB.palette()`만. 라이트/다크 모두. 폭 360px 가로 스크롤 금지. SVG는 `viewBox`만, 폭 900 이하.
- 시뮬레이터 `id`는 `sim-<접두사>-<이름>`, 요소 id·전용 CSS 클래스도 접두사. 절 `id`는 의미 있는 영어 슬러그.

## 단위·부호·색 규약 (책 전체 공통)

**단위.** 힘 kN, 길이 m(단면 mm), 모멘트 kN·m, 응력 MPa(구조)·kPa(지반·포장), 속도 km/h(도로·철도)·m/s(수리·바람), 유량 m³/s, 경사 %(도로) 또는 소수(수리), 교통량 대/일·대/시. `CB.civ` 각 함수의 단위는 소스 주석을 따른다.

**부호.** 구조는 MechanicsBook 규약(인장 +, 새깅 +, 휨모멘트도 인장측), 지반·터널은 GeotechBook 규약(압축 +, 깊이 아래 +). 터널 단면의 각 θ는 수평(스프링라인)에서 반시계로 잰다. 도로 종단 경사는 진행 방향 오르막 +.

**색.** 하중·차량 `accent2`, 반력 `ok`, 인장 `tension`, 압축 `compression`, 케이블 `accent`, 지반 `warn` 계열 갈색 톤, 물·지하수 `blue`, 지보·라이닝 `text-dim`, 판정 `ok`/`bad`, 시거·한계선 `warn` 점선.

**01 교량의 이해** — 교량이 하는 일과 구성(상부 구조·받침·하부 구조·기초) / 형식 분류: 거더·라멘·아치·트러스·사장·현수, 경간에 따른 적용 범위(경험적 띠, 교육용) / 재료(강·RC·PSC·복합) / 가설 공법 개요(동바리·ILM·MSS·FCM·크레인 가설·캔틸레버 가설) / 유명 교량은 확인된 사실만 / B-130 소개와 이 책의 지도. 시뮬: B-130 3D 탐색(`CB.orbit`: 부재 켜고 끄기, 클릭 → 제원), 경간–형식 선택 도표(경간 → 적합 형식 띠), 하중 경로 애니메이션(트럭 → 바닥판 → 거더 → 받침 → 교각 → 말뚝), 단순 vs 연속 거더(같은 하중 → 모멘트·처짐 `CB.beam`), 형식별 자중 비교, 가설 공법 단계 애니메이션, 교량 높이·하천 단면 배치(형하 여유).
**02 교량 하중과 이동 하중** — 하중의 종류(고정·활·충격·원심·제동·풍·온도·지진·수압·유수압) / 설계 트럭과 차로 하중(`TRUCK`), 축 배치, 차로 수와 다차로 재하 계수 형태 / 영향선(MechanicsBook 6장 연결)과 트럭 주사(`truckScan`, `ilSimple`), 최대 모멘트 위치(합력과 축의 중앙) / 충격 계수(`impact`) / 연속교 영향선(`CB.beam`으로 단위 하중 이동) / 하중 조합과 한계 상태(교량 형태) / 피로 하중 맛보기 / B-130 경간별 최대 효과. 시뮬: 트럭 주행(트럭 끌기·자동 주행 → 휨모멘트·전단 시간 이력, 최대값), 영향선 그리기(위치 c → RA·V·M 영향선), 절대 최대 모멘트 찾기, 연속교 영향선(B-130 지점·경간 위치 → 영향선, `CB.beam`), 차로 하중 재하 구간 고르기(영향선 양·음 구간), 충격 계수 곡선, 다차로 재하 계수 효과.
**03 거더교와 바닥판** — 거더교 형식(강 I형·박스, PSC I형·박스, RC 슬래브교) / 강합성 거더: 합성 전·후 단면(StructureBook 11장 연결), 유효 폭, 가설 단계 응력 / 횡분배: 레버 룰, 강성 비에 의한 분배(교육용 근사, 기준 형태), 격자 해석 맛보기 / 연속교 부모멘트 구간과 균열·종방향 철근 / 바닥판: 지간 방향 휨, 바닥판 설계(ConcreteBook 9장 연결), 캔틸레버부, 방호벽 / 박스 거더와 비틀림(편재 하중) / PSC 거더(ConcreteBook 15장 연결) / B-130 거더. 시뮬: 합성 단면 계산기(바닥판 두께·유효 폭·강 거더 → 중립축·I·응력, 합성 전/후 단계 응력 누적, `CB.section`), 횡분배(트럭 횡위치 끌기 → 거더별 분담률, 레버 룰 vs 강성 분배), 연속교 모멘트 포락선(B-130, `CB.beam` 트럭·차로 하중), 바닥판 휨(거더 간격·두께 → 단위 폭 모멘트·철근), 편재 하중 비틀림(박스 vs I형 처짐 차이), 거더 높이–경간 비(경간 → 높이·강재량), 3D 처짐 형상(`CB.orbit`).
**04 아치교와 트러스교** — 아치의 원리와 추력(MechanicsBook 5장 연결), 상로·중로·하로, 타이드 아치(추력을 타이로) / 아치 리브의 압력선과 편재 하중의 휨, 2힌지·고정 아치 / 아치 좌굴 맛보기 / 트러스교 형식(프랫·워런·K), 부재력(T-36 연결)과 경간 확장, 2차 응력 / 트러스 가설(캔틸레버) / 아치·트러스 효율과 경간. 시뮬: 아치 추력(라이즈 비 → H, 지점 반력, `CB.frame`), 편재 하중 휨(아치 형상 포물선·원호 → 압력선 편차·모멘트), 타이드 아치 타이 장력과 받침 반력, 트러스교 해석(형식·높이 → 부재력 색, `CB.truss`), 트럭 주행 트러스 부재력 이력(영향선, `truckScan` 응용), 아치 좌굴 하중 근사(라이즈 비), 3D 하로 아치교(`CB.orbit`).
**05 사장교와 현수교** — 장대교의 구조(주탑·케이블·보강 거더·앵커리지) / 현수교: 주케이블 포물선(`cable`), 처짐비와 장력, 행어, 앵커리지 반력, 처짐 이론 맛보기 / 사장교: 케이블 배치(부채·하프·방사), 케이블 장력(`stay`), 거더 압축, 주탑 높이 비, 새그와 등가 탄성계수(`ernst`) / 공기 역학적 안정: 플러터·와류 진동(타코마 1940 확인된 사실만, StructureBook 6장 연결), 단면 형상 / 가설: 캔틸레버 가설과 케이블 긴장 순서 / 세계·국내 장대교(확인된 사실만) / CS-420과 600 m 현수교 비교. 시뮬: 주케이블 형상(처짐비 → H·Tmax·케이블 길이, 현수교 그림), 사장교 케이블 장력(주탑 높이·정착 위치 → 경사·장력·거더 압축 막대), 케이블 배치 비교(부채·하프), 에른스트 등가 탄성계수(케이블 길이·응력 → Eeq/E), 캔틸레버 가설 단계(단계 → 거더 모멘트·주탑 휨), 와류 공진 풍속(단면 폭·고유 진동수), 3D 사장교(`CB.orbit`).
**06 하부 구조와 받침** — 교각(벽식·기둥식·라멘식), 교대(역T형·반중력식), 날개벽 / 교대 토압(GeotechBook 10장 연결)과 안정 / 기초(직접·말뚝·케이슨, GeotechBook 연결) / 받침: 고정·가동, 탄성 받침·포트 받침·면진 받침(StructureBook 9장 연결), 받침 반력과 들림 / 신축 이음: 온도 신축량 Δ = αLΔT + 크리프·건조 수축, 유간 / 지진 시 교량: 연속 교각의 강성 분배, 낙교 방지(받침 지지 길이 형태), 면진 교량 / B-130 하부 구조. 시뮬: 온도 신축량 계산기(교량 길이·온도 범위 → 신축량·유간), 교각 수평력 분배(교각 높이·단면 → 강성 비 → 분담, 고정·가동 받침 배치), 교대 안정(뒤채움 높이·기초 폭 → 전도·활동·지지력, `CB.soil`), 받침 반력과 들림(편재 하중 → 받침별 반력), 지진 시 받침 지지 길이(변위 → 낙교 판정, 교육용), 면진 받침 효과(주기 이동 → 교각 전단), 3D 하부 구조(`CB.orbit`).
**07 터널의 이해와 굴착** — 터널의 용도와 단면(도로·철도·지하철·수로·공동구) / 지반 조건과 암반 분류(GeotechBook 16장 연결) / 굴착 공법: 발파(NATM 굴착 순서, 발파 패턴 맛보기), 기계 굴착, 개착 / 굴착 분할(전단면·반단면·벤치·CD) / 원형 공동 주위 응력: 커쉬 해(`kirsch`), 측압 계수 K의 영향, 응력 집중, 아치 작용 / 막장 안정 / 지하수 / TN-11 소개. 시뮬: 커쉬 응력장(K·r → σθ·σr 등고선, 벽면 응력 분포 극좌표, `kirsch`), 측압 계수와 벽면 응력(K 슬라이더 → 천단·측벽 응력, 인장 발생), 단면 형상 비교(원형·마제형 응력 집중, 교육용), 굴착 분할 단계 애니메이션, 발파 패턴(공 배치 → 굴착 단면, 교육용), 토피·초기 응력 계산(`CB.soil`과 단위중량), 3D 터널 진행(`CB.orbit`: 막장 진행·지보 설치).
**08 지반 반응과 지보** — 수렴–구속법: 지반 반응 곡선(`grc`), 막장 효과와 종방향 변위 곡선(교육용 근사), 지보 특성 곡선(`shotcrete`), 평형점과 지보 안전율 / 지보재: 숏크리트, 록볼트(정착·마찰형, 볼트 패턴), 강지보, 라이닝 / NATM의 원리(지반이 스스로 지지, 관찰적 방법) / 계측: 내공 변위·천단 침하·록볼트 축력, 계측 관리 기준(교육용) / 지보 패턴과 암반 등급(RMR, GeotechBook 16장) / TN-11 지보 설계(평형 0.21 MPa, 4.4 mm, 안전율 3.6). 시뮬: 지반 반응 곡선(p₀·E·c·φ → 곡선, 소성 영역 그림, `grc`), 지보 설치 시기(설치 시 변위 끌기 → 평형점·지보압·안전율), 지보 조합(숏크리트 두께 + 록볼트 강성 → 합성 지보 특성), 종방향 변위 곡선(막장 거리 → 변위 비), 소성 영역 단면 그림(Rp/a 원, 록볼트 길이 비교), 계측 데이터 해석(내공 변위 시간 곡선 → 수렴 판정, 교육용), 암반 등급별 지보 패턴 표 탐색.
**09 TBM과 도심지 터널** — TBM의 종류(개방형·실드: 토압식 EPB·이수식) / 막장 안정: 막장압과 지하수압 / 세그먼트 라이닝(링, 이음, 하중) / 지반 손실과 지표 침하: 정규 분포 곡선 S(x) = Smax exp(−x²/2i²), i = K z₀, 지반 손실률(Peck 형태) / 인접 건물 영향: 각변위·수평 변형률과 손상 등급(GeotechBook 11장 연결) / 개착식과 비교 / 환기·방재·화재(교육용) / TM-7 도심 TBM. 시뮬: 지표 침하 곡선(지반 손실·깊이·K → 곡선·Smax·침하 폭, 정규 분포), 인접 건물 손상 평가(건물 위치 끌기 → 각변위·변형률·등급), 막장압 계산(깊이·지하수 → 정지 토압 + 수압 범위, `CB.soil`), 세그먼트 링 하중(토피 → 링 축력·모멘트, 교육용 탄성 링), TBM 굴진 애니메이션(커터헤드·추진 잭·세그먼트 조립), 개착 vs TBM 비교(깊이 → 비용·영향, 교육용), 3D 도심 단면(`CB.orbit`: 터널·건물·지층).
**10 도로 계획과 교통** — 도로의 기능 분류(간선·집산·국지), 접근 관리 / 교통량 조사, AADT, 설계 시간 교통량 DHV = AADT·K·D / 교통류 이론: 속도–밀도–교통량(그린실즈, `greenshields`), 충격파 맛보기 / 용량과 서비스 수준(LOS, 교육용 기준) / 교차로: 신호 주기·포화 교통류율·웹스터 최적 주기 맛보기 / 대중교통·보행 / 교통 수요 4단계 맛보기 / R-60 교통 계획. 시뮬: 교통류 3관계(밀도 슬라이더 → 속도·교통량 곡선 위 점), 설계 시간 교통량 계산기(AADT·K·D → DHV → 차로 수), 서비스 수준(교통량/용량 → LOS 띠, 교육용), 충격파(병목 → 정체 전파 애니메이션), 신호 교차로(주기·녹색 시간 → 용량·지체, 웹스터 형태), 교통 시뮬레이션(셀 오토마타 나겔–슈레켄베르크, 밀도 → 정체파), 차로 수–용량 계획.
**11 도로 선형 설계** — 설계 속도와 설계 기준 / 시거: 정지 시거(`ssd`), 앞지르기 시거 맛보기 / 평면 선형: 원곡선(`curve`), 최소 반지름(`rMin`), 편경사와 편경사 접속, 완화 곡선(클로소이드 `clothoid`), 곡선부 확폭 / 종단 선형: 종단 경사, 오르막 차로, 종단 곡선(`vcurve`), 볼록·오목 곡선 길이(`crestL`), 정점과 최저점 / 평면·종단 조화와 운전자 시각(3D) / R-60 선형 설계. 시뮬: 정지 시거 계산기(속도·반응 시간·마찰·경사 → 공주·제동 거리 막대), 곡선 주행 힘의 평형(속도·R·편경사 → 필요 마찰, 차량 그림), 원곡선 요소 계산기(R·Δ → T, Lc, E, M, 평면도), 클로소이드 완화 곡선(A·L → 곡률 변화 그래프, 평면 그림), 종단 곡선 설계(g₁·g₂·L → 표고 그림, 시거 선, 최소 길이 판정), 3D 운전자 시점 주행(`CB.orbit` 또는 투시: 평면·종단 선형 조합), 편경사 접속 다이어그램.
**12 토공과 배수** — 횡단면 구성(차로·길어깨·측구·비탈면) / 토량 계산: 횡단면 면적, 평균 단면법·각주 공식, 토량 환산 계수(GeotechBook 2장 연결) / 토적곡선(매스 커브)과 운반 거리, 평형선, 유용토·사토 / 성토 다짐과 품질 관리, 깎기·쌓기 비탈 안정(GeotechBook 12장 연결) / 배수: 강우 강도–지속 시간, 합리식(`rational`), 측구 설계(`manning`), 암거·맹암거, 지하 배수 / E-4 성토와 R-60 구간. 시뮬: 횡단면 토량(지반선 끌기 → 깎기·쌓기 면적), 평균 단면법 vs 각주 공식, 토적곡선(측점별 토량 → 매스 커브, 평형선 끌기 → 운반량·거리), 운반 장비 계획(거리 → 장비 선택·비용, 교육용), 강우 강도 곡선과 합리식(유역·C·도달 시간 → 첨두 유량), 측구 단면 설계(유량 → 수심·유속, `manning`, 침식·퇴적 판정), 암거 수리(관경 → 통수 능력).
**13 포장 설계** — 포장의 구조(연성·강성·반강성)와 층(MaterialsBook 13장 연결) / 교통 하중: 축하중, 4제곱 법칙(`esal`), 누적 ESAL / 연성 포장 설계: AASHTO 93(`w18`, `sn`), 층 계수와 두께(`snLayers`), 신뢰도 / 역학적–경험적 설계 맛보기(층 변형률·피로 수명) / 강성 포장: 웨스터가드(`westergaard`), 줄눈과 다웰바, 온도 컬링 / 파손: 소성 변형·피로 균열·포트홀·펌핑, 포장 상태 지수(PSI·PCI), 보수 공법 / R-60 포장 설계(SN 3.47). 시뮬: 4제곱 법칙(축하중 → 손상 비, 과적 차량 효과), 누적 ESAL 계산기(교통량·성장률·차종 → 20년 ESAL), AASHTO 93 설계(MR·신뢰도·ESAL → SN, 층 두께 조합 탐색), 층별 응력·변형률(층 두께·탄성계수 → 깊이 분포, 오데마르크 근사 교육용), 웨스터가드 응력(두께·k·하중 → 내부·가장자리·모서리 응력, 교육용 형태), 포장 수명 곡선(PSI 시간 감소, 보수 시점), 연성 vs 강성 생애 비용.
**14 철도** — 철도의 특성(강철 바퀴와 레일, 낮은 마찰, 정해진 궤도) / 궤도의 구성(레일·체결 장치·침목·도상·노반)과 하중 분산: 탄성 지반 위 보(Winkler, β = (k/4EI)^(1/4)) / 곡선과 캔트: 평형 캔트 C = G V²/(127R)(형태), 부족 캔트, 완화 곡선 / 고속철도: 동적 하중, 공진, 궤도 틀림, 슬래브 궤도 vs 자갈 궤도 / 철도 교량(장대 레일 상호 작용 맛보기) / 신호와 선로 용량 맛보기. 시뮬: 레일 처짐·휨모멘트(윤하중·궤도 강성 → 탄성 지반 보 해석, 영향 거리), 침목·도상 압력 분산(침목 간격 → 분담), 평형 캔트(속도·반지름 → 캔트·부족 캔트·승차감), 곡선 최소 반지름(속도·최대 캔트), 고속 주행 공진(속도·교량 경간 → 가진 진동수, 교육용), 궤도 틀림 → 차량 응답(교육용 1자유도, `CB.dyn` 없으므로 페이지 내 모델), 3D 궤도 단면(`CB.orbit`).
**15 하천과 수공 구조물** — 수문 순환과 홍수(강우–유출, 합리식 `rational`, 단위도 맛보기) / 개수로 흐름: 매닝 공식(`manning`), 등류 수심(`normalDepth`), 비에너지와 한계 수심, 프루드 수(`froude`), 도수 / 하천 단면과 계획 홍수위, 여유고 / 제방(침투·활동 — GeotechBook 5·12장 연결) / 보·수문, 댐(중력식 안정: 전도·활동·양압력) / 교각 세굴(경험식 형태, 교육용)과 세굴 방지 / B-130 하천(Q 600 m³/s → 수심 5.15 m). 시뮬: 매닝 수로 계산기(단면·경사·조도 → 유속·유량, 단면 그림), 등류 수심 역산(유량 → 수심, 홍수위 판정), 비에너지 곡선(수심 → 비에너지, 한계 수심, 상류·사류), 합리식 홍수량(유역·강우 강도·유출 계수), 중력식 댐 안정(높이·폭 → 전도·활동·양압력, `CB.soil` 없이 페이지 내), 교각 세굴 깊이(유속·수심·교각 폭 → 세굴 깊이, 교육용 형태), 제방 침투(수위 → 침윤선, 교육용).
**16 유지관리와 성능 개선** — 기반 시설의 노후화와 생애 주기 / 점검: 정기·정밀·정밀 안전 진단(시설물안전법 형태, 확인), 상태 등급 A–E / 열화 예측: 마르코프 상태 전이(교육용), 생애 주기 비용(LCC, 할인율) / 교량 내하력 평가: 재하 시험, 내하율 RF = (C − D)/L 형태 / 보수·보강: 단면 복구, 외부 긴장, FRP(MaterialsBook 16장), 강판 / 내진 보강: 받침 교체·면진화, 교각 보강 / 스마트 계측·디지털 트윈 맛보기(BIMBook 연결) / 성수대교 1994 등 사고는 확인된 사실만 / B-130·TN-11·R-60 유지관리 계획. 시뮬: 상태 등급 마르코프 예측(전이 확률 → 연도별 등급 분포 누적 막대), 보수 시점 최적화(LCC 곡선, 할인율), 내하율 계산(저항·고정·활하중 → RF, 통행 제한 판정), 재하 시험 해석(측정 처짐 vs 계산 → 보정 계수), 보강 효과(외부 긴장력·FRP → 모멘트 강도 증가, `CB.section`), 계측 이상 탐지(시계열 + 온도 보정, 교육용), 시설별 예산 배분(우선순위 점수).
**17 용어집 & 종합 퀴즈** — 공식·수치 한눈표(트럭·충격·영향선, 케이블, 커쉬·지반 반응 곡선, 시거·곡선·종단 곡선, 교통류, ESAL·AASHTO·웨스터가드, 매닝·합리식, 기준 시설 결과), 부호 규약, 용어 검색, 종합 퀴즈. `../concrete/chapters/glossary.html` 구조를 따른다.

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `civil/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
