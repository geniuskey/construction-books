# StructureBook 챕터 작성 가이드

StructureBook은 ConstructionBooks 서가(`construction.euiyun.com`)의 네 번째 권인 건축구조 교과서다. 배포 주소는 `https://construction.euiyun.com/structure/`. 엔진·CSS·장 구성 규칙은 앞 권(`../mechanics/`, `../materials/`, `../geotech/`)을 물려받았다. 전역 객체 `CB`와 구조 해석기(`CB.frame`/`CB.beam`/`CB.truss`/`CB.section`, `CB.drawFrame`, `CB.orbit`)가 그대로 있고, 이 책에서 **구조 동역학과 횡하중 모델** `CB.dyn`(1자유도 진동, 뉴마크 시간 이력, 응답 스펙트럼, 전단 건물 모드 해석, 설계 응답 스펙트럼, 등가 정적 해석, TMD)과 `CB.wind`(풍속 분포, 속도압, 층 풍하중, 와류)를 더했다. (재료·지반 모델 `CB.conc`, `CB.soil`은 이 책에 없다.) 본보기는 `../mechanics/chapters/beam-forces.html`, `../mechanics/chapters/matrix.html`, `../geotech/chapters/consolidation.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 역사·수치·기준 조항은 확인된 것만 쓴다(확실하지 않으면 쓰지 않거나 "약", "교육용 가정"으로 표시한다).

## 구조

빌드 없이 열리는 정적 페이지다. `index.html` + `chapters/<slug>.html` + `css/style.css`(앞 권과 같고 강조색만 청록 `#0b7285`, 보조색 안전 주황 `#e8590c`) + `js/common.js`(전역 `CB`, 장 목록 `CHAPTERS`). classic script만 쓴다. 외부 라이브러리는 쓰지 않는다(KaTeX는 빌드가 처리). 3D는 `CB.orbit`으로 그린다 — 이 책은 건물 전체를 다루므로 장마다 3D 장면을 적극적으로 쓴다(B-10 골조, 코어, 아웃리거, 대공간 지붕, 모드 형상 애니메이션).

- 장 목록은 `js/common.js`의 `CHAPTERS`에 있다.
- 용어는 `js/glossary-data.js`(시리즈 공통 v1). 본문에서 처음 나오는 용어는 `<span class="term">…</span>`. 장의 용어는 `js/glossary/<slug>.json`(용어 객체 `{"ko","en","abbr","def","chapters":["<slug>"]}`의 배열)에 적고, `tools/merge-glossary.py structure`가 합친다. `en`은 대문자로 시작, `abbr`에 밑줄 금지. 같은 개념을 띄어쓰기만 다르게 두 번 넣지 않는다(예: "층간 변위"로 통일). 앞 권 용어(하중 조합, 좌굴 등)는 건축구조 관점으로 다시 정의하되 모순되지 않게 한다.

## 원칙: 시스템 → 하중 → 응답 → 판단

건축구조는 "건물 전체가 하나의 구조 시스템으로 하중을 어떻게 나르고, 흔들릴 때 어떻게 응답하며, 그 응답을 어떻게 설계 기준으로 판단하는가"를 다룬다. MechanicsBook이 부재 하나를 풀었다면, 이 책은 **시스템을 고르고(3D 장면) → 하중을 정하고(기준 형태의 식) → 해석해 응답을 보고(시뮬레이터, `CB.frame`·`CB.dyn`) → 기준과 성능으로 판단하는** 순서로 쓴다. 기준 건물 B-10의 구조 계획, 횡하중, 내진 설계를 책 전체가 따라간다.

- 한국어, 대상은 건축공학 3학년과 구조 설계를 다시 공부하는 신입 엔지니어(구조역학·재료·기초 지식을 안다고 가정, 앞 권 링크). 영어 원어는 `<span class="en">(Base shear)</span>`처럼 병기.
- 장 첫머리는 `.origin`("이 계산이 없었다면" 또는 "이 시스템이 없었다면")으로 연다. 각 절은 가능하면 `.problem`으로 시작.
- 흐름: 문제 → 그림(SVG) → **조작하는 시뮬레이터** → 정의·원리(KaTeX) → **손으로 푸는 예제**(`.callout`, 단계별, 단위까지) → 기준 구조물 노트(`.callout.site`) → 쓰이는 곳(`.uses`) → 핵심 정리 → 확인 퀴즈(8문항).
- 정의·원리는 `<div class="callout def"><strong>원리 7.2 (모드 직교성)</strong> …</div>`처럼 장 번호.순번. `.callout.deep`은 심화. 예제 `예제 7.1`, 그림 `그림 7-1.`.
- 장마다 **시뮬레이터 7–8개, 그림 6개 이상, 퀴즈 8문항.** 시뮬레이터는 계산하는 모델이다. 입력을 끝까지 움직여도 NaN·음수 주기·0으로 나누기가 없어야 한다. 무거운 계산(모드 해석, 시간 이력, 스펙트럼)은 입력이 바뀔 때만 다시 하고 프레임마다 하지 않는다(애니메이션은 결과를 재생).
- 구조 계산은 `CB.frame`(2D 골조)·`CB.beam`·`CB.truss`·`CB.section`과 `CB.dyn`·`CB.wind`로 한다. 장 고유 모델(포털법, 벽–골조 상호작용, 슬래브 계수법, 바닥 진동 기준, 면진 받침 이력, 연쇄 붕괴 시나리오)은 페이지 스크립트에 둔다.
- 색은 CSS 변수와 `CB.palette()`만. 라이트/다크 모두 확인. 폭 360px 가로 스크롤 금지. SVG는 `viewBox`만, 폭 900 이하.
- 시뮬레이터 `id`는 `sim-<접두사>-<이름>`, 요소 id·전용 CSS 클래스도 접두사. 절 `id`는 의미 있는 영어 슬러그.

## 단위·부호·색 규약 (책 전체 공통)

**단위.** 힘 kN, 길이 m(단면 mm), 모멘트 kN·m, 면 하중 kN/m², 응력 MPa, 질량 t(= kN·s²/m), 강성 kN/m, 주기 s, 진동수 Hz, 가속도는 g 배수 또는 m/s²(밝힌다), 풍속 m/s, 속도압 kN/m². 층간 변위비는 % 또는 소수.

**부호.** MechanicsBook 규약을 그대로 쓴다(전역 x 오른쪽, y 위, 반시계 +, 인장 +, 휨모멘트도는 구조물 위 인장측). 수평 하중은 왼쪽에서 오른쪽(+x)을 기본 방향으로 그린다. 층 번호는 1층이 아래, 지붕이 위(배열 인덱스 0 = 1층).

**색.** 앞 권과 같다: 하중 `accent2`(주황), 반력 `ok`, 인장 `tension`(파랑)·압축 `compression`(빨강), 휨모멘트 `accent`, 변형 형상 `accent` 점선. 더해서: 바람 `blue` 계열 화살표, 지진 지반 운동 `accent2`, 모드 형상 1·2·3차는 `accent`·`accent2`·`ok`, 감쇠기·면진 장치 `warn`, 판정 합격 `ok`·불합격 `bad`.

**01 건축 구조의 이해** — 구조가 하는 일(중력·횡하중을 땅까지, 강도·강성·안정·연성) / 구조 형식의 분류(가구식·일체식·조적식, 라멘·벽식·가새·튜브·대공간) / 재료와 시스템의 조합(RC·강·합성·목) / 구조 계획의 순서(그리드·코어 위치·부재 크기 가정 → 해석 → 설계 → 상세) / 부재 크기 가늠(보 춤 L/12–L/15, 슬래브 L/30–L/35, 기둥 축력 비 — 경험값, 교육용) / 한계상태: 강도·사용성, 강도 설계 φRn ≥ Σγ Qi, 허용응력 설계와 비교 / 하중 경로 다시 보기(MechanicsBook 1장 연결) / 설계 도서(구조 계산서·도면) / B-10의 구조 계획과 이 책의 지도. 시뮬: B-10 3D 구조 시스템 탐색(`CB.orbit`: 골조·코어·슬래브 켜고 끄기, 부재 클릭 → 크기·하중), 시스템 고르기(층수 → 적합한 시스템 띠, 교육용 도표), 부재 크기 가늠 계산기(경간·하중 → 보 춤·슬래브 두께·기둥 단면), 같은 하중에 RC·강·목 골조 비교(부재 크기·무게), 강도 설계 vs 허용응력 설계(하중 비·변동 → 안전 여유 비교), 코어 위치에 따른 비틀림 맛보기(코어 끌기 → 강성 중심 이동), 그리드 계획(경간 바꾸기 → 기둥 수·보 춤·층고).
**02 설계 하중과 하중 조합** — 하중의 분류와 지속 시간 / 고정하중 산정(재료 단위중량 × 두께, 마감·설비) / 활하중: 용도별 값(사무실·주거·주차장 등 — 확실한 값만), 활하중 저감(영향 면적, 기준 형태), 부분 재하 / 적설 하중(지붕 형상·노출, 개요) / 풍하중·지진하중 개요(6·8장 연결) / 온도·부등 침하 등 기타 하중 / 하중 조합 1.4D, 1.2D + 1.6L + 0.5S, 1.2D + 1.0W + L, 0.9D + 1.0W, 1.2D + 1.0E + L, 0.9D + 1.0E(KDS 형태, 기준 확인) / 신뢰도 이론 맛보기: 하중·저항의 확률 분포, 신뢰도 지수 β, 하중 계수가 생긴 이유 / B-10 기둥 C1의 하중 집계(층별 누적, 활하중 저감). 시뮬: 바닥 하중 쌓기(마감층 선택 → 고정하중 kN/m²), 활하중 저감 계산기(영향 면적 → 저감 계수, 층수 누적), 하중 조합 탐색기(D·L·W·E 크기 → 모든 조합 막대, 지배 조합 강조, 0.9D 조합으로 들림 검토), 신뢰도 지수(하중·저항 평균·변동 계수 → 파괴 확률 면적, `CB.normCdf`), 부분 재하(연속보 경간마다 활하중 켜기 → 최대 모멘트, `CB.beam`), 기둥 축력 누적(B-10 층 수·기여 면적 → 1층 축력, 저감 적용), 적설 지붕 형상 계수(지붕 경사·형상 → 눈 하중 분포, 교육용).
**03 바닥 구조** — 바닥이 하는 일(연직 하중 분배 + 수평 격막) / 1방향·2방향 슬래브 판별(장단변비 2) / 2방향 슬래브 모멘트: 직접 설계법 개념(정적 모멘트 M₀ = wℓ₂ℓn²/8, 주열대·중간대 분배), 계수법 맛보기 / 플랫 플레이트·플랫 슬래브, 뚫림 전단(임계 단면 d/2), 드롭 패널·전단 머리 / 보 배치(큰보·작은보), 바닥 판의 경제적 경간 / 데크 플레이트·합성 슬래브, 중공·PT 슬래브 맛보기 / 처짐(MechanicsBook 11장, 장기 처짐 MaterialsBook 8장) / 바닥 진동: 보행 하중, 바닥 고유 진동수 f ≈ 18/√δ(mm), 3 Hz·8 Hz 기준 형태, 가속도 한계(교육용) / B-10 210 mm 슬래브. 시뮬: 슬래브 판별과 하중 분담(장단변비 → 1방향/2방향, 45° 분담선 그림), 2방향 슬래브 정적 모멘트 분배(경간·하중 → M₀, 부/정 모멘트, 주열대/중간대 막대), 뚫림 전단 검토(기둥 크기·슬래브 두께·드롭 패널 → 임계 둘레·전단 응력 비), 보 배치 비교(작은보 유무·방향 → 보 춤·슬래브 두께·콘크리트 물량), 합성 슬래브 단면(데크 형상·콘크리트 두께 → 자중·강성, `CB.section`), 바닥 진동(경간·두께·질량 → 고유 진동수·보행 가속도, 기준선과 비교), 처짐 계산(경간 바꾸기 → 즉시·장기 처짐, `CB.beam`).
**04 모멘트 골조** — 강절점 골조가 수평 하중을 받는 방식(기둥 휨, 보의 구속) / 수평 하중 아래 변형 형상과 반곡점 / 근사 해석: 포털법(반곡점 중앙, 내부 기둥 전단 2배), 캔틸레버법(축력 ∝ 도심 거리) / `CB.frame`으로 정해와 비교 / 층 강성과 층간 변위, 보–기둥 강성 비의 영향(보가 강하면 전단형, 약하면 휨형) / 강기둥–약보(ΣMc ≥ 1.2ΣMb 형태)와 소성 힌지 위치, 층 붕괴 메커니즘 / 패널 존 / P–Δ 효과와 안정 계수 θ / 연직 하중 + 수평 하중 조합 / B-10 Y 방향 골조 한 줄의 풍하중·지진하중 해석. 시뮬: 다층 골조 수평 하중 해석기(층 수·경간 수·보/기둥 단면 → 변형·BMD·층간 변위, `CB.frame`), 포털법 vs 강성법(같은 골조, 기둥 전단·모멘트 비교 표), 캔틸레버법 기둥 축력, 보–기둥 강성 비 슬라이더(변형 형상이 전단형 → 휨형), 소성 힌지 메커니즘(강기둥/약기둥 → 보 힌지 vs 층 붕괴 애니메이션), P–Δ 증폭(중력 하중 비 → θ, 증폭 1/(1 − θ)), 반곡점 위치 탐색(1층 기둥 반곡점 높이 vs 지점 조건).
**05 전단벽·코어·튜브** — 전단벽의 거동(휨형 캔틸레버), 벽의 강성(휨 + 전단 변형) / 벽–골조 상호작용: 아래는 벽이, 위는 골조가 잡는다(벽은 휨형, 골조는 전단형), 이중 골조 / 코어의 비틀림 강성과 위치 / 개구부가 있는 벽과 연결보(coupling beam) / 아웃리거와 벨트 트러스: 기둥을 동원해 전도 모멘트를 나눈다, 최적 위치 / 튜브 구조: 골조 튜브, 가새 튜브, 묶음 튜브, 전단 지연(shear lag) / 높이와 구조 시스템(Fazlur Khan의 도표 개념, 교육용) / 초고층 사례는 확인된 사실만 / B-10 코어 16 × 8 m의 횡하중 분담. 시뮬: 벽 vs 골조 변형 형상(같은 수평 하중, 휨형·전단형 곡선), 벽–골조 상호작용(벽 강성 비 → 층별 분담률 곡선, `CB.frame`에 벽을 기둥 요소로), 연결벽(연결보 강성 → 연결 정도·전도 모멘트 분담), 아웃리거 위치 최적화(아웃리거 높이 끌기 → 지붕 변위·코어 밑 모멘트), 튜브 전단 지연(평면 기둥 축력 분포, 3D `CB.orbit`), 코어 위치와 비틀림(코어 끌기 → 강성 중심·편심·비틀림 회전), 높이–시스템 선택 도표(층수 → 단위 면적당 강재량 곡선, 교육용).
**06 풍하중과 바람의 영향** — 바람의 성질: 대기 경계층, 평균 풍속 + 난류, 노풍도 / 기본 풍속과 재현 기간 / 높이에 따른 풍속(멱법칙, `CB.wind.speed`), 속도압 q = ½ρV²(`CB.wind.q`) / 풍압 계수: 풍상·풍하·측면·지붕, 외압·내압 / 가스트 영향 계수와 동적 응답 / 층 풍하중(`CB.wind.storyForce`)과 밑면 전단·전도 모멘트 / 국부 풍압과 외장재 / 와류 방출과 공진(`vortexFreq`, 스트로할 수), 횡풍 진동, 갤로핑 맛보기 / 건물 가속도와 거주성(진동수–가속도 기준 곡선 형태, 교육용) / 풍동 실험, 공력 형상 개선(모서리 깎기, 테이퍼) / 타코마 교량 1940(확인된 사실만) / B-10 풍하중(층마다 약 220 kN, Y 방향). 시뮬: 풍속 높이 분포(노풍도·V₀ → 프로파일, 속도압), 건물 주위 풍압 분포(평면 그림, 풍향 바꾸기 → 면별 풍압 계수 화살표), 층 풍하중과 밑면 전단(B-10 높이·폭 → 층 하중 막대, 지진하중과 비교), 와류 공진(풍속 슬라이더 → 방출 진동수와 건물 고유 진동수 교차, 공진 풍속), 가스트(난류 풍속 시계열 → 순간 최대 / 평균), 거주성 판정(고유 진동수·가속도 → 기준 곡선 위 점), 공력 형상 비교(단면 모양 → 횡풍 응답 지수, 교육용).
**07 구조 동역학** — 왜 동역학인가(하중이 시간에 따라 변할 때) / 1자유도: 운동 방정식 mü + cu̇ + ku = p(t), 고유 진동수·주기(`CB.dyn.sdof`), 자유 진동과 감쇠(대수 감쇠율) / 조화 하중과 공진, 동적 증폭 계수(`Rd`) / 지반 운동: 상대 변위, 유효 하중 −mü_g / 수치 해법: 뉴마크 평균 가속도법(`newmark`) / 응답 스펙트럼: 정의, 만들기(`spectrum`), 변위·의사 속도·의사 가속도 / 다자유도: 전단 건물(`shearBuilding`), 고유값 문제, 모드 형상과 직교성(`modes`), 모드 참여 계수와 유효 질량, 모드 중첩, SRSS(`srss`) / 감쇠의 종류와 크기(RC 약 5 %) / B-10 모드 해석(T₁ = 1.00 s). 시뮬: 1자유도 자유 진동(m·k·ζ → 감쇠 진동 곡선과 애니메이션), 공진 곡선(진동수 비 → Rd, ζ별 곡선), 지진 시간 이력(인공 지진파 `quake` + 주기·감쇠 → 변위·가속도 이력, 최대값), 응답 스펙트럼 만들기(주기마다 최대 응답이 점으로 찍히는 애니메이션), 전단 건물 모드 형상(층 수·질량·강성 → 1–3차 모드 애니메이션, 주기·유효 질량, `modes`), 모드 중첩 시간 이력(각 모드 기여 막대), 감쇠 측정(자유 진동 곡선에서 대수 감쇠율 → ζ).
**08 내진 설계** — 지진 피해에서 배운 것(확인된 사실만) / 내진 설계의 철학: 작은 지진에 손상 없이, 큰 지진에 붕괴 없이 / 설계 지진: 지진 구역·재현 주기, 지반 증폭, 설계 응답 스펙트럼(`designSa`, SDS·SD1) / 중요도와 내진 등급 / 연성과 반응수정계수 R, 등에너지·등변위 원리, Ω₀·Cd / 등가 정적 해석(`Ta`, `els`): Cs, 밑면 전단력, 수직 분포, 전도 모멘트 / 응답 스펙트럼 해석과 비교 / 층간 변위 제한(Cd 증폭) / 비정형성: 평면(비틀림·요철), 수직(연층·약층·질량) — 필로티 사례 / 내진 상세: 띠철근 간격, 135° 갈고리, 강기둥–약보 / 비구조 요소 / 성능 기반 설계 맛보기(푸시오버) / B-10 등가 정적 해석(V ≈ 5,000 kN). 시뮬: 설계 응답 스펙트럼(SDS·SD1·TL → 곡선, 건물 주기 점 끌기), 등가 정적 해석기(B-10 기본값, R·Ie·T → Cs·V·층 지진력 막대·전단력도), R과 연성(탄성 응답 vs 항복 강도 → 등변위·등에너지 그림), 층간 변위 검토(층 강성 → 탄성 변위 × Cd/Ie → 허용 한계 비교), 연층 필로티(1층 강성 비 → 층간 변위 집중, 모드 형상), 푸시오버 곡선(교육용 이선형 골조 → 용량 곡선과 성능점), 비틀림 비정형(편심 → 가장자리 변위비).
**09 면진과 제진** — 지진 에너지를 피하거나 흡수하는 두 전략 / 면진의 원리: 주기 이동과 변위 증가, 전달률(`TR`) / 면진 장치: 적층 고무 받침(LRB·고감쇠 고무), 마찰 진자(FPS: T = 2π√(R/g)), 이력 곡선 / 면진층 설계 개념(유효 강성·유효 감쇠, 변위 요구) / 제진: 점성 감쇠기(F = cv^α), 마찰 감쇠기, 이력(강재) 감쇠기, 좌굴 방지 가새(BRB) / 동조 질량 감쇠기(TMD, `tmdOpt`, `tmdResponse`)와 동조 액체 감쇠기, 초고층 사례(확인된 사실만) / 능동·반능동 제어 맛보기 / 성능 비교: 가속도·변위·층간 변위 / B-10을 면진·제진했을 때. 시뮬: 면진 전후 스펙트럼 이동(면진 주기·감쇠 → 가속도 감소·변위 증가, `designSa`), 전달률 곡선(진동수 비·감쇠), 면진 받침 이력 곡선(LRB 이선형, 반복 변위 → 소산 에너지 넓이), 마찰 진자(곡률 반경 → 주기, 진자 애니메이션), 감쇠기 비교(점성·마찰·이력 F–u 루프), TMD 튜닝(질량비·진동수비·감쇠 → 주 구조 증폭 곡선, 덴 하르톡 최적, `tmdResponse`), 시간 이력 비교(B-10 일반 vs 면진 vs 감쇠기 → 지붕 가속도, `newmark`).
**10 강구조 시스템** — 강구조의 장단점 / 골조 형식: 모멘트 골조, 중심 가새(X·V·역V), 편심 가새(링크), 좌굴 방지 가새 / 부재 설계 개념(LRFD, KDS 41 31 형태, 기준 확인): 인장재(총단면 항복·순단면 파단), 압축재(세장비와 좌굴, 휨 좌굴 곡선 — MechanicsBook 13장 연결), 휨재(소성 모멘트, 횡비틀림 좌굴과 비지지 길이), 조합력 상호작용 / 접합: 고장력 볼트(마찰·지압), 용접(필릿·완전 용입), 전단 접합과 모멘트 접합 / 기둥 이음·주각 / 내화 피복 / 강재 물량과 경제성 / L-60 지붕이나 강구조 변형안 B-10S(교육용) 예제. 시뮬: 골조 형식 비교(같은 높이·하중, 모멘트·X 가새·V 가새·편심 가새 → 변위·강재량, `CB.frame`), 압축재 설계 강도 곡선(세장비 → Fcr, 탄성/비탄성), 횡비틀림 좌굴(비지지 길이 → Mn 곡선, Lp·Lr 구간), 인장재 순단면(볼트 구멍 배치 → 파단 경로), 볼트 접합(볼트 수·배치 → 전단·지압·편심 하중 분배), 필릿 용접 강도(다리 길이·길이 → 강도), 가새 좌굴과 BRB(이력 곡선 비교).
**11 합성 구조와 프리캐스트** — 합성의 원리: 콘크리트는 압축, 강은 인장, 미끄럼을 막는 전단 연결재 / 합성보: 유효 폭, 완전·부분 합성, 소성 중립축, 전단 연결재(스터드) 개수 / 합성 슬래브(데크) / 합성 기둥: CFT(구속 효과), SRC / 프리캐스트 콘크리트: 부재 종류(더블 티·중공 슬래브·PC 기둥·보), 접합부(습식·건식), 일체성과 연쇄 붕괴 / 프리스트레스의 개념: 편심 긴장력과 응력 분포, 손실 맛보기 / 모듈러 공법과 연결(13장) / B-10 바닥을 합성보 + 데크로 바꾸면. 시뮬: 합성보 단면(유효 폭·슬래브 두께·강재 → 소성 중립축·Mn, `CB.section`), 완전 vs 부분 합성(스터드 수 → 미끄럼·강도·강성), 스터드 배치(전단 흐름 → 간격), CFT 구속 효과(강관 두께 → 콘크리트 강도 증가, 축력 곡선), 프리스트레스 응력(긴장력·편심 → 상하연 응력, 하중 추가, `CB.section`), PC 부재 접합(접합 방식 → 일체성·연속성 비교), 프리캐스트 바닥 경간표(부재 종류·경간 → 춤·자중).
**12 대공간 구조** — 경간이 커지면 자중이 지배한다 / 깊이–경간 비와 형식 선택 / 트러스(MechanicsBook 3장 연결)와 입체 트러스·스페이스 프레임 / 아치·볼트와 추력, 타이 / 쉘: 막 응력, 돔(자오선·위선 응력), 원통 쉘, 쌍곡 포물면 / 케이블 구조: 현수 지붕, 케이블 넷, 케이블 돔, 프리스트레스로 강성 / 막 구조: 프리스트레스 막, 공기막 / 형태 찾기(퓨니큘러, 역현수) / 적설·바람(흡인)과 들림 / 대공간 사례(확인된 사실만) / L-60 체육관 지붕. 시뮬: 경간–형식 선택(경간 → 트러스 춤·아치 높이·자중 비교 막대), 트러스 지붕 해석(L-60, 춤 바꾸기 → 현재력·처짐, `CB.truss`), 아치 추력(높이/경간 → 추력·휨, 타이 유무, `CB.frame`), 돔 막 응력(구형 돔 위도 → 자오선·위선 응력, 인장으로 바뀌는 51.8°), 케이블 지붕(처짐비·프리스트레스 → 장력·강성), 형태 찾기(하중 배치 → 퓨니큘러 곡선 → 뒤집은 아치), 3D 스페이스 프레임 처짐(`CB.orbit`, 그리드 크기).
**13 목구조와 모듈러 건축** — 목구조의 형식: 경골 목구조(2×4 계열), 중목·매스 팀버, CLT 벽식, 하이브리드 / 목재의 설계 특성(MaterialsBook 14장 연결): 하중 지속 기간, 함수율, 크리프 / 접합: 못·볼트·철물, 접합부 강성과 연성 / 목조 벽의 수평 저항(전단벽, 홀다운) / CLT 패널 바닥·벽, 진동과 차음 / 고층 목조 사례(확인된 사실만) / 화재: 탄화와 내화 피복 / 모듈러 건축: 공장 제작, 유닛 구조(철골·RC·목), 적층 방식, 운송·양중 하중, 유닛 간 접합과 횡력 전달, 공차 / 탄소와 공기 / B-10과 같은 규모를 목조·모듈러로 바꾸면. 시뮬: 목조 전단벽 강성(못 간격·합판 두께 → 수평 강성·강도), 홀다운 인발력(벽 길이·수평력 → 인발), CLT 바닥 경간표(층 수·두께 → 처짐·진동 진동수), 접합부 하중–미끄럼(못·볼트·철물 곡선), 모듈러 적층(유닛 수 → 하부 유닛 축력·접합 전단), 양중 하중(인양점 위치 → 유닛 휨, `CB.beam`), 재료별 무게·탄소 비교(같은 바닥 면적).
**14 구조 해석 모델링** — 실제 건물 → 해석 모델(MechanicsBook 16장 연결) / 부재 모델링: 보·기둥 선 요소, 벽 판 요소 또는 등가 기둥, 강역(rigid end zone), 균열 단면 강성 저감(교육용 계수) / 바닥: 강막(rigid diaphragm) 가정과 한계 / 질량 중심과 강성 중심, 편심과 비틀림, 우발 편심 / 지점 조건과 지하층·기초 모델 / 하중 입력: 면 하중 분배, 질량 원 / 해석 종류: 선형 정적, 응답 스펙트럼, 시간 이력, 비선형 맛보기 / 결과 검증: 평형(밑면 반력 = 하중 합), 손계산 대조, 고유 주기 상식, 변형 애니메이션 / 흔한 실수(단위, 지점, 중복 하중, 강막 오용) / B-10 3D 모델. 시뮬: 강막 바닥과 기둥 분담(평면 기둥 강성 → 층 전단 분배·비틀림, 강막 vs 유연 바닥), 질량 중심·강성 중심(기둥·벽 배치 끌기 → 두 중심과 편심, 비틀림 회전), 균열 강성 저감(저감 계수 → 주기·변위·부재력 변화), 강역 효과(강역 길이 → 골조 변위), 해석 결과 검증 체크리스트(하중 합 vs 반력 합, 의도적 오류 찾기 게임), 모델 단순화 비교(전체 3D vs 평면 골조 한 줄 → 분담 차이), B-10 3D 변형 애니메이션(`CB.orbit`, 하중 방향·모드).
**15 사용성** — 사용성 한계상태 / 처짐 제한(L/240·L/360·L/480, 비구조재 손상, 기준 확인) / 균열 폭(개념, ConcreteBook 연결) / 바닥 진동: 보행 진동수(1.6–2.4 Hz), 고조파, 공진과 가속도 한계(사무실·쇼핑몰, 교육용) / 보도교 진동: 연직·수평, 런던 밀레니엄 브리지 2000(확인된 사실만: 개통 직후 수평 진동, 감쇠기로 보강), T-36의 연직 진동수 / 건물 횡변위·가속도(풍하중, 6장 연결) / 기둥 축소(탄성·크리프·수축)와 보정 / 신축 이음과 온도 / 차음·진동 기계실 맛보기 / B-10 바닥, T-36 보도교, 10층 기둥 축소. 시뮬: 처짐 제한 검토(경간·EI·하중 → 처짐과 L/n 선, `CB.beam`), 보행자 하중과 바닥 응답(보행 진동수 → 공진 증폭, 가속도 vs 한계), T-36 보도교 고유 진동수(질량·강성 → 연직 1차 진동수, 보행 대역과 겹침 판정, `CB.truss` 정적 처짐으로 레일리 근사), 군중 동기화 수평 진동(사람 수 → 임계 군중, 교육용), 기둥 축소 누적(층별 시공 순서 → 기둥·코어 차등 축소, 보정량), 온도 신축(길이·온도 차 → 신축량, 이음 간격), 횡변위 거주성(풍하중 층간 변위·가속도).
**16 화재·연쇄 붕괴와 보강** — 화재 시 구조: 표준 화재 곡선(ISO 834), 강재·콘크리트의 고온 강도(MaterialsBook 10장 연결), 내화 시간과 피복, 성능 기반 내화 설계 맛보기 / 연쇄 붕괴: 로넌 포인트 1968(확인된 사실만), 대체 하중 경로, 기둥 제거 시나리오, 연결부 연속성(타이), 캐터너리 작용 / 안전 진단: 육안·비파괴 시험, 내력 평가, 재하 시험 / 보수·보강 공법: 단면 증설, 강판 부착, FRP 보강(MaterialsBook 16장 연결), 내진 보강(벽 증설·가새·감쇠기) / 리모델링·용도 변경과 하중 증가 / 사례 학습은 확인된 사실만 / B-10의 기둥 하나가 없어진다면. 시뮬: 화재 곡선과 부재 온도(피복 두께 → 강재 온도 시간 곡선, 임계 온도), 고온 강도 저감 곡선(강·콘크리트 비교), 기둥 제거 대체 경로(B-10 골조 한 줄, 기둥 클릭 제거 → 재해석 `CB.frame`, 보 모멘트 증가와 판정), 캐터너리 작용(처짐 → 축력·수직 저항), 보강 공법 비교(보 단면 증설 vs 강판 vs FRP → 강도 증가·무게), 내진 보강 효과(벽·가새 추가 → 층간 변위 감소, `CB.frame`), 재하 시험 판정(하중–처짐 곡선, 잔류 처짐 비).
**17 용어집 & 종합 퀴즈** — 공식·수치 한눈표(하중 조합, 부재 크기 가늠, 포털법, 1자유도·모드 식, 설계 스펙트럼과 등가 정적 해석 단계와 B-10 값, 풍하중 단계, 면진·TMD 식, 사용성 한계), 부호 규약, 용어 검색, 종합 퀴즈. `../geotech/chapters/glossary.html` 구조를 따른다.

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `structure/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
