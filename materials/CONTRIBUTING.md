# MaterialsBook 챕터 작성 가이드

MaterialsBook은 ConstructionBooks 서가(`construction.euiyun.com`)의 두 번째 권인 건설재료 교과서다. 배포 주소는 `https://construction.euiyun.com/materials/`. 엔진·CSS·장 구성 규칙은 MechanicsBook(`../mechanics/`)을 그대로 물려받았다. 전역 객체 `CB`, 구조 해석기(`CB.frame`/`CB.beam`/`CB.truss`/`CB.section`)도 그대로 있고, 이 책에서 **재료 모델**(`CB.conc`, `CB.agg`, `CB.steel`, `CB.asph`, `CB.mixRule`, `CB.wall`, `CB.dewPoint`)을 더했다. 문체·구성·그림·시뮬레이터 수준의 본보기는 `../mechanics/chapters/beam-forces.html`과 `../mechanics/chapters/stress-strain.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 역사·수치·기준 조항은 확인된 것만 쓴다(확실하지 않으면 쓰지 않거나 "약", "교육용 가정"으로 표시한다).

## 구조

빌드 없이 열리는 정적 페이지다. `index.html` + `chapters/<slug>.html` + `css/style.css`(MechanicsBook과 같고 강조색만 슬레이트 청회색 `#3f6177`, 보조색 안전 주황 `#e8590c`) + `js/common.js`(전역 `CB`, 장 목록 `CHAPTERS`). classic script만 쓴다(ES module 금지). 외부 라이브러리는 쓰지 않는다(KaTeX는 빌드가 처리). 3D는 `CB.orbit`(캔버스 2D 투시)으로 그린다.

- 장 목록은 `js/common.js`의 `CHAPTERS`에 있다. 아직 쓰지 않은 장은 `planned: true`로 두면 목차에만 보인다.
- 용어는 `js/glossary-data.js`(시리즈 공통 v1: `ko`, `en`, `abbr`, `def`, `chapters`)에 있다. 본문에서 처음 나오는 용어는 `<span class="term">…</span>`. 장을 쓸 때는 그 장의 용어를 `js/glossary/<slug>.json`(용어 객체의 배열)에 따로 적고, 합치는 일은 `tools/merge-glossary.py`가 한다(같은 `ko`는 하나로, `chapters`는 합친다). MechanicsBook에 이미 있는 용어(응력, 변형률, 탄성계수, 포아송비, 항복 등)는 정의를 재료 관점으로 새로 쓰되 모순되지 않게 한다.

## 원칙: 재료 → 시험 → 숫자 → 구조물

건설재료는 "무엇으로 짓는가, 그 재료는 얼마나 버티는가"를 다룬다. 이 책은 재료를 **만들고(배합·제조) → 시험하고(시편을 깨뜨리고 곡선을 읽고) → 숫자로 판정하고(기준·통계) → 실제 구조물에서 만나는**(기준 건물 B-10, 기준 교량 T-36, 기준 배합 M-30, 기준 포장 P-13) 순서로 쓴다. 미시 구조(수화물, 결정립, 세포벽)를 거시 성질(강도·강성·내구성)로 잇는 설명을 장마다 한 번 이상 넣는다.

- 한국어, 대상은 건축·토목 2학년과 현장·품질 관리를 다시 공부하는 신입 엔지니어(고등학교 화학·물리, 구조역학 7장 수준의 응력·변형률을 안다고 가정). 영어 원어는 `<span class="en">(Hydration)</span>`처럼 병기.
- 장 첫머리는 `.origin`("이 재료가 없었다면" 또는 "이 시험이 없었다면")으로 연다. 각 절은 가능하면 `.problem`(현장의 질문)으로 시작한다.
- 흐름: 문제 → 그림(SVG) → **조작하는 시뮬레이터** → 정의·원리(KaTeX) → **손으로 푸는 예제**(`.callout` 안에 단계별, 단위까지) → 기준 구조물 노트(`.callout.site`) → 쓰이는 곳(`.uses`) → 핵심 정리 → 확인 퀴즈(6–8문항).
- 교과서다운 엄밀함: 정의·원리·정리는 `<div class="callout def"><strong>정의 4.2 (물–결합재비)</strong> …</div>`처럼 **장 번호.순번**을 붙인다. `.callout.deep`은 "심화 · " 접두어가 붙는 심화 내용(유도·예외·고급 주제)에만 쓴다. 예제는 `예제 4.1`, 그림은 `그림 4-1.`.
- 장마다 **시뮬레이터 6–8개, 그림 6개 이상, 퀴즈 6–8문항.** 시뮬레이터는 장식이 아니라 **계산하는 모델**이다. 숫자를 바꾸거나 점을 끌면 그림과 값이 바로 반응해야 하고, 입력을 끝까지 움직여도 NaN·음수 질량·0으로 나누기가 나오면 안 된다. 쓰는 식은 본문이나 `sim-note`에 적는다.
- 재료 모델은 `CB.conc`/`CB.agg`/`CB.steel`/`CB.asph`로 계산한다(장 고유의 모델 — 수화 동역학, 입도 최적화, 블리딩, 온도 해석, 확산, 점탄성, 함수율 평형 등 — 은 페이지 스크립트에 둔다). 같은 공식을 장마다 다시 구현하지 않는다. 구조 계산이 필요하면 `CB.beam`/`CB.frame`/`CB.section`을 쓴다.
- 색은 CSS 변수와 `CB.palette()`만. 라이트/다크 모두 확인. 폭 360px에서 가로 스크롤 금지. SVG는 `viewBox`만 주고 width/height 생략, viewBox 폭은 900 이하.
- 시뮬레이터 `id`는 `sim-<장 접두사>-<이름>`, 캔버스·입력 등 요소 id도 같은 접두사를 붙인다(`mx-cv-vol`, `mx-wb`). 이 장 전용 CSS 클래스도 접두사를 붙인다(`.mx-bar`). 절 `id`는 의미 있는 영어 슬러그로 짓고 바꾸지 않는다.

## 단위·부호·색 규약 (책 전체 공통)

**단위.** 응력·강도 MPa(= N/mm²), 탄성계수 MPa 또는 GPa(본문에서 밝힌다), 변형률은 무차원 또는 με(10⁻⁶)·‰, 질량 kg, 배합은 kg/m³(콘크리트 1 m³당), 밀도 g/cm³ 또는 kg/m³, 길이 mm(부재·피복·깊이), 시간은 재령 일(day)·내구성 연(year), 온도 °C, 열전도율 W/(m·K), 열관류율 W/(m²·K). 힘이 나오면 MechanicsBook처럼 kN, kN·m. 값 표시는 `CB.num(v, d)`(진짜 빼기표 −) 또는 `CB.sig(v)`.

**부호.** 재료 시험 곡선은 그 시험의 관습을 따른다. 콘크리트 압축 시험·압축 곡선은 **압축을 +**로 그리고 축 이름에 밝힌다. 강재 인장 시험은 인장 +. 두 재료를 한 그래프에 그릴 때(RC 단면 등)는 MechanicsBook 규약(인장 +)으로 돌아가 축 이름에 적는다.

**색.**

| 대상 | 색 | 사용 |
|---|---|---|
| 시멘트·결합재 | `text-dim` 회색 계열 | 배합 막대, 수화 그림 |
| 물 | `blue` | 배합 막대, 수분 이동 |
| 잔골재 | `warn`(황토) | 배합 막대, 입도 곡선 |
| 굵은 골재 | `accent` | 배합 막대 |
| 공기 | `text-faint` | 배합 막대 |
| 혼화재(플라이애시·슬래그) | `green` | 배합 막대 |
| 인장 / 압축 | `tension` 파랑 / `compression` 빨강 | 응력 분포 |
| 하중·가열·공격 인자(CO₂·Cl⁻) | `accent2`(주황) | 화살표, 침투 전선 |
| 합격 / 불합격 | `ok` / `bad` | 판정 |

배합 막대(1 m³를 부피 비율로 나눈 띠)는 책 전체에서 위 색 순서(물 → 시멘트 → 혼화재 → 공기 → 잔골재 → 굵은 골재)로 그린다.

**01 건설재료의 성질과 선택** — 건물 한 채를 이루는 재료(B-10 한 층의 콘크리트 290 m³·철근 35 t, T-36 강재 32 t) / 재료의 성질: 강도(항복·인장·압축), 강성(탄성계수), 밀도, 연성과 취성, 인성(곡선 아래 넓이), 경도 / 응력–변형률 곡선 읽기(강재·콘크리트·목재·고무·유리 비교) / 미시 구조 → 거시 성질(결합, 결정, 공극) / 비강도와 비강성, 재료 선택 지도(애시비 차트: 밀도–탄성계수, 밀도–강도) / 성능 지수(가벼운 인장재 σ/ρ, 가벼운 보 E^(1/2)/ρ) / 가격과 내재 탄소(kgCO₂e/kg) / 시험의 언어: 표준, 시편, 통계, 품질 관리 / 이 책의 지도와 기준 재료 M-30·P-13 소개. 시뮬: 여러 재료의 응력–변형률 곡선 겹치기(끝까지 당기기, 인성 넓이 칠하기), 애시비 차트(재료 점 클릭 → 성질 표, 성능 지수 선 끌기), 같은 하중을 견디는 인장재·보의 무게 비교(강·알루미늄·목재·콘크리트·CFRP), B-10 3D(`CB.orbit`)에서 부재 골라 재료 물량·질량·탄소 쌓기, 연성–취성 파괴 비교(에너지), 단위 감각(MPa·GPa·kg/m³ 변환).
**02 시멘트와 수화** — 시멘트의 역사(로마 콘크리트, 애습딘의 포틀랜드 시멘트 1824) / 제조: 석회석 + 점토 → 소성(약 1,450 °C) → 클링커 + 석고 → 분쇄 / 클링커 광물 C₃S·C₂S·C₃A·C₄AF와 시멘트 화학 약어 / 보그 식으로 산화물 → 광물 조성 / 수화 반응: C₃S + 물 → C-S-H + CH, 반응열(광물별) / 수화 발열 곡선의 다섯 단계(미세 열량계) / 응결과 경화, 석고의 역할(급결 방지) / 수화도와 파워스 모델: 겔·모세관 공극, W/C 0.42 이상에서 남는 모세관 공극, 강도와 투수성 / 시멘트 종류: KS L 5201 1–5종(보통·중용열·조강·저열·내황산염), 혼합 시멘트(고로·플라이애시), 분말도 / 시멘트 생산의 CO₂(탈탄산 + 연료). 시뮬: 킬른 온도 따라 광물 생성(온도 슬라이더 → 상 변화), 보그 계산기(산화물 % 입력 → 광물 % 막대), 수화 발열 곡선(시멘트 종류·온도·W/C), 파워스 모델 부피 막대(W/C·수화도 → 겔·모세관 공극·미수화 시멘트), 입자 수화 미시 애니메이션(C-S-H 껍질 성장), 분말도 → 초기 강도, 시멘트 CO₂ 계산기.
**03 골재와 혼화재료** — 골재의 역할(부피 65–75 %, 경제·체적 안정) / 잔골재·굵은 골재(5 mm 체 기준), 천연·부순 골재·순환 골재 / 체가름 시험과 입도 곡선, 표준 입도 범위 / 조립률 FM과 굵은 골재 최대 치수 / 밀도·흡수율과 네 가지 함수 상태(절건·기건·표건·습윤), 표면수 / 단위 용적 질량과 실적률·공극률 / 유해 물질(점토 덩어리, 염화물, 알칼리 반응성) / 혼화제: 감수제·고성능 감수제(분산 원리), AE제(미세 기포), 지연제·촉진제 / 혼화재: 플라이애시·고로슬래그 미분말·실리카퓸(포졸란 반응, 잠재 수경성), 치환율과 성질 변화 / 입자 채움(패킹)과 공극 최소화. 시뮬: 체가름 시험기(체별 잔류 질량 → 입도 곡선 + 표준 범위 + FM, `CB.agg.sieve`), 함수 상태 계산기(질량 세 개 → 흡수율·표면수, `CB.agg.moisture`), 두 골재 혼합 비율로 입도 맞추기, 입자 채움 2D(크기 분포 → 공극률), 감수제 분산(응집 입자 풀기 애니메이션 → 같은 슬럼프에 필요한 물), 포졸란 반응 진행(CH 소비 시간 곡선), 혼화재 치환율 → 강도·발열·탄소 막대.
**04 콘크리트 배합 설계** — 배합 설계가 정하는 것(강도·워커빌리티·내구성·경제) / 설계 기준 강도와 배합강도, 표준편차와 불합격 확률(정규분포) / 시험 횟수가 적을 때의 보정 계수 / 물–결합재비: 아브람스 법칙과 강도–결합재수비 관계, 내구성에 따른 상한 / 단위수량과 잔골재율 표, 보정 규칙 / 절대용적법 1 m³ 채우기 / 현장 배합: 표면수 보정 / 시험 비빔과 조정 / 레디믹스트 콘크리트 호칭(25-30-150)과 주문 / 고강도·고유동 배합 맛보기. 시뮬: 배합 설계 마법사(단계별 입력 → 1 m³ 배합 막대, `CB.conc.mix`), 배합강도와 정규분포(s 슬라이더 → 불합격 확률 면적), 아브람스 곡선(W/B ↔ 강도, 점 끌기), 절대용적 블록 쌓기(재료를 넣을 때마다 남는 부피), 현장 배합 보정기(`CB.conc.fieldMix`), 물 10 kg 더 넣으면(강도·수축·비용 변화), 배합 비용·탄소 비교(OPC vs 플라이애시 vs 슬래그).
**05 굳지 않은 콘크리트** — 워커빌리티·컨시스턴시·성형성·펌프 압송성 / 슬럼프 시험과 슬럼프 플로, 슬럼프 손실(시간·온도) / 빙햄 유체: 항복 응력 τ₀과 소성 점도 μ, 슬럼프와 τ₀의 관계 / 공기량과 AE: 동결융해 저항 vs 강도 손실(공기 1 %당 약 4–5 %) / 블리딩과 레이턴스, 재료 분리 / 소성 침하 균열·소성 수축 균열 / 운반 시간 한도(기준 확인)와 펌프 압송(관 마찰, 압송 압력) / 타설·다짐: 진동기 영향 반경, 콜드 조인트 / 고유동·자기 충전 콘크리트(L-box, V-funnel) / 거푸집 측압. 시뮬: 슬럼프 시험 애니메이션(τ₀·밀도 → 내려앉는 콘 모양과 슬럼프 값), 빙햄 유동 곡선(τ₀·μ 끌기 → 물·모르타르·콘크리트·SCC), 블리딩 시간 곡선(W/C·높이 → 블리딩 수량), 펌프 압송 압력(배관 길이·높이·관경·토출량), 시간 경과 슬럼프 손실(온도·지연제), 거푸집 측압(타설 속도·온도·높이, 액압 vs 실제), 공기량 ↔ 강도·동결융해 균형.
**06 강도 발현과 양생** — 강도는 수화도다 / 재령 강도식 βcc(t)(시멘트 종류별, `CB.conc.beta`) / 온도의 영향: 적산온도(Nurse–Saul)와 등가 재령(아레니우스), 거푸집 해체 시기 / 양생 방법: 습윤(살수·피막), 증기 양생, 양생 기간 / 건조가 강도와 표층 품질을 망치는 이유 / 한중 콘크리트(초기 동해, 보온 양생, 기준 확인)와 서중 콘크리트(슬럼프 손실, 콜드 조인트) / 매스 콘크리트: 단열 온도 상승, 내외부 온도 차와 온도 균열 지수, 저발열 시멘트·플라이애시·파이프 쿨링 / B-10 기초 매트 2.5 m(M-30F)의 온도 이력. 시뮬: 재령–강도 곡선(시멘트 종류·온도), 적산온도 계산기(일별 기온 막대 끌기 → 등가 재령·현재 강도·거푸집 해체 가능일), 양생 조건 비교(습윤·공기 중·처음 3일만), 한중 콘크리트 보온(외기·보온재 → 콘크리트 온도 시간 곡선, 동결 경고), 매스 콘크리트 1차원 온도 해석(두께·시멘트량·플라이애시·타설 온도 → 중심·표면 온도와 온도 차, 유한 차분), 온도 균열 지수 판정, 파이프 쿨링 효과.
**07 콘크리트의 강도와 시험** — 압축 강도 시험: 원주 공시체 φ100 × 200·φ150 × 300, 하중 속도, 캐핑 / 파괴 모양과 공시체 크기·형상 효과(입방체 vs 원주) / 강도의 통계: 정규분포, 평균·표준편차·변동 계수 / 품질 판정(레디믹스트 콘크리트 받아들이기: 3회 연속 평균 ≥ fck, 각 회 ≥ fck − 3.5, fck ≤ 35 MPa 형태 — 현행 기준 확인), 관리도 / 인장 강도: 직접 인장, 쪼갬 인장(브라질리언), 휨 강도(파괴계수 fr = 0.63√fck), 압축의 약 1/10 / 응력–변형률 곡선: 미세 균열의 진행, 최대 응력 변형률 0.002, 극한 0.0033, 할선 탄성계수 Ec = 8,500 ∛fcm / 다축 응력과 구속(나선 철근 기둥 맛보기) / 코어 채취와 비파괴 시험(반발 경도·초음파 속도·복합법) / B-10 납품 기록 판정. 시뮬: 압축 시험기(공시체 크기·하중 속도 → 하중–변위 곡선과 파괴 애니메이션), 응력–변형률 곡선 비교(fck별, `CB.conc.sigma` hognestad·pr), 강도 판정기(공시체 결과 입력·무작위 생성 → 3회 이동 평균 판정, 관리도), 정규분포와 불량률(s·평균 → fck 미만 확률), 쪼갬·휨 시험 응력 분포, 반발 경도–강도 환산(곡선 + 불확실성 띠), 초음파 속도 → 동탄성계수, 탄성계수 계산기(단위 질량·fcm).
**08 수축과 크리프** — 콘크리트의 체적 변화 종류 / 소성 수축(증발 속도 노모그램)·자기 수축(낮은 W/B)·건조 수축(모세관 장력) / 건조 수축의 크기(약 400–800 × 10⁻⁶)와 영향 인자(단위수량, 골재, 부재 크기 h₀ = 2Ac/u, 상대습도) / 시간 함수와 이론 부재 두께 / 구속과 균열: 구속도, 인장 크리프, 균열 간격, 신축 이음·조절 줄눈 / 크리프: 지속 하중 아래 시간에 따라 느는 변형, 크리프 계수 φ, 유효 탄성계수 Ec/(1 + φ), 재하 재령 / 장기 처짐(구조역학 11장과 연결: 처짐 증가 계수), 기둥의 철근으로 하중 이동 / 프리스트레스 손실 맛보기 / 온도 변형(열팽창계수 약 10 × 10⁻⁶ /°C) / B-10 슬래브의 장기 처짐, 32 m 슬래브의 수축량. 시뮬: 수축 시간 곡선(상대습도·부재 두께·단위수량), 구속된 벽의 수축 균열(구속도 → 인장 응력 vs 인장 강도 발현 → 균열 시점), 크리프 계수 계산기(재하 재령·습도·h₀), 지속 하중 처짐 시간 곡선(`CB.beam`으로 즉시 처짐 × (1 + φ)), RC 기둥 하중 이동(크리프에 따라 철근 응력 증가), 줄눈 간격 설계, 증발 속도 노모그램(기온·습도·풍속 → 소성 수축 위험).
**09 콘크리트의 내구성** — 내구성이란: 설계 수명과 열화 메커니즘 / 투수성과 공극 구조(W/B, 양생) / 탄산화: CO₂ + Ca(OH)₂, pH 13 → 9, 페놀프탈레인, x = k√t(`CB.conc.carbonation`), k의 인자 / 염해: 해양·제빙 화학제, 피크 제2법칙과 오차 함수(`CB.conc.chloride`), 임계 염화물량, 확산 계수와 혼화재 / 철근 부식의 시작과 진전(투티 모델: 잠복기 + 진전기) / 동결융해: 수압설, 기포 간격 계수, 내구성 지수 / 알칼리–골재 반응(ASR 겔 팽창, 지도 모양 균열) / 황산염 침식(에트린자이트), 산 / 피복 두께와 품질의 맞교환, 노출 등급(기준 확인) / B-10의 탄산화(131년)와 주차장 염해(28년 vs 56년). 시뮬: 탄산화 전선 진행(k·피복·시간 → 단면 그림과 부식 개시 연도), 염화물 프로파일(Cs·D·시간·깊이, erf 곡선, 임계값 선), 피복 두께 × 품질 설계 지도(W/B·피복 → 수명 등고), 투티 모델 수명(잠복기 + 진전기), 동결융해 사이클(공기량·기포 간격 → 상대 동탄성계수), 페놀프탈레인 시험 단면 그림, 확산 1차원 유한 차분 vs 해석해.
**10 구조용 강재** — 철과 강: 고로–전로, 전기로(철스크랩), 연속 주조·압연 / 탄소량과 철–탄소 조직(페라이트·펄라이트), 열처리(담금질·뜨임), TMCP / 인장 시험: 항복점·항복 단·변형 경화·네킹, 0.2 % 오프셋, 연신율, 항복비 / 강종: SS275, SM355, SN355(내진용, 항복비 상한), HSA650 고성능 강, 두께에 따른 항복강도 / 인성과 샤르피 충격 시험, 연성–취성 천이 온도 / 피로: S–N 곡선, 응력 범위, 상세 등급, 마이너 법칙(`CB.steel.fatigueLife`, `CB.steel.miner`) / 용접성: 탄소당량 Ceq(`CB.steel.ceq`), 예열, 열영향부 / 고온에서 강도 저하(내화 피복 맛보기) / T-36의 강재 SM355와 하현재 피로. 시뮬: 인장 시험기(강종 선택 → 곡선, 0.2 % 오프셋 선, 연신율, `CB.steel.sigma`), 탄소량 슬라이더 → 조직 그림·강도·연성, 샤르피 천이 곡선(온도 → 흡수 에너지, 강종별), S–N 곡선과 수명(응력 범위·상세 등급), 마이너 법칙 하중 블록, 탄소당량 계산기(성분 → Ceq·예열 권고 구간), 고온 강도 저감 곡선(온도 → fy 비), 항복비와 소성 변형 능력 비교.
**11 철근** — 철근의 역할(인장과 균열 제어) / 이형철근 vs 원형철근, 마디와 리브 / 규격: KS D 3504 SD300–SD700, 내진용 S, 용접용 W 표시 / 호칭 D10–D35의 공칭 지름·단면적·단위 질량(`CB.steel.BARS`) / 부착: 화학적 접착·마찰·기계적 맞물림, 부착 응력과 뽑힘 시험, 쪼갬 파괴 / 정착 길이 개념 ld ∝ db fy/√fck(기준식 이름만, 계수는 확인된 것만) / 이음: 겹침·기계식·용접 / 갈고리와 구부림 지름 / 철근 가공·조립·간격, 피복 두께 유지(스페이서) / 물량 산출: 길이 × 단위 질량, 할증 / B-10 G1(7-D25, 늑근 D13@150)과 기준층 35 t. 시뮬: 철근 단면적 계산기(개수·호칭 조합 → As, 배치 그림·순간격 검토), 뽑힘 시험(묻힘 길이 → 뽑힘 vs 파단, 부착 응력 분포), 정착 길이 감각(db·fy·fck → ld 상대 비교), 철근 응력–변형률(SD400·SD500·SD600, 항복비), 구부림 반지름 vs 균열(굽힘 시험), 물량 산출기(B-10 보·기둥 배근 → 길이·질량·트럭 대수), 겹침 이음 위치(휨모멘트도 위에서 이음 위치 고르기).
**12 부식과 방식** — 부식은 전기화학이다: 양극(Fe → Fe²⁺ + 2e⁻)·음극(O₂ 환원)·전해질·도체 / 전위와 갈바닉 계열, 이종 금속 접촉 / 부동태 피막(콘크리트 속 pH 13)과 그 파괴(탄산화·염화물) / 녹의 부피 팽창(2–6배)과 피복 균열·박리 / 대기 부식: 부식성 범주 C1–C5, 시간 법칙 d = A tⁿ / 국부 부식: 공식·틈새·응력 부식 / 방식: 도장 계통(하도·중도·상도, 막 두께), 용융 아연 도금(희생 방식), 내후성 강(안정 녹), 음극 방식(희생 양극·외부 전원), 에폭시 도막 철근·스테인리스 철근 / 유지관리와 생애 비용 / T-36의 도장과 재도장 주기. 시뮬: 부식 전지 애니메이션(전자·이온 흐름, 산소·수분 스위치), 갈바닉 계열(두 금속 고르기 → 전위차·어느 쪽이 부식), 대기 부식 두께–시간(범주·n → 남은 판 두께와 단면 손실률), 녹 팽창 → 피복 균열(철근 지름·피복·부식량), 도장 열화와 재도장 주기(막 두께·환경), 음극 방식 전위(희생 양극 수명), 생애 비용 비교(도장·도금·내후성 강, 할인율).
**13 아스팔트와 포장 재료** — 도로 포장의 층 구조(표층·기층·보조 기층·노상), 연성 vs 강성 포장 / 아스팔트 바인더: 원유 정제, 성분(아스팔텐·레진), 점탄성과 온도 의존성 / 시험: 침입도·연화점·신도·점도, 침입도 지수 / PG 등급(PG 64-22의 뜻: 고온 64 °C·저온 −22 °C) / 점탄성 모델(맥스웰·켈빈), 시간–온도 중첩 맛보기 / 아스팔트 혼합물: 골재 입도와 바인더 함량, 마샬 배합 설계(안정도·흐름값, 공극률 Va·VMA·VFA, `CB.asph.volumetrics`) / 파손: 소성 변형(바퀴 자국), 피로 균열, 저온 균열, 포트홀(수분) / 개질 아스팔트, 재생 아스팔트(RAP), 중온·배수성 포장 / P-13 배합. 시뮬: 바인더 온도–점도·강성 곡선(PG 등급 선택), 침입도·연화점 시험 애니메이션, 마샬 배합 설계(바인더 함량 슬라이더 → 밀도·Va·VMA·VFA·안정도 곡선, 최적 함량 찾기), 점탄성 크리프·회복(맥스웰·켈빈 스프링–대시포트), 바퀴 자국 깊이(온도·교통량·바인더), 포장 단면 응력 분포(층 두께·강성, 단순 모델), 저온 균열(온도 강하 → 열응력 vs 인장 강도).
**14 목재와 공학 목재** — 나무가 자라는 방식: 나이테·춘재·추재, 심재·변재, 침엽수·활엽수 / 세포 구조(셀룰로스 미세 섬유)와 이방성: 섬유 방향 vs 직각 방향 강성·강도(10–40배 차) / 함수율, 섬유 포화점(약 28–30 %), 평형 함수율, 수축(접선 > 반경 > 섬유 방향), 뒤틀림 / 밀도와 강도, 결점(옹이·경사 섬유) / 등급: 육안·기계 등급, 강도 등급 / 하중 지속 기간과 크리프(함수율의 영향) / 공학 목재: 집성재(glulam), 교차 적층 목재(CLT), LVL, 합판 / 접합(못·볼트·철물) 맛보기 / 내화: 탄화 속도(약 0.65–0.8 mm/분, 교육용), 잔존 단면 / 내구성: 부후·흰개미, 방부 처리 / 탄소 저장 / T-36 목재 데크판. 시뮬: 각도에 따른 강도(행킨슨 식: 섬유와 하중의 각 → 강도), 함수율–수축(판 단면이 뒤틀리는 모양, 나이테 방향), 평형 함수율(온도·습도 → EMC), 옹이 위치와 휨 강도 저감, 집성재 적층(층 수·등급 배치 → 휨 강성), CLT 층 구성(층 방향·두께 → 두 방향 강성 비), 화재 시 탄화(시간 → 잔존 단면·보의 남은 저항 모멘트, `CB.section.rect`), 데크판 처짐(함수율·크리프).
**15 조적·유리·단열·방수** — 벽돌·콘크리트 블록·석재의 성질(흡수율·압축 강도) / 모르타르의 종류와 배합 / 조적조의 압축 강도: 단위체와 모르타르의 상호작용(줄눈의 횡구속), 횡하중에 약한 이유와 보강 조적 / 판유리: 비정질 구조, 이론 강도 vs 실제 강도(그리피스 결함), 강화·배강도·접합 유리, 열파손 / 복층 유리와 로이 코팅 / 열 이동: 전도·대류·복사, 열전도율, 열저항·열관류율 U(`CB.wall`) / 단열재 종류와 성능, 열교 / 결로: 이슬점(`CB.dewPoint`), 표면 결로와 내부 결로, 방습층 위치 / 방수: 아스팔트·시트·도막 방수, 실링재와 줄눈의 움직임 / B-10 커튼월·옥상 단열·지하 외벽 외방수. 시뮬: 조적 벽 압축 강도(단위체·모르타르 강도·줄눈 두께), 그리피스 결함(결함 길이 → 파괴 응력, 강화 유리의 표면 압축), 벽체 단면 열관류율 계산기(층 쌓기·두께 → U, 온도 분포), 이슬점 계산기와 결로 판정(실내 온도·습도 → 벽체 내부 온도선과 이슬점선 교차), 복층 유리 구성(공기층·로이·가스 → U값·표면 온도), 열교(창틀·슬래브 끝) 2D 온도장(유한 차분), 실링재 줄눈 폭 설계(온도 범위·부재 길이·허용 변형률).
**16 복합재료와 지속 가능한 재료** — 복합재료의 뜻과 혼합 법칙(`CB.mixRule`, 보이트·로이스 경계) / 섬유: 유리·탄소·아라미드·현무암 / FRP: 이방성, 선형 탄성–취성 파괴, FRP 보강근(낮은 탄성계수, 부식 없음), FRP 시트 보강(휨·전단·기둥 구속) / 섬유 보강 콘크리트: 강섬유·합성섬유, 균열 후 잔류 강도, 인성 / 초고성능 콘크리트(UHPC, 150 MPa 이상) / 강–콘크리트 합성 맛보기 / 지속 가능성: 시멘트의 CO₂, 내재 탄소, 전과정 평가(LCA) 단계(A1–A3 제품, A4–A5 시공, B 사용, C 폐기, D 재활용), 기능 단위 / 저탄소 콘크리트(혼화재, 석회석 시멘트), 순환 골재, 강재 재활용, 목재의 탄소 저장 / B-10 골조의 내재 탄소와 줄이는 방법. 시뮬: 혼합 법칙(섬유 부피비·방향 → 강성, 보이트·로이스 사이), 섬유 각도에 따른 FRP 강성(극좌표), FRP 시트 휨 보강(보 단면에 겹 수 → 휨 강도 증가, `CB.section`), 섬유 보강 콘크리트 하중–처짐(섬유 함량 → 균열 후 거동), B-10 내재 탄소 계산기(콘크리트·철근·혼화재 치환 → tCO₂e, 막대), LCA 단계별 막대(재료·운송·폐기·재활용), 재료 대안 비교(같은 기둥을 RC·강·목재로 → 질량·탄소).
**17 용어집 & 종합 퀴즈** — 공식·수치 한눈표(배합 설계 단계, M-30 배합표, 강도·탄성계수 식, 탄산화·염화물 식, 철근 규격표, 강종표, 마샬 공극 성질, 열관류율), 용어 검색, 전 범위 종합 퀴즈(장마다 1–2문항). `../mechanics/chapters/glossary.html`의 구조를 따른다.

// 콘크리트 (응력 MPa, 시간 일, 내구성 시간 연)

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `materials/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
- 화학식은 HTML 아래 첨자(`C<sub>3</sub>S`, `Ca(OH)<sub>2</sub>`) 또는 KaTeX `\mathrm{C_3S}`로 쓴다.
