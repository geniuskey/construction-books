# SiteBook 챕터 작성 가이드

SiteBook은 ConstructionBooks 서가(`construction.euiyun.com`)의 일곱 번째 권인 시공·건설관리 교과서다. 배포 주소는 `https://construction.euiyun.com/site/`. `js/common.js`는 MechanicsBook 엔진(구조 해석기 `CB.frame`/`CB.beam`/`CB.truss`/`CB.section`, `CB.orbit`, `CB.normCdf`, `CB.rng` 등)에 **공사 관리 모델** `CB.pm`(CPM — FS·SS·FF와 지연, PERT, 완료 확률, 삼각 분포와 몬테카를로 공기 위험, 비용·자원 분포와 S 곡선, EVM, 공기 단축 비용 경사, 굴삭기 작업량·덤프트럭 대수, 학습 곡선, NPV·IRR, 위험성 점수, 재해율)과 기준 공사 `CB.pm.B10`을 더했다. (재료·지반·동역학 모델은 이 책에 없다. 필요하면 앞 권 링크.) 본보기는 `../civil/chapters/traffic.html`, `../concrete/chapters/case-study.html`, `../structure/chapters/seismic.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 법령·기준·통계·역사적 사실은 확인된 것만 쓴다(확실하지 않으면 "형태", "약", "교육용", "현행 법령·기준 확인"). 특히 산업안전보건법, 건설기술 진흥법, 국가계약법, 표준품셈, 재해 통계 숫자는 "현행 확인"을 붙이고 연도·수치를 지어내지 않는다.

## 구조

빌드 없이 열리는 정적 페이지. `index.html` + `chapters/<slug>.html` + `css/style.css`(앞 권과 같고 강조색 주황 `#c2410c`, 보조색 강철 파랑 `#1d5fa8` — 이 책만 주황이 강조색) + `js/common.js`(전역 `CB`, `CHAPTERS`). classic script만, 외부 라이브러리 없음. 3D는 `CB.orbit`(현장 배치, 크레인 작업 반경, 층별 공정 진행 4D 장면).

- 용어: `js/glossary/<slug>.json`(`{"ko","en","abbr","def","chapters":["<slug>"]}` 배열)에 적고 `tools/merge-glossary.py site`가 합친다. `en` 대문자 시작, `abbr` 밑줄 금지, 정의에 `<`·`>` 금지("미만·초과"로), 띄어쓰기 변형 중복 금지, 일상어와 겹치는 짧은 말(예: "공정", "원가")은 그대로 쓰되 다른 뜻의 동음이의어가 생기면 수식어를 붙인다.

## 원칙: 계획 → 실행 → 측정 → 조정

건설 관리는 "한 번뿐인 프로젝트를 정해진 기간·예산·품질로, 사고 없이 끝내는" 일이다. 이 책은 모든 개념을 **계획을 세우고(공정표·견적·시공 계획) → 실행하고(공종별 시공, 장비·인력) → 측정하고(진도·원가·품질·안전 지표) → 조정하는(공기 단축, 자원 평준화, 원가 회복)** 순서로 쓴다. 기준 공사 P-B10(B-10 신축 공사)의 공정·원가·품질·안전을 책 전체가 따라간다. 앞 권(재료·지반·구조·RC·토목)이 "무엇을 짓나"였다면, 이 책은 "어떻게 짓고 관리하나"다.

- 한국어, 대상은 건축·토목 4학년과 현장 기술자·공무 담당 신입. 영어 원어 병기.
- 장 첫머리 `.origin`("이 관리가 없었다면"), 각 절은 가능하면 `.problem`(현장 상황).
- 흐름: 문제 → 그림(SVG) → **조작하는 시뮬레이터** → 정의·원리(KaTeX) → **손으로 푸는 예제**(`.callout`, 단계별, 단위, 판정) → 기준 공사 노트(`.callout.site`) → `.uses` → 핵심 정리 → 확인 퀴즈(8문항).
- 정의·원리 `<div class="callout def"><strong>정의 9.2 (전체 여유)</strong> …</div>`, 예제 `예제 9.1`, 그림 `그림 9-1.`, `.callout.deep` 심화.
- 장마다 **시뮬레이터 7–8개, 그림 6개 이상, 퀴즈 8문항.** 계산하는 모델이어야 한다(공정표를 고치면 주공정이 바뀌고, 투입을 바꾸면 비용과 공기가 바뀐다). 극단 입력에도 NaN·음수 기간이 없다. 몬테카를로 등 무거운 계산은 입력이 바뀔 때만 다시 한다.
- 계산은 `CB.pm`으로 한다. 공정표(간트·네트워크) 그리기, 자원 평준화 알고리즘, LOB, 관리도, 크레인 양중 검토, 거푸집 측압, 견적 표 등 장 고유 모델은 페이지 스크립트에 두고 "교육용"이라 밝힌다. 구조 검토가 필요하면 `CB.beam`/`CB.frame`.
- 색은 CSS 변수와 `CB.palette()`만. 라이트/다크 모두. 폭 360px 가로 스크롤 금지. SVG는 `viewBox`만, 폭 900 이하.
- 시뮬레이터 `id`는 `sim-<접두사>-<이름>`, 요소 id·전용 CSS 클래스도 접두사. 절 `id`는 의미 있는 영어 슬러그.

## 단위·부호·색 규약 (책 전체 공통)

**단위.** 기간: 공정은 주(기준 공사) 또는 일(공종 장에서 밝힌다), 금액: 억 원 또는 백만 원·원(밝힌다), 물량 m³·t·m², 장비 작업량 m³/h, 인원 명/주(자원 부하), 재해 지표 도수율·강도율. 할인율·이율은 연 %.

**공정표 그리기 규약.** 간트 차트는 왼쪽에서 오른쪽으로 시간, 위에서 아래로 활동(작업 분류 순서). 주공정 활동은 `bad`(빨강)로 굵게, 여유 있는 활동은 `accent2`(파랑), 여유 시간은 막대 뒤 점선 꼬리. 네트워크(AON)는 노드 상자에 ES·EF·LS·LF를 네 귀에 적는 형태(그림 9장에서 정의). 계획(기준선) 막대는 `text-faint` 윤곽, 실적은 채운 막대.

**EVM 색.** PV `text-dim` 점선, EV `ok`(초록), AC `bad`(빨강). 비용·자원 막대 `accent`(주황), 누적 곡선 `accent`.

**01 건설 프로젝트의 이해** — 건설 산업의 특성(일품 주문 생산, 옥외·이동 생산, 다수 참여자, 긴 공급망) / 프로젝트 생애 주기(기획·설계·발주·시공·운영) / 참여자(발주자·설계자·시공자·감리·CM·전문 건설업체) / 관리의 축: 공정·원가·품질·안전(+환경), 철의 삼각형 / 시공 과정 한눈에(가설 → 토공 → 기초 → 골조 → 외장 → 마감·설비 → 준공) / P-B10 소개와 이 책의 지도. 시뮬: P-B10 4D 장면(`CB.orbit` + 주 슬라이더: 공정에 따라 건물이 올라감), 생애 주기 비용 비중(설계 변경 비용이 단계마다 커지는 곡선, 교육용), 철의 삼각형(공기·비용·품질 하나를 줄이면 나머지 변화, 교육용 모형), 참여자 관계도(계약 방식 선택 → 계약선·소통선 그림), 공종 순서 맞히기 게임, 공사비 구성 막대(P-B10 활동별), 산업 규모 감각(교육용 수치).
**02 발주 방식과 계약** — 발주 방식: 설계·시공 분리(DBB), 설계·시공 일괄(턴키·DB), CM(CM for fee, CM at risk), 민간 투자(BTO·BTL 맛보기) / 계약 방식: 총액·단가·실비 정산(+이윤), 위험 분담 / 입찰과 낙찰: 적격 심사·최저가·종합 심사 낙찰(형태, 현행 확인), 예정 가격 / 계약 관리: 설계 변경, 물가 변동 조정(형태), 지체상금, 클레임과 분쟁 / 위험 관리: 위험 식별·평가·대응 / P-B10을 DBB·턴키·CM으로 발주하면. 시뮬: 계약 방식별 위험 분담(불확실성 → 발주자·시공자 비용 분포, 교육용 몬테카를로), 입찰 가격 결정(원가·경쟁자 수 → 낙찰 확률·기대 이익, 교육용), 실비 정산 + 이윤 방식 비교(비용 초과 시 각 당사자 부담), 설계 변경 정산(물량 증감 → 계약 금액 변화), 지체상금 계산(지연 일수·요율 → 금액, 형태), 위험 등록부(위험 끌어 놓기 → 빈도·영향 매트릭스, `CB.pm.risk`), 발주 방식 선택 의사 결정(가중치 → 점수).
**03 공사 계획과 가설 공사** — 시공 계획서의 구성 / 현장 조사와 제약(인접 건물·도로·지하 매설물) / 가설 공사: 가설 울타리·사무실·창고·가설 전기·용수·진입로·세륜 / 현장 배치 계획(야적·가공장·동선) / 양중 계획: 타워크레인 선정(작업 반경–인양 하중 표, 형태), 위치·높이, 양중 횟수 산정, 호이스트 / 가설 구조물: 비계·동바리·작업 발판(안전은 15장) / 공사용 도로와 교통 처리 / P-B10 현장 배치. 시뮬: 현장 배치 계획기(평면에 크레인·야적장·사무실 끌어 놓기 → 크레인 반경 커버율·동선 길이, 교육용 점수), 타워크레인 하중–반경 곡선(지브 길이·인양물 → 가능 여부), 양중 횟수와 크레인 대수(층 물량·사이클 → 필요 대수), 크레인 기초 반력(전도 모멘트 → 기초 접지압, `CB.beam` 또는 손계산 형태), 가설 전기 용량 산정(장비 목록 → kVA, 교육용), 3D 현장(`CB.orbit`: 크레인 회전 반경과 인접 건물), 가설 공사비 비중.
**04 토공과 흙막이 시공** — 토공 계획: 물량(P-B10 8,450 m³), 토량 환산(CivilBook 12장, GeotechBook 2장 연결), 장비 조합 / 굴삭기 작업량(`excavator`), 덤프트럭 배차(`trucks`), 장비 조합 최적화, 사토장 거리 / 흙막이 시공 순서(지하연속벽: 가이드월·굴착·슬라임 처리·철근망·트레미 타설, CIP·SCW 맛보기), 버팀보·어스앵커 설치와 프리로딩, 굴착 단계(GeotechBook 11장 연결) / 지하수 처리와 배수 / 계측 관리(경사계·변형률·지하수위, 관리 기준 형태) / 인접 건물 보호 / P-B10 굴착 공정. 시뮬: 굴삭기 작업량 계산기(버킷·사이클·효율 → m³/h, 일 작업량), 덤프트럭 배차(운반 거리·속도 → 사이클 → 필요 대수, 대기 시간 애니메이션), 장비 조합 비용(굴삭기 대수·트럭 대수 → 일수·비용 최소점), 굴착 단계 애니메이션(단계별 굴착 깊이·버팀보 설치, 3D `CB.orbit`), 계측 관리도(경사계 변위 시계열 → 1·2차 관리 기준 판정, 교육용), 지하연속벽 패널 시공 순서(패널 수·사이클 → 공기), 사토 운반 계획(사토장 거리 → 비용·탄소).
**05 기초 공사** — 기성 말뚝(PHC) 시공: 항타·매입 공법, 장비, 시공 순서와 위치 관리, 항타 관리(관입량·리바운드, 동재하 시험 맛보기 — GeotechBook 14장 연결), 두부 정리 / 현장 타설 말뚝 시공(굴착·철근망·트레미, 공벽 안정) / 기초 매트 대량 타설: 타설 계획(레미콘 대수·펌프카·타설 순서·이음), 수화열 관리(MaterialsBook 6장 연결), 양생 / 품질 시험(말뚝 재하, 콘크리트 공시체) / 공기와 비용 / P-B10 말뚝 120여 본(교육용, C1 5본 등)과 기초 매트. 시뮬: 말뚝 시공 순서 최적화(말뚝 배치 → 장비 이동 경로 길이, 교육용 탐욕 알고리즘), 항타 관리 기록(타격 수–관입량 그래프 → 지지 판정, 교육용), 매트 타설 계획(타설량·펌프 능력·레미콘 사이클 → 필요 펌프·트럭 대수, 타설 시간, 콜드 조인트 위험), 타설 순서 애니메이션(층·구획별 타설 진행), 수화열 온도 이력(단열 온도 상승·보온 → 중심·표면 온도차, 교육용 간이 모델), 말뚝 공기·비용(본수·장비 수 → 일수), 3D 말뚝·매트 장면.
**06 철근·거푸집·콘크리트 공사** — 골조 공사의 흐름과 층 사이클 / 철근 공사: 가공도·가공장, 조립 순서, 이음·정착 확인(ConcreteBook 7장 연결), 검측 / 거푸집: 재래식·유로폼·알루미늄폼·갱폼·시스템 폼, 전용 횟수와 비용, 측압(ACI 347 형태, MaterialsBook 5장 연결), 동바리와 존치 기간(형태) / 콘크리트: 레미콘 주문·운반 시간 한도(형태), 펌프 압송, 타설·다짐, 이음, 양생, 품질 시험(MaterialsBook 7장) / 층 공정 사이클(3주/층)과 반복 / P-B10 기준층 물량(콘크리트 약 290 m³, 철근 약 35 t). 시뮬: 층 사이클 공정(작업 단계·인원 → 사이클 일수, 간트), 거푸집 측압 계산기(타설 속도·온도 → 측압 분포, 액압 비교), 거푸집 시스템 비교(층수·전용 횟수 → 층당 비용, 교육용 단가), 동바리 하중 검토(타설 하중·간격 → 동바리 축력·좌굴 여유, 교육용), 레미콘 배차(타설량·펌프 능력·운반 시간 → 트럭 대수·대기), 타설 순서와 콜드 조인트(구획·타설 속도 → 이음 시간 간격 판정), 철근 물량·가공 손실(B-10 물량 → 길이·질량, 할증).
**07 철골 공사** — 철골 공사의 흐름(제작 도면 → 공장 제작 → 운반 → 세우기 → 접합 → 검사) / 공장 제작과 품질(용접·도장·검사) / 운반 제한과 부재 분할 / 세우기: 양중 계획(부재 무게·크레인 반경, 3장 연결), 세우기 순서와 가설 안정(가새·가볼트), 정밀도 관리(기둥 수직도, 허용 오차 형태) / 접합: 고장력 볼트 조임(토크법·너트 회전법 형태), 현장 용접(예열·검사, MaterialsBook 10장 연결) / 데크 플레이트와 합성 슬래브(StructureBook 11장 연결) / 내화 피복 / P-B10을 철골조로 바꾸면(StructureBook 10장의 B-10S 연결). 시뮬: 부재 분할과 운반(부재 길이·무게 → 운반 제한·트럭 대수), 양중 가능 판정(부재 위치 끌기 → 크레인 반경·정격 하중 판정), 세우기 순서와 가설 안정(순서 바꾸기 → 단계별 안정 판정, 교육용), 볼트 조임력(토크 → 축력, 토크 계수 산포, 교육용), 기둥 수직도 누적 오차(층별 오차 → 누적 편차, 교정), 철골 vs RC 공기 비교(층수 → 공기, 교육용), 3D 세우기 애니메이션(`CB.orbit`).
**08 외장·마감·설비 공사** — 외장: 커튼월(유닛·스틱 공법, 양중·설치 순서, 수밀·기밀 시험 형태), 석재·패널 / 방수(옥상·지하, MaterialsBook 15장 연결)와 단열 / 내부 마감: 공종 순서(설비 배관 → 경량 벽체 → 천장 → 바닥 → 도장 → 가구), 공종 간 간섭과 작업 구역 / 기계·전기 설비: 설비 공정 비중(약 20–30 %, 교육용), 시운전과 TAB / 준공: 검사·인수인계·하자 보수 / P-B10 커튼월 16주·내부 마감 20주. 시뮬: 커튼월 설치 속도(유닛 수·양중 사이클 → 층별 진행, 간트), 마감 공종 순서 최적화(작업 구역 × 공종 흐름 → 공기, 교육용 LOB 맛보기), 공종 간섭 매트릭스(공종 쌍 → 간섭 정도, 순서 재배치), 방수 누수 시험 판정(교육용), 설비 공정 S 곡선, 준공 체크리스트 진행률(항목 체크 → 남은 공정), 하자 발생 분포(공종별 하자 비율 → 파레토, 교육용).
**09 공정 계획과 CPM** — 공정 관리의 목적 / 작업 분류 체계(WBS)와 활동 정의, 기간 산정(물량 ÷ 생산성) / 공정표의 종류: 바 차트(간트), 네트워크(AOA·AON), 사선식 / 선후행 관계 FS·SS·FF·SF와 지연(lag) / CPM 계산: 전진 계산(ES·EF), 후진 계산(LS·LF), 전체 여유·자유 여유, 주공정(`cpm`) / 공정표 읽기와 갱신 / 마일스톤과 계약 공기 / P-B10 공정표(93주, 주공정 A–B–C–E–F–G1–H–J–M). 시뮬: 네트워크 편집기(활동 추가·선후행 연결·기간 바꾸기 → 즉시 CPM, 노드에 ES/EF/LS/LF, 주공정 빨강, `CB.pm.cpm`), P-B10 간트 차트(기간 슬라이더 → 주공정 이동, 여유 꼬리), 전진·후진 계산 단계 애니메이션, 선후행 관계 종류(FS·SS·FF + lag → 두 막대 관계 그림), 여유 시간 이해(비주공정 활동 끌어 늦추기 → 언제 주공정이 되나), 기간 산정기(물량·생산성·인원 → 기간), 공정 갱신(실적 입력 → 남은 공정 재계산).
**10 PERT와 공기 위험** — 기간의 불확실성 / 3점 추정과 베타 분포 근사(`pert`) / 주공정의 평균·분산, 완료 확률(`prob`) / PERT의 한계: 합류 편향(병렬 경로) / 몬테카를로 공정 위험 분석(`tri`, `monteCarlo`): 공기 분포 히스토그램, P50·P80, 주공정 지수 / 일정 버퍼와 위험 대응(CCPM 맛보기) / 날씨 위험(강우 일수, 교육용) / P-B10: PERT 평균 97주(σ 3.3) vs 몬테카를로 평균 약 101주·P80 약 105주. 시뮬: 3점 추정 분포(a·m·b 끌기 → 베타·삼각 분포 비교, 평균·σ), 완료 확률 계산기(목표 공기 → 확률, 정규 곡선 면적), 합류 편향 실험(병렬 경로 수 → 최대값 분포가 오른쪽으로), P-B10 몬테카를로(반복 수·시드 → 히스토그램·누적 곡선·P80, 주공정 지수 막대, 입력 바뀔 때만 계산), 버퍼 크기 정하기(목표 신뢰도 → 버퍼 주수), 날씨 위험(월별 강우 일수 → 옥외 공종 지연, 교육용), 토네이도 차트(활동별 불확실성 기여).
**11 자원 관리와 공기 단축** — 자원 부하도(`spread` rate)와 산·골 / 자원 평준화(여유 안에서 이동, 교육용 휴리스틱)와 자원 제약 공정 / 공기 단축: 직접비·간접비와 총 공사비 곡선, 비용 경사(`slope`), 주공정 단축 순서(가장 싼 활동부터), 최적 공기 / 반복 공정과 LOB(층별 작업 흐름, 작업 간 버퍼) / 인력 계획과 생산성 저하(초과 근무·밀집, 교육용) / P-B10 최대 부하 약 115명(ES)과 평준화. 시뮬: 자원 부하도(ES·LS 기준 전환, 활동 끌어 옮기기 → 부하 변화, 최대값·변동 지수), 자동 평준화(휴리스틱 실행 → 전후 비교), 공기 단축 비용 곡선(목표 공기 → 단축할 활동·추가 비용, 직접비 + 간접비 → 최적 공기, 교육용 단축 데이터), 주공정 단축 단계별(단축할 때마다 새 주공정 출현), LOB 다이어그램(층별 작업 속도 → 선 기울기, 간섭과 버퍼), 초과 근무 효율(근무 시간 → 생산성, 교육용), 인력 히스토그램과 누적 인일.
**12 적산과 원가 관리** — 적산과 견적의 차이 / 수량 산출(콘크리트·거푸집·철근, B-10 기준층 예) / 표준품셈과 일위대가(형태), 재료비·노무비·경비 / 직접비·간접비·일반 관리비·이윤의 구성(요율은 형태) / 견적 단계와 정확도(개략·상세, AACE 등급 형태) / 원가 계획: 실행 예산, 원가 분류, 현금 흐름과 기성(`spread`, S 곡선) / 경제성 분석: 시간 가치, NPV·IRR(`npv`, `irr`), 생애 주기 비용 / P-B10 244억과 현금 흐름. 시뮬: 수량 산출기(B-10 기준층 부재 치수 → 콘크리트·거푸집·철근 물량), 일위대가 구성(재료·노무·장비 투입량·단가 → 단위 단가, 교육용 단가), 원가 구성 막대(직접비 → 간접비·관리비·이윤 누적, 형태 요율), 견적 정확도 깔때기(설계 단계 → 오차 범위), P-B10 현금 흐름(기성 지급 지연·유보율 → 시공자 현금 수지 곡선, 교육용), NPV·IRR 계산기(현금 흐름 끌기 → NPV·IRR), 생애 주기 비용 비교(초기비 vs 유지비, 할인율).
**13 진도 관리와 EVM** — 진도 측정(물량·마일스톤·가중 진도) / S 곡선과 기준선 / 획득 가치 관리: PV·EV·AC, SV·CV, SPI·CPI(`evm`), 완료 시 예상 원가 EAC·ETC·VAC, TCPI / 획득 일정(ES) 맛보기 / 원인 분석과 회복 대책(공기 단축 11장, 자원 재배치) / 보고서와 대시보드 / P-B10 50주 시점 교육용 시나리오. 시뮬: S 곡선 기준선(ES·LS 기준 곡선과 사이 띠, `spread`), EVM 계산기(PV·EV·AC 끌기 → 모든 지표·판정 색), 시간에 따른 EVM 추적(주 슬라이더 → PV·EV·AC 곡선과 지표 시계열, 교육용 실적 시나리오), EAC 예측 방법 비교(CPI 기반·CPI×SPI 기반·잔여 계획 기반), 가중 진도 계산(공종 진도 입력 → 전체 진도), 회복 대책 효과(지연 활동 단축 → 예상 준공일·비용), 대시보드 신호등.
**14 품질 관리** — 품질의 정의와 비용(예방·평가·실패 비용) / 품질 계획·보증·관리, 검측과 시험 계획 / 통계적 품질 관리: 산포와 정규 분포(`CB.normCdf`), 관리도(X̄–R, p 관리도), 공정 능력 지수 Cp·Cpk / 샘플링 검사와 OC 곡선 / 콘크리트 품질 판정(MaterialsBook 7장 연결) / 하자와 근본 원인 분석(파레토, 특성 요인도, 5 Why) / ISO 9001 형태 / P-B10 콘크리트 강도·철근 피복 검측. 시뮬: 관리도(측정값 생성 → X̄–R 관리도, 관리 한계 이탈 규칙 판정, 교육용 데이터), 공정 능력(평균·표준편차·규격 → Cp·Cpk, 불량률 면적), OC 곡선(표본 크기·합격 판정 수 → 합격 확률 곡선), 파레토 차트(하자 유형 빈도 → 누적 비율, 교육용), 품질 비용 최적(예방 투자 → 총 품질 비용 곡선, 교육용), 피복 두께 검측 판정(측정값 분포 → 합격률), 특성 요인도 만들기(원인 끌어 놓기).
**15 건설 안전** — 건설 재해의 특성과 지표(도수율·강도율, `rates`; 실제 통계는 출처가 확실한 것만, 아니면 교육용 가상 현장) / 재해 이론: 하인리히(1:29:300 형태), 스위스 치즈 모형 / 위험성 평가(빈도 × 강도, `risk`), 작업 전 안전 점검 / 주요 재해 유형: 추락(안전 난간·개구부·안전대), 붕괴(흙막이·동바리·거푸집), 끼임·맞음, 크레인 전도·낙하물 / 가설 구조물 안전(비계·동바리 하중 검토 맛보기) / 안전 관리 체계와 안전 관리비(형태, 현행 법령 확인) / 안전 문화와 행동 / P-B10 위험성 평가. 시뮬: 위험성 평가 매트릭스(작업 위험 끌어 놓기 → 등급·대책, `CB.pm.risk`), 재해 지표 계산기(재해 건수·근로 시간 → 도수율·강도율), 추락 거리와 충격(높이 → 낙하 속도·충격, 안전대 처짐, 교육용), 크레인 전도 안정(인양 하중·반경·아웃리거 → 전도 모멘트 비, 교육용), 동바리 붕괴 검토(타설 하중·동바리 간격 → 축력 vs 좌굴 하중, `CB.beam` 또는 오일러 식), 하인리히 피라미드(아차 사고 보고 수 → 예상 사고, 교육용), 안전 투자 효과(투자 → 재해 감소·비용 곡선, 교육용).
**16 생산성과 스마트 건설** — 건설 생산성의 문제 / 학습 곡선(`learning`)과 반복 층 공사 / 린 건설: 낭비 유형, 풀 계획, 라스트 플래너(PPC 지표), 작업 흐름 안정화 / 탈현장 시공(OSC)·프리패브·모듈러(StructureBook 13장 연결)와 현장 공기 단축 / 스마트 건설: 드론 측량과 물량, 센서·IoT 계측, 건설 로봇·자동화, BIM 기반 4D·5D(BIMBook 연결) / 디지털 현장 관리와 데이터 / 생산성 측정(단위 작업량, 부가가치 시간 비율) / P-B10 골조 반복 층의 학습 효과와 모듈러 대안. 시뮬: 학습 곡선(학습률·첫 층 시간 → 층별 시간·누적, 반복 층 공기 단축), 라스트 플래너 PPC 추적(주별 약속·완료 → PPC 곡선과 공기 안정성, 교육용), 작업 흐름 변동(변동 크기 → 대기·버퍼, 교육용 큐잉), 부가가치 시간 분석(작업 표본 → 부가가치·필수 비부가가치·낭비 비율), 모듈러 vs 현장 시공 공기·비용(유닛 수·공장 생산 속도 → 공기 비교), 드론 물량 산출(측량 점 → 체적, 교육용 격자 적분), 4D 진행 비교(계획 vs 실적 3D, `CB.orbit`).
**17 용어집 & 종합 퀴즈** — 공식·수치 한눈표(CPM 계산 규칙, PERT·확률, EVM 지표, 공기 단축 경사, 장비 작업량, 학습 곡선, NPV·IRR, 관리도 한계·Cp, 재해 지표, P-B10 결과), 공정표 그리기 규약, 용어 검색, 종합 퀴즈. `../civil/chapters/glossary.html` 구조를 따른다.

## JS 헬퍼 (`js/common.js`, 전역 `CB`)

화면·컨트롤·차트·좌표 평면·구조 해석은 `../mechanics/CONTRIBUTING.md`의 "JS 헬퍼"와 같다(`CB.canvas`, `CB.chart`, `CB.plane`, `CB.orbit`, `CB.range`, `CB.seg`, `CB.loop`, `CB.normCdf`, `CB.rng`, `CB.histogram`, `CB.mean`, `CB.std`, `CB.beam`, `CB.frame` …). 시그니처는 반드시 `js/common.js` 소스에서 확인한다.

공사 관리(이 책에서 더함):

```js
const r = CB.pm.cpm(acts);   // acts: [{ id, name, d, pred: ["A", { id: "B", type: "SS" | "FF" | "FS", lag }] }]
// r = { ok, T, acts: { id: { ES, EF, LS, LF, TF, FF, critical } }, order, critical: [id] }   (순환이면 ok false, reason "cycle")
CB.pm.pert(a, m, b);          // { te, sd, v }
CB.pm.prob(Ts, mu, sd);       // 완료 확률
CB.pm.tri(a, m, b, u);        // 삼각 분포 표본
CB.pm.monteCarlo(acts, n, seed);   // acts에 a, m, b → { T: [공기], crit: { id: 주공정 지수 } }
CB.pm.spread(acts, r, "cost" | "res", "ES" | "LS", T, rate);   // { per, cum } — cost는 총액을 기간에 나눔, res는 기간당 값(rate)
CB.pm.evm({ BAC, PV, EV, AC });   // { SV, CV, SPI, CPI, EAC, ETC, VAC, TCPI }
CB.pm.slope({ d, dc, c, cc });    // 공기 단축 비용 경사
CB.pm.excavator(q, K, f, E, Cm); CB.pm.trucks(cycleMin, loadMin); CB.pm.learning(T1, r, n);
CB.pm.npv(cfs, i); CB.pm.irr(cfs); CB.pm.risk(freq, sev); CB.pm.rates(cases, lostDays, hours);
CB.pm.B10;                    // 기준 공사 활동 14개 { id, name, d, pred, cost, res, a, m, b }
```

`CB.pm`을 고쳤으면 `node tools/site.test.cjs`(`npm test`에 포함)를 다시 돌린다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
